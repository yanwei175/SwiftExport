# 权限目录同步

首次初始化及代码权限目录变更后，在仓库根目录运行：

```powershell
& .\_tools\DbSeed\同步权限目录.ps1
```

连接直接复用 `SwiftExport.WebApi/appsettings.json` 中的 `ConnectionStrings.Default`，按宿主环境叠加同目录环境配置，最后应用标准环境变量 `ConnectionStrings__Default`。环境变量未指定时使用 `Production`；需要开发环境配置时传 `-EnvironmentName Development`。不需要新建 `SWIFTEXPORT_DBSEED_CONNECTION`。

首次拉取仓库须先正常还原项目依赖；脚本使用 `--no-restore`，避免每次同步重复访问包源。

预览及指定服务器私有配置：

```powershell
& .\_tools\DbSeed\同步权限目录.ps1 -DryRun
& .\_tools\DbSeed\同步权限目录.ps1 -ConfigurationPath 'D:\Install\服务器配置.json'
```

脚本调用现有 PostgreSQL 权限目录同步实现。只插入代码目录缺失的权限定义，更新已有定义的名称、分组、排序；保留已有权限 UID、状态、版本、审计及角色/用户关系，不创建账号、不自动分配权限、不清库、不改结构。结构须已部署。运行仍是显式操作，不在每次 WebApi 启动时隐式写库。

旧 `ExcelFieldMapping` 功能已退出，目前读取配置使用 `excel_read_profile` 与 `excel_read_field`。当前 `System.ExcelFieldMapping.Manage` 是保留的权限键名称，显示名为“Excel读取配置维护”，实际控制 `ExcelReadProfileController` 的新增、修改、删除接口；同步该定义不恢复旧表或旧功能。

`SWIFTEXPORT_RUNTIME_DV_PASSWORD` 是运行验证的 dv 应用登录密码；`SWIFTEXPORT_RUN_PG_TESTS` 与 `SWIFTEXPORT_PG_TEST_CONNECTION` 用于测试。同步运行库权限不自动使用测试连接，避免连接到错误的库。
