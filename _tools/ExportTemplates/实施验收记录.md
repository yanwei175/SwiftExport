# 服务器模板公共服务实施验收

验证日期：2026-10-12。构建使用 .NET SDK 10.0.401，复用 `D:\DevCaches\NuGet`，产物隔离在 `.artifacts/export-templates`。没有部署正式服务器，也没有读取或写入业务数据库。

## 已完成范围

- Contracts 专用模板信息 DTO 和 Refit 列表契约，保持 netstandard2.0。
- Application 清单服务、WebAPI 独立存储配置及受保护的列表/固定版本下载；默认关闭，启用时检查目录隔离。
- WPF 服务器模板入口、在线版本复核、受认证流式下载、完整性检查、账号及服务器缓存隔离、配额清理和会话提交保护。
- 维护脚本、示例清单、部署说明和公共文件服务调用说明。

共享 DI 和权限过滤器在原「产品管理」任务完成后接管，仅合并模板接线；其系统参数、图片及其它未提交改动保留。没有改销售、采购、拼箱业务规则、导入读取行为或数据库结构。

## 构建与定向测试

Contracts、Application、WebAPI、WPF 和两测试项目均已构建成功；存在项目原有的可空性及 MSTest 分析器警告。

| 范围 | 结果 | 证据 |
| --- | --- | --- |
| WPF `Services.Files` | 106/106 通过 | 原有文件能力 72 项，服务器模板 34 项 |
| 后端文件服务及端点权限 | 113/113 通过 | 包含模板目录 64 项及相关文件/权限回归 |
| 发布脚本 | 34/34 场景通过 | 独立临时目录，包含不可变版本、失败保护、停用回退、宏及非法 ZIP |

HTTP 贯通通过本机 Kestrel、正式 Refit/认证处理器和真实 XLSX 验证两千行、相对/绝对公式引用、嵌套分组、小计、打印范围、纸张方向、固定底部内容及分页页脚；模板停用、版本更新和活动账号失效都不能凭已有缓存发起新导出。

后端筛选必须限定文件服务命名空间，避免 `~Files` 意外匹配包含 `Profiles` 的数据库测试名称。首次宽筛选误匹配的数据库门禁用例在环境标记断言处停止，连接创建代码未执行；随后使用下面的范围通过回归。

