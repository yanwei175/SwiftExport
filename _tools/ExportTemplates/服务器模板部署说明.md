# 服务器 Excel 模板发布

`发布Excel模板.ps1` 只负责校验、打包和完整发布文件，不调用数据库、正式 API、Excel、VSTO 或 ClosedXML.Report。需要 PowerShell 7.4 及以上；脚本不会自动读取正式环境配置或寻找服务器路径。

## 清单与目录

服务器根目录中的固定清单名为 `模板目录.json`，编码为严格 UTF-8，可带 UTF-8 BOM，最多 1 MiB。模板文件固定在 `{templateId}/v{templateVersion}/模板.xlsx`；清单不能声明任意文件地址。

每条记录包含以下字段：

| 字段 | 规则 |
| --- | --- |
| `templateId` | 唯一的小写字母、数字及单短横线标识，最多 64 字符 |
| `displayName` | 无首尾空格的非空文本，最多 200 字符 |
| `documentType` | 无首尾空格的非空业务类型，最多 64 字符，如 `SO`、`PO`、`PL` |
| `dataContractKey` | 无首尾空格的非空数据契约键，最多 128 字符 |
| `dataContractVersion` | 正整数，表示客户端供给的字段及结构契约 |
| `templateVersion` | 正整数，表示该模板文件的不可变版本 |
| `fileLength` | 文件实际字节数，必须大于零且不超过 20 MiB |
| `sha256` | 文件 SHA-256，64 位十六进制；输出规范为小写 |
| `enabled` | 必须明确提供 JSON 布尔值，不能省略 |

`模板目录示例.json` 是开发源描述，只省略 `fileLength`、`sha256`。脚本在校验及打包时计算并补齐这两个字段。若源描述显式提供它们，必须与文件相符；`0`、空哈希或过期哈希不会被静默覆盖。示例元数据不代表已经交付销售单业务模板或数据模型。

发布模式要求完整元数据。清单记录的 ID 不重复，即使两个版本的 ID 相同也拒绝；同时保留的历史文件不必全部出现在当前清单。

`enabled=false` 且身份元数据完整合法时，允许文件缺失或损坏，以便管理员撤下坏版本；不会为停用记录复制、覆盖或删除文件。停用源描述若省略长度或哈希，仍须有源文件来计算身份，但不要求该停用文件可渲染，也不会将其打包。未来重新启用时重新执行全部文件、长度及哈希校验。

## 开发机验证与打包

将已验收的 Excel 模板放到源目录，例如 `D:\TemplateSource\sales-order-standard\v1\模板.xlsx`，并维护源描述。

```powershell
# 只验证，不修改源目录或服务器。
pwsh -File .\_tools\ExportTemplates\发布Excel模板.ps1 -Mode Validate `
  -ManifestPath .\_tools\ExportTemplates\模板目录示例.json -SourceRoot D:\TemplateSource

# 生成包含完整清单和版本文件的独立包。
pwsh -File .\_tools\ExportTemplates\发布Excel模板.ps1 -Mode Package `
  -ManifestPath .\_tools\ExportTemplates\模板目录示例.json `
  -SourceRoot D:\TemplateSource -OutputRoot D:\TemplatePackage
```

脚本输出 `Mode`、`TemplateCount`、`Root` 和 `Manifest`。失败抛出错误并退出非零；成功的包可完整复制到服务器。不要只复制清单。

启用文件最大 20 MiB，ZIP 条目声明解压总量最大 100 MiB。脚本拒绝宏、缺失工作簿结构、坏 ZIP/XML、错误编码或启用文件身份不匹配。该结构检查不代替模板渲染验收；发布前仍需使用对应客户端数据契约生成空、单行、多行、分组及代表性单据，并检查公式和打印布局。

## 服务器发布、停用与回退

先复制包到服务器受控暂存目录，再明确指定与 WebAPI `FileStorage:ExportTemplates:RootPath` 相同的根。服务器根和包目录须专用于受控模板，不由其它工具并发改写版本文件。WebAPI 配置示例：

```json
{
  "FileStorage": {
    "ExportTemplates": {
      "Enabled": true,
      "RootPath": "D:\\ServerTemplates"
    }
  }
}
```

该根不能与通用文件容器、产品图片目录或文件存储的内部保留目录重叠；服务启动会拒绝双向包含。模板存储不注册成通用可写容器，也不映射成公开静态目录。WebAPI 运行账号只需读取模板，管理员发布账号负责写入。省略配置或设置 `Enabled=false` 时接口返回 503，不要求模板目录存在。发布脚本不修改宿主配置。

模板 API 使用现有 HTTPS 与登录认证：列表为 `GET /api/export-templates?documentType=SO&dataContractKey=...&dataContractVersion=1`，下载为 `GET /api/export-templates/{templateId}/versions/{templateVersion}/content`。二者都会实时检查活动账号；下载返回 XLSX attachment、`private, no-cache`，首期不提供 HEAD、Range 或续传。客户端使用现有 API 基址，不需要新增模板服务器系统参数。

```powershell
pwsh -File .\发布Excel模板.ps1 -Mode Publish `
  -OutputRoot D:\TemplatePackage -PublishRoot D:\ServerTemplates

# 已切换到完整包目录时，只需提供发布根。
Set-Location D:\TemplatePackage
pwsh -File D:\Tools\发布Excel模板.ps1 -Mode Publish -PublishRoot D:\ServerTemplates
```

也可在开发打包命令中显式增加 `-PublishRoot`，先完成打包再重新校验包并发布。默认 `Package` 模式不发布服务器。

脚本用服务器根的 `.模板发布.lock` 独占句柄串行化操作。锁文件可留存；是否存在该文件不代表锁仍被占用。脚本先预检所有同 ID 同版本文件，再以同目录临时文件完成新增版本，最后原子替换 `模板目录.json`。失败时保留原清单和所有旧版本；中途已完成的新版本可能留存，但未进入清单就不会成为当前模板。临时文件会清理，不删除历史版本。

同 ID 同版本的不同内容必须提高 `templateVersion`，不能覆盖。停用将完整候选清单的 `enabled` 改为 `false`；回退将记录改回已经保留的旧 `templateVersion`、`fileLength`、`sha256` 和对应契约信息。把候选清单另存，不直接编辑服务器当前清单，然后发布：

```powershell
# SourceRoot 缺省时从发布根校验既有版本文件，适用于停用或回退。
pwsh -File .\发布Excel模板.ps1 -Mode Publish `
  -ManifestPath D:\Candidates\停用或回退清单.json -PublishRoot D:\ServerTemplates
```

保留历史打包清单以便回退。切换模板版本只影响后续客户端模板选择；正在进行的导出应由客户端冻结其已选择版本。清单发布不自动刷新所有客户端，也不自动升级数据契约。

## 脚本验收

```powershell
pwsh -File .\_tools\ExportTemplates\验证模板发布.ps1
```

验证脚本只在仓库 `.artifacts/export-templates-publish-agent` 的唯一临时子目录运行，默认结束后清理。加 `-KeepArtifacts` 可保留测试包供核对。它不连接或部署真实服务器。

## 正式部署验收

当前交付公共服务，不包含模板选择页面。管理员可通过调用公共接口的验收工具或后续已接入的业务 Feature，在两个独立客户端完成以下步骤：

1. 配置同一 HTTPS API 地址，以两个活动账号登录，查询同一数据契约，确认模板 ID、文件版本及 SHA-256 一致，并分别生成 XLSX。
2. 发布新的模板文件版本，两个客户端重新查询均应取得新版本；旧选择不得自动改为新版，须刷新并重新选择。
3. 停用模板后，两端即使已缓存该模板也不能发起新的导出；停用账号后也应停止导出。
4. 断网时导出失败，恢复联网后重新在线确认；查看已生成文件的明细、公式引用、打印范围与页脚。
5. 如需回退，原子发布保留的旧版本清单，两个客户端刷新后确认一致；不覆盖旧版本文件。

开发验证使用临时 Kestrel 和内存账号，不访问业务数据库。正式服务器发布、HTTPS 配置与两个实际客户端验收由管理员执行，本次源码实施不自动部署。
