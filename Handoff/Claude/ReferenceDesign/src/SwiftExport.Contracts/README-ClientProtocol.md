# 客户端调用约定（供后端设计参考，说明协议如何被消费）

`SwiftExport.Contracts/README-ClientProtocol.md`

| 场景 | 客户端行为 |
|---|---|
| 用户点击状态命令按钮 | 生成 `key = Guid.NewGuid()`，**保存在当前操作对象上**，按钮置为忙 |
| 200 | 用返回 DTO 替换界面数据；丢弃 key |
| 400 / 422 | 显示消息；丢弃 key（用户修改后再点是新操作，新 key） |
| 401 | 重新登录 |
| 403 | 提示无权限 |
| 404 / 409 `concurrency_conflict` | 提示“已被他人修改”，重新加载单据；丢弃 key |
| 409 `idempotency_in_flight`、503、网络超时 | **用同一个 key 自动重试 1–2 次**（间隔 1s、3s）；仍失败则提示“无法确认结果”，并自动重新加载单据显示真实状态 |
| 500 `unexpected` | 显示 traceId；丢弃 key（服务器已回滚） |
| 成功但后续刷新列表失败 | 只重新读取，**不**重发命令 |

用户界面上不需要常驻的“重试”按钮：同 key 重试由客户端自动完成；重新加载后用户看到真实状态，再决定是否重新操作（新 key）。
