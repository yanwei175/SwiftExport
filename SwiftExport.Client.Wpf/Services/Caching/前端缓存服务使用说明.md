# 前端基础资料缓存使用说明

`IReferenceDataCacheService` 是应用级单例，通过构造函数注入 ViewModel 或前端 Service。不要自行 `new ReferenceDataCacheService`。

首次使用前调用：

```csharp
var result = await cacheService.EnsureLoadedAsync();
if (!result.Success)
{
    // result.Message 可用于页面提示；失败时服务会保留旧缓存。
}
```

产品颜色集合可绑定 `cacheService.ProductColors`。产品分类提供两种稳定的只读集合：

- `ProductCategoryTree`：保留层级，供 TreeView 使用。
- `ProductCategories`：按树顺序扁平化，供本地 Lookup 使用；节点的 `CategoryPath` 是完整分类路径。

字典缓存提供：

- `DictionaryTypes`：全部未删除字典类型。
- `DictionaryValues`：全部未删除字典值，包含停用值。
- `GetDictionaryValues(dictCode)`：按编码取得启用值，适合业务下拉。
- `GetDictionaryValues(dictCode, enabledOnly: false)`：按编码取得包含停用项的全部值，适合维护或历史数据显示。

产品分类树可直接绑定 TreeView：

```xml
<TreeView ItemsSource="{Binding ReferenceDataCache.ProductCategoryTree}">
    <TreeView.Resources>
        <HierarchicalDataTemplate DataType="{x:Type caching:ProductCategoryCacheNode}"
                                  ItemsSource="{Binding Children}">
            <TextBlock Text="{Binding CategoryName}" />
        </HierarchicalDataTemplate>
    </TreeView.Resources>
</TreeView>
```

维护基础资料并保存成功后，调用对应的 `RefreshProductColorsAsync()`、`RefreshProductCategoriesAsync()` 或 `RefreshDictionariesAsync()`。需要全部重拉时调用 `RefreshAllAsync()`。字典专项刷新会同时更新字典类型和值，任一接口失败都保留旧字典快照。

对外集合是只读集合，调用方不得修改其中的 DTO，也不得把分类缓存节点当成编辑模型。编辑页面应建立自己的模型，保存成功后再刷新缓存。退出登录、登录过期或切换用户时，缓存会自动清空。
