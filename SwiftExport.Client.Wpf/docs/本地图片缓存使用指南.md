# 本地图片缓存使用指南

## 使用边界

- 支持本机绝对路径和 UNC 共享路径。
- 不支持相对路径、HTTP/HTTPS、图片上传或编辑。
- 业务 ViewModel 只保存路径，不创建 `BitmapImage`。
- 缓存服务只生成缩略图，不复制或修改原始图片。

## XAML

```xaml
<controls:CachedImage
    Style="{StaticResource SwiftExportCachedImage}"
    SourcePath="{Binding MainImage}"
    DecodePixelWidth="96" />
```

DataGrid 中应把控件放在 `DataGridTemplateColumn.CellTemplate`，并保持行、列虚拟化开启。路径变化和容器回收会取消旧等待，因此不会把上一行图片显示到新行。

大图预览建议复用同一控件并设置 `DecodePixelWidth="400"`；WPF-UI Dialog 只负责弹窗外壳，不负责加载和缓存图片。

## 缓存位置和上限

- 内存默认 64 MB、最多 512 项，按解码后的像素字节进行 LRU 淘汰。
- 磁盘默认 512 MB，目录为 `%LOCALAPPDATA%\SwiftExport\Cache\Images\v1`。
- 超过磁盘上限时按最近使用时间清理到 80%，30 天未使用的缩略图自动过期。
- 原图片的长度或最后写入时间变化后会生成新 Key，旧缩略图等待配额或过期清理。

缓存配置位于 `appsettings.json` 的 `ImageCache` 节。应用需要主动清缓存时，通过 DI 获取 `IImageCacheService` 并调用 `ClearAsync`。
