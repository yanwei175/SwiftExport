# 主型号资料显式同步关联物料

主型号默认资料不实时覆盖已有物料；保存选项和独立下发命令均需用户显式触发。

- 保存入口为 ProductMaster 的 `batch-save` 和 `save-detail`，不包含独立 Neutral 保存。管理页另有描述、配置、供应商、重量体积和四组统一下发五个独立 API。
- 两页共享 WPF-UI ContentDialog；每次两个选项都默认不勾选。确认才保存，取消、Esc 或关闭均保留编辑且不发送保存请求。
- 管理页一批只询问一次，选项作用于新增和修改项；纯删除不询问，也不更改关联 Product。
- 仅按 `Product.ProductMasterId = ProductMaster.Uid` 匹配全部未软删除物料（含停用物料），不按字符串补关联。
- 保存时始终同步主型号编码。`UpdateProductDescriptions` 控制四个描述/配置字段，`UpdateProductDefaultSupplier` 只控制默认供应商 ID；空值明确清空。供应商代码由产品查询按 ID 实时联表展示，不存回 Product。
- 独立下发只接收主型号 UID 集合，从数据库当前值按已有关系寻找目标，不同步主型号编码，也不改关联。页面有未保存修改时先保存或放弃；执行前确认范围。服务端要求产品编辑权限；供应商下发时校验非空供应商存在、未删除且启用。
- 产品页“更多功能”提供相同五组资料的拉取入口：勾选产品优先，无勾选时用当前行；请求仅发送产品 UID，未关联或关联主型号失效的产品跳过并计数，不影响同主型号下未选产品。页面有未保存修改时先保存或撤销。
- 重量体积独立下发直接把主型号 `DefaultGrossWeight`、`DefaultCbm` 写入产品 `UnitWeight`、`UnitCBM`，不下发装箱数与净重，也不按装箱数换算。源字段按每箱、目标字段按每基础单位命名，此直接复制是当前明确采用的口径。
- 每次保存或独立下发均由应用服务持有单一事务。覆盖读取数据库当前值，不提供物料预览版本；发生差异才更新审计字段并递增一次 Product.Version，旧版本物料保存会冲突。
- 不修改历史单据、物料价格、BOM、库存、启停状态或关联本身；产品普通保存逻辑保持原有行为。

## 部署及已知边界

ProductMasterId 列及关联数据由用户维护。本次不提供 DDL、迁移或旧编码兜底。普通 Product API 尚未携带新关联字段，其保存映射可能覆盖 ProductMasterId；按用户指定，本功能不处理该链路，须由 Product 模块另行处理。

## 验证

- 客户端筛选测试：`dotnet test SwiftExport.Client.Wpf.Tests/SwiftExport.Client.Wpf.Tests.csproj --filter FullyQualifiedName~ProductMaster`。
- 真实数据库测试：显式设置 `SWIFTEXPORT_RUN_SQL_TESTS=1`，运行 Application.Tests 中 `ProductMasterSynchronizationSqlTests`。只使用本机 LocalDB，为每个测试创建随机测试库并清理，绝不读取应用连接配置。测试表不是生产建表脚本。
- 人工验收：两页用键盘打开弹窗、Tab/Space 勾选、确认及 Esc 取消，检查焦点返回和高对比度。保存后刷新已打开的 Product 页面再编辑；旧版本保存应收到并发冲突。
