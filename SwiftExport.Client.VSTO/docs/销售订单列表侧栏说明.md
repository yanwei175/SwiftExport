# 销售订单列表侧栏

## 入口与布局

Ribbon「单据 → 销售订单」在所属 Excel 窗口右侧打开列表。配置位于 `TaskPaneRegistrar.CreateDefault()`，页面键 `sales-order-list`，首次宽度 720；用户可调整宽度，后续显示不覆盖。重复点击切换显隐，× 隐藏保留当前页和勾选，失效重建或插件退出释放 Scope。

`SalesOrderListView.xaml` 顶部为 Excel 工具栏：输出路径默认 `Environment.SpecialFolder.DesktopDirectory`（系统桌面，兼容重定向目录），允许修改；「生成选中订单成 Excel」「批量生成勾选订单成 Excel」仅预留、禁用，尚无文件生成、输出校验或详情加载。

筛选只有 Keyword、客户代码、确认状态、快捷视图。客户代码精确筛选，留空查询全部；确认状态单选「全部／待确认／已确认」，快捷视图沿用 .NET 10 管理页九个选项，两者与普通条件取交集。点击查询从第一页开始，刷新使用当前页，每页 30 条，支持上一页／下一页。首次显示按需加载，同会话重复 Loaded 不重复查询。

下方原生 DataGrid 展示勾选、确认、单据、执行、订单号、发票号、数量、已交、未交。执行来自查询契约 `FulfillmentStatus`，不自行推导。数量保留 nullable，无法汇总显示「—」，不转换为零；行提示展示单位。数据列只读，单行选中与批量勾选独立。勾选仅限本页，成功重新查询或翻页后清空；失败保留已有列表和输入，错误单独展示。

## 复用与生命周期

- 直接复用 `ISalesOrderManagerApi.SearchAsync`、`SalesOrderManagerSearchRequest`、`SalesOrderManagerListItemDto`；VSTO 注册相对根地址 `api/sales-orders/manager`，沿用认证 HTTP 管线。
- 两端消费的是同一销售订单管理摘要，查询来源、权限、状态、数量及空值语义相同，不新增 DTO／后端接口。`SalesOrderListRow` 仅组合原 DTO 与本页通知勾选状态，不将 UI 状态写回共享契约。
- View／ViewModel 在 DI 注册 Scoped，由窗格持有；模型继承 `ViewModelBaseEx`，属性和 Toolkit 命令手写 C# 7.3，不使用源生成器。
- Ribbon 与页面均使用 `Sales.Order.View` 改善访问体验，服务器门禁始终权威。Ribbon getter 只读内存；无权限、登录恢复或切换期间入口禁用。
- 查询期间禁止并发操作；请求冻结筛选，接纳检查操作身份、会话版本和模型存活。账号变化清空旧列表、筛选和勾选，取消旧传输，等待首次显示或用户主动查询。Scope 释放取消请求并解绑会话和行通知，迟到响应不回填。
- 隐藏不释放页面，也不自动轮询或预热基础资料；没有增加缓存、Excel COM 访问、导出业务或订单写操作。
