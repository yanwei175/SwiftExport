# PackingList 导入验收清单

实现及部署说明见 [PackingList 导入与来源关联](../../docs/PackingList导入与来源关联实施说明.md)。本清单只适用于 VSTO PackingList，仍需用户在安装了 Excel 的实际宿主验证。

## 自动验证

纯托管测试项目 `SwiftExport.Client.VSTO.Tests` 共 87 项通过。新增测试覆盖附件二维值快照 21 行／195 数量、Q／R 原文、反射字段边界、客户选择取消、检查失效、未知保存重试和旧会话／释放回写隔离。

STA 测试入口 `SwiftExport.Client.VSTO.WpfTests.exe --packing-import-only` 的 9 项断言通过，验证真实资源、单头日期、标准／非标单位、数量输入、检查 SKU 回显和关闭保护。没有加载 Office。

Visual Studio MSBuild 的 Debug 和 Release 构建通过。全量 STA 的既有隐式样式断言失败及地址配置的异常诊断记录见总说明；不得将专项通过当作全量通过。

## Excel 实机待验

- 未验证登录时入口禁用；登录后打开非模态导入窗口，重复点击激活唯一窗口，Owner 正确。
- 从 Ribbon 独立打开地址配置侧栏，选择 PackingList；配置工作表仅设置一次，可空，系统身份不进入反射字段目录。
- 单头和明细按配置读取，不限制打印区域；Q／R、隐藏行、空 PO、多个 Invoice 原文正确保留。附件明细 21 行，数量合计 195。
- B15:B35、I20:I35 等可选包装纵向合并留空并提示；没有重复箱数、重量、体积。整理后的地址单格正常读取。
- 修改客户、型号、数量、候选或差异确认后必须重新检查；多候选不自动选第一条；非标须描述和单位。
- 再读先确认，只替换对应部分；失败、取消不覆盖旧编辑。标准单位取系统，非标可编辑。
- 保存使用现有创建链路；系统单号回显，刷新客户端可见待关联草稿。未知结果只重试原命令。
- 网络期间 Excel 可以操作；更换账号清空旧数据，迟到结果不能回填；多次开关无残留，插件退出不弹阻塞确认、不强杀 Excel。
