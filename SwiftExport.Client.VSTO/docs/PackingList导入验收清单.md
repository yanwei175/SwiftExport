# PackingList 导入验收清单

本清单只适用于 VSTO PackingList。导入维持“按地址读取 → 修正 → 检验 → 保存未关联草稿”，来源关联、拆行、合并及拼箱在保存后的独立用例完成。后端及部署说明见 [PackingList 导入与来源关联](../../docs/PackingList导入与来源关联实施说明.md)。

## 页面与编辑边界

- 单头全部常驻，横向标签与输入框布局，取消“其他表头资料”Popup。客户、单据日期使用红字星号。系统箱单号未保存显示“保存后生成”，保存成功回显服务器编号。
- Ship-To 收货名称、地址、联系人和运输资料可直接编辑；明细 PO／Invoice 原文分别保留，不替代系统箱单号。
- 顶部“更多”使用与销售、采购相同的 WPF-UI DropDownButton，菜单保留加载／刷新配置、设计读取配置和新导入三个入口。
- “相关发票号”只读绑定 `InvoiceNosSummary`：保存前按当前明细 `InvoiceNo` 修剪首尾普通空格、去重，按集合顺序以逗号连接预览；保存后接纳后端详情的汇总值。后端汇总未删除行的 `InvoiceNo`，不汇总来源查询字段 `SourceInvoiceNo`，也不采用 Excel 单头读取值。多单号行原文仍作为完整文本汇总，不在这里拆分来源。
- `Header.ExcelDocumentNo` 恢复为活动配置字段，显示名称“单头发票号”、`DisplayOrder = 40`，位于联系人与单据日期之间。已有该键的地址继续有效，新增配置同样显示其地址编辑器。导入按地址读取原文到前端模型，不加入草稿请求，不追加到备注，不替代 `InvoiceNosSummary`。该地址供后续导出定位使用，本次不实现导出。新导入或账号变化清空此前服务器汇总和原文。
- PackingList 分组复用已有配置创建接口；配置列表为空时可以直接点击“新建空配置”，名称为空则使用“装箱单读取配置”。仅显式点击时创建，不在打开页面时自动预置数据库记录。服务器返回空字段后，前端按模型特性及 `DisplayOrder` 显示所有单头／明细编辑器；地址留空，单头读取一次、明细默认向下读取，需要获取地址及设置结束方式后保存。
- 页面用有限高度 Grid，DataGrid 占剩余高度，无顶层 ScrollViewer。读取与检验反馈区域最大高度 84，内部滚动；检验问题使用红字。
- 再读取先确认，只替换所读取部分。单头只更新本次实际读取的字段，未配置字段保留，已配置空单元格清空对应值。读取失败或取消保留旧输入。
- 换客户或清空客户保留单头及明细，不再清空整张表；清除旧产品身份、图片、候选和型号差异确认，撤销检查与保存资格。客户必须从缓存控件明确选择，输入文字本身不授予客户身份。

## 明细与匹配

- 工具栏提供读取明细、匹配全部 SKU、添加标准行、添加非标行、多选删除和“显示更多字段”开关。新增行自动选中并滚动定位，批量读取不逐行抢占焦点。
- 行号按读取顺序生成；手工添加取当前最大号加一，删除不重排。行号不进入地址配置目录。排序仅改变视图，保存仍按底层集合顺序生成请求行号。
- 行号列内红／绿圆点表示行校验资格；“校验 / 处理”列按 IsCheckPassed 排序，可将未通过行集中处理。
- 标准／非标由“非标件”CheckBox 明确切换，不因匹配失败自动转换。标准单位取系统，只读；非标单位在常驻 ComboBox 中选择或输入。系统图片复用 HttpsImage 的 HTTPS／本地路径及内存缓存。
- 每行有“匹配 SKU”及“处理”Popup。Popup 内展示候选、中性型号差异确认和完整反馈；选择候选或确认差异后重新匹配。关闭按钮、Esc、再次点击入口同步复位；页面卸载关闭浮动弹层。
- 未选客户时全部／本行匹配禁用。独立匹配只接纳目标行结果，无需先填齐日期等单头，也不授予整单保存资格。
- 数量、包装、描述等编辑撤销行检查资格，保留已匹配产品；客户型号、客户或行类型变化清除产品身份。Excel 中性型号变化撤销差异确认。非法数值原文保留，不能因请求临时转换为空或零显示通过。
- 接纳响应核对客户、会话、整单及行修订、行身份和页面生命周期。保存要求当前整单检验通过；未知保存结果冻结原请求，用同一 CommandId 重试。
- 默认常显行号、校验处理、非标、图片、系统 SKU、客户型号、Excel／系统中性型号、描述、数量、单位、每箱数量、每箱体积及 PO／Invoice 原文；颜色、每箱净重／毛重、箱唛及备注由开关显示，隐藏不改变数据或验证。

## 设计器预览

- 项目的 `Properties/DesignTimeResources.xaml` 已标记 `ContainsDesignTimeResources=true`。PackingList 页同时通过 `d:ResourceDictionary` 显式合并这份字典，预览不依赖 Excel 启动或应用级资源自动发现；编译后的运行页面不合并它。
- 使用独立的 `ViewModels/PackingListImportDesignViewModel.cs`，通过 `d:DataContext` 和 `d:DesignInstance IsDesignTimeCreatable=True` 接入。示例在设计模型构造函数中集中调整，提供单头、客户、配置和已匹配／未匹配／非标三条明细；移除 XAML 内的占位数组和 `d:SampleData`。
- 设计模型不注册 DI、不访问缓存、会话、Excel 或网络，按钮使用无业务副作用的预览命令。视图无参构造函数仅建立可视树，运行时仍由带参数构造函数接纳真实 ViewModel 并接线生命周期，不自动注入示例数据。
- DataGrid 列头、数据文字及行内按钮字号统一为 10，图标保留控件模板尺寸。实际 Visual Studio 设计器显示仍需人工确认。
- “仅显示平台控件”会停用项目自定义控件和转换器；日期模板可能因转换器不可用而报告 MultiBinding 错误，不能据此认定运行时漏配 Converter。独立加载已确认日期模板含有效转换器及三个绑定；空应用级主题资源下的页面局部设计资源加载也已验证。这些检查不等同于实际 VS 设计器验收。
- `InitializeComponent`、`LinesGrid` 来自 WPF 标记编译生成的部分类型，与设计时数据方式无关。若正式构建通过但 IntelliSense 报 CS0103，应核对设计时生成清单和项目重载；不要在后台代码手写同名成员或修改生成文件。
- 本次设计模型的构建和 STA 结果见下方自动验证。独立测试不等同于验证 Visual Studio 中红线已消失；传统项目新增设计模型已登记 Compile 项，若 VS 提示项目文件外部变化应重新加载项目。

## 包装暂计

汇总位于 DataGrid 上方，显示行数、总数量、总箱数、总毛重、总体积。非正数量红字。

- 箱数＝数量÷每箱数量，保留小数，不向上取整。
- 毛重／体积＝箱数×对应每箱值。
- 缺失、非法或溢出值不计入对应统计，并提示“包装汇总不完整”。缺少可选包装资料本身不阻止保存，非法输入仍按现有规则检验。
- 汇总注明“按当前行资料暂计”，不代表已完成拼箱整理，不据此建立包装或来源关系。
- 跨行合并的每箱数量、净重、毛重和体积留空并提示，不复制、不分摊。箱唛是文字标识，跨行合并时读取左上角原文并复制到读取范围内的有效明细，保留换行；只有箱唛而其他字段全空且无读取错误的行跳过。单头继续按单格或合并单格配置。
