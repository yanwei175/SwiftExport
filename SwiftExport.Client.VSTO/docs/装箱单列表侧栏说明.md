# 装箱单列表侧栏

Ribbon“单据 → 装箱单”打开 `PackingListView`。页面只负责查询、当前页勾选和未来导出工具栏，不建立来源关联、拼箱或执行过账。

## 查询和展示

- 复用现有 `IPackingListApi.SearchAsync`、`PackingListManagerSearchRequest`、`PackingListManagerListItemDto`，路径为 `POST /api/shipping/packing-lists/search`。未新增后端、DTO、列表数量汇总或逐行详情请求。
- 筛选为关键词、缓存客户选择和过账状态；留空客户表示全部，过账状态包含全部、未过账、已过账、已冲销。不提交日期筛选，关键词提交时修剪空白。
- 列为勾选、箱单号、客户名称快照、单据日期、有效行发票号汇总、过账状态、集装箱号、封条号、ETD、ETA。业务字段只读，状态中文回显，日期按 yyyy-MM-dd 展示；表格支持排序、虚拟化及横向滚动。
- 每页 30 条，查询回第一页，刷新当前页。表格当前行与勾选独立；接纳新页清除旧选择，勾选仅限当前页。
- 输出路径默认当前电脑桌面，可编辑；“生成选中箱单成 Excel”和“批量生成勾选箱单成 Excel”禁用并标注“待实现”。本期不创建文件、不获取导出详情，不使用采购导出服务。

## 生命周期与宿主

- 构造函数仅接线，首次 Loaded 加载客户和第一页；重复 Loaded 保留筛选、列表和勾选。客户资料失败时仍可查询全部客户，刷新重试资料；查询失败保留当前行和筛选。
- 页面模型继承 ViewModelBaseEx，手写 C# 7.3 属性和命令。行模型组合只读 DTO 与本页勾选，不复制传输字段，不改缓存 DTO。
- 每次操作冻结请求，接纳核对请求身份、取消状态、会话版本和页面存活。切换或退出账号清空旧列表、客户、筛选和勾选；Scope 释放取消查询并解绑会话及行事件。不可取消的客户缓存等待结束后仍检查身份，不能启动旧账号搜索。
- 沿用 `Shipping.PackingList.View` 权限及现有认证 HTTP 管线，Ribbon getter 只读内存。服务端授权仍是最终结果。
- `TaskPaneRegistrar` 注册键 `packing-list`，Scoped View／ViewModel；当前初始宽度与销售／采购列表一致为 1400，之后保留用户调整。按 Excel HWND 和页面键复用，重复点击切换显示，× 隐藏保留内容，销毁释放 Scope。不新增协调器或宿主。
- 有限高度 Grid 内表格占剩余空间，反馈最多 84 高度并内部滚动；沿用固定 Light 主题和宿主统一字体。
