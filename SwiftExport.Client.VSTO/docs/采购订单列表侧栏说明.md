# 采购订单列表侧栏

## 页面与入口

Ribbon「单据 → 采购订单」打开所属 Excel 窗口的右侧栏。`TaskPaneRegistrar.CreateDefault()` 注册页面键 `purchase-order-list`，首次宽度 720。重复点击切换显隐，隐藏保留当前页与勾选，失效重建或插件退出释放页面 Scope；后续不覆盖用户调整的宽度。

顶部 Excel 工具栏沿用销售侧栏：输出路径默认系统桌面，可手工修改；单张生成与勾选批量生成仅预留、禁用，尚不加载详情或生成文件。

筛选保留 Keyword、客户代码、确认状态、快捷视图。客户代码使用采购头快照精确筛选，不请求主数据缓存。确认默认全部，可选待确认／已确认；快捷视图直接采用采购管理的交期风险枚举「全部／逾期未货好／临期未货好」，与其他条件取交集。首次显示按需搜索，每页 30 条；查询回第一页，刷新当前页，提供上一页／下一页。

DataGrid 保留以下列，另外提供本页勾选列：

| 列 | 数据来源 |
| --- | --- |
| 确认 | ConfirmationStatus 的中文描述 |
| 单据 | LifecycleStatus 的中文描述 |
| 采购单号 | OrderNo |
| 自定义采购单号 | BoNo |
| 总数量 | TotalQty |
| 已知已备好合计 | ReadyQty |
| 货好状态 | ReadyStatus 的中文描述 |
| 收货状态 | ReceiptStatus 的中文描述 |

数量原样保留 nullable，显示最多四位小数，空值为「—」，不推导为零。行提示展示数量单位；已知已备好合计不能替代整单货好状态，收货状态不代表库存余额，未知枚举显示「未知」。本期没有确认、收货、跟进或其他写操作。

## 契约与生命周期

复用 `IPurchaseOrderManagerApi.SearchAsync`、`PurchaseOrderManagerSearchRequest`、`PurchaseOrderManagerListItemDto`。VSTO 注册根地址 `api/procurement/order-manager`，沿用认证 HTTP 管线。两端消费同一采购管理摘要，权限、状态、数量、单位和空值口径一致；不新增 API／DTO，不使用普通采购详情查询替代 Manager。`PurchaseOrderListRow` 只组合 DTO 与通知勾选，不复制业务字段或修改 DTO。

View／ViewModel 注册 Scoped，模型继承 `ViewModelBaseEx`，使用 C# 7.3 手写属性与 Toolkit 运行库命令。Ribbon 与模型采用 `Procurement.Order.Read`；服务器授权仍是最终依据。

当前行与勾选独立，勾选只作用于本页，成功查询／翻页清空，失败保留已有列表与输入。重复 Loaded 不重复查询或清空勾选。查询期间禁止并发操作，响应接纳检查请求身份、会话版本及模型存活；账号变化清空旧列表、筛选、勾选并取消传输。Scope 释放解绑事件并取消查询，旧响应不得覆盖新账号或已释放页面。
