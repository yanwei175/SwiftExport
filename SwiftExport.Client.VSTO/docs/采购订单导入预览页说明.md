# 采购订单导入页

本文件沿用旧“预览页”文件名；当前已接入本地编辑、地址读取、检验及草稿创建，原静态布局说明由本文取代。

## 操作与业务边界

登录后，从 Ribbon“数据导入 → 采购订单导入”打开非模态 WinForms＋ElementHost 窗体，可同时操作 Excel。同一 Excel HWND 下重复打开激活原实例，不同窗口各有 Scope。普通关闭未保存输入须确认；插件退出不弹确认。

基础资料采用 ReferenceDataCacheService 首次使用加载，不在 Startup 或登录后预热；加载失败可以重试，成功后重复 Loaded 不重置编辑。选择 PurchaseOrder 读取配置，分别读取单头和明细；设计入口打开右侧配置栏，Ribbon 设置入口也可独立打开。管理员在顶部选择销售或采购业务组，各组字段从自己的通知模型特性生成。

客户使用与销售导入相同的缓存选择器，实际供应商由用户明确选择。标准产品通过客户代码＋客户型号匹配 ProductId；未选客户时匹配按钮禁用。明细工具栏可“匹配全部 SKU”，每行校验列可“匹配本行”，不要求先选供应商或填完单头。独立匹配只接纳产品结果，不授予整单保存资格。未匹配不自动当非标；歧义需明确采用候选并重新检验；Excel 本司型号与系统 LinkSku 差异须勾选确认并重新检验。

只有当前编辑版本完整通过检查才开放保存。创建未确认、无来源采购草稿；关联来源销售需求、确认、入库另行处理。

## 字段与金额

当前单头参考 .NET 10 采购详情，以五组横向“标签＋输入框”Grid 常驻显示：客户／客户 PO／BONO／业务员／特殊要求；日期／跟单员／系统单号；实际供应商／进水管／起泡器／托盘／CNY；内盒／标贴／说明书／外箱／商标；优惠倍率／整单优惠金额／优惠备注。客户、实际供应商、订单日期使用红色星号。该布局取代原采购单头 Popup；不增加顶层 ScrollViewer。顶部提示红字、内部滚动且上限 84，DataGrid 占剩余高度。

明细以一个“非标件”CheckBox 表达行类型；行头红绿圆点显示是否通过当前行检验。“校验”模板列可按 IsCheckPassed 排序，包含本行匹配按钮和处理 Popup；完整问题、候选选择和型号差异确认在该弹层中处理。弹层不占明细布局高度，关闭保留输入，宿主卸载时关闭。使用入口按钮、关闭按钮或 Esc 关闭。“显示更多字段”默认关闭，控制工厂型号、表面处理、配置、物料类型、供货方式、含税单价、客供件送至供应商及行备注。系统图片常显，隐藏列不改变值、验证或请求。数量小于等于零显示红字；明细数量和 CNY 未税行金额汇总在工具栏。

行内 Popup 的 PlacementTarget 和 EntryButton 分别负责定位与开关；IsOpen 双向绑定当前行处理按钮的 IsChecked。弹层显式接入当前行 DataContext、字体和页面命令，避免 Popup 独立可视树找不到 ViewModel。标题区的“关闭”按钮调用 ApplicationCommands.Close，由 ImportHeaderPopup 接收。

- Excel 原采购号为 BoNo，系统 OrderNo 由后端生成，成功后单独显示。
- 非空 BONO 在所有未软删除采购订单中唯一，跨客户、供应商和确认／关闭／作废状态；只修剪首尾普通空格并按现有不区分大小写口径比较。空号不参与查重。重复不能通过确认绕过，正式创建仍在事务内复核，数据库唯一索引负责并发占号。
- 本期币种固定 CNY；数量大于零，未税单价必填且非负，零价须明确填 0；含税价可空。数量、单价最多四位小数。
- 特殊要求使用 Header.Remark。PackagingRequirements 不出现在配置目录和页面，不填写该契约字段；内盒、外箱等细分字段保留。
- 优惠倍率、整单优惠金额及优惠备注可编辑，仅记录，不改变报价和汇总；倍率非负，金额允许有符号。
- 新手工行采用当时单头预计交期，后续改单头不覆盖既有行；读取缺失交期保持空。
- 分别显示真实 Sku、系统 LinkSku 和 Excel 原本司型号 OriginalLinkSku。原工厂型号、描述、表面处理、配置、价格和备注不被检查结果覆盖。
- 标准单位由主数据返回，禁止手工伪造；明确转为非标后可填写单位。非标需要描述和单位，创建用空 ProductId，编号由服务器生成。
- 客供件可选送达供应商，误选可以清除，资格由后端判断；非标不传送达供应商。
- 原生 DataGrid 支持编辑、多选删除及横向滚动，不使用 EnterpriseGrid。非法数字保留文字，不转为零；金额两位显示，不改变内部精度。数量合计只是输入统计。
- 图片显示系统匹配的 HTTPS 或本地图片路径，复用 HttpsImage 及内存缓存，不建本地图片缓存。本期不读取 Excel 内嵌图片。

## 客户采购默认配置

客户和供应商都选齐后，复用 ICustomerPoConfigApi.GetByPartiesAsync 查询配置；同一组合自动尝试一次，顶部“更多 → 重新获取客户采购配置”可显式重试。不建设配置共享缓存，也不复制 .NET 10 详情 ViewModel；其需求转采购默认值当前由后端预览用例组合。

只补仍为空的进水管、起泡器、托盘、内盒、标贴、说明书、外箱、商标、业务员、跟单员、优惠倍率、优惠备注和特殊要求；IMType → InstructionManualType，Purchaser → PurchasePerson，Note → Remark。非空值（包括尚未完成或非法的数字原文）保留，不更改 BONO、客户 PO、日期、整单优惠金额和明细。配置币种不是 CNY 时提示，保存仍固定 CNY。

查看配置需 Customers.PoConfig.View。无配置、无权限或失败仅提示，可以手工填写和显式重试；不放宽权限。查询期间可编辑，只暂禁整单检验和保存。响应核对请求序号、双方 ID、会话和页面存活，关闭／退出／切换账号取消请求并拒绝迟到结果。换双方后非空默认资料继续保留，自动查询不替换上一组合的内容。

## 地址配置和读取

PurchaseOrderImportHeader／PurchaseOrderImportLine 的 ExcelImportField 特性是采购配置的唯一目录；ProductId、系统 Sku、非标状态和差异确认不能由地址赋值。管理员选择地址即可，不需要寻找第二套 SQL 字段表。

WorksheetName 为顶部统一可空参考名称，实际读取当前活动 Worksheet。明细 IsDownward 配合 EndMode／LastRowColumn／SummaryCellAddress，沿用公共读取器，包含隐藏和筛选隐藏行，合并区域取左上角，跨行合并拒绝。采购文本日期按 zh-CN 解析，数值日期遵循工作簿 1900／1904 日期体系。

重新读取先确认，只替换对应部分：读单头只赋值本次确实读取的配置字段，未配置字段保留；已配置单格为空则明确清空该字段。实际供应商与明细保留，读明细不改单头。读取客户代码后只按缓存中的唯一未删除客户回显；无法定位时保留 Excel 代码并提示手选，不允许匹配。客户变化保留数量、价格、描述等原始输入，撤销旧产品身份、候选、差异确认和检查资格。取消、失败、旧账号及释放后的结果不得回写。

配置不进入基础资料缓存，不自动读取 Excel。配置栏分组及配置切换须确认未保存修改；取消保留原组。再次显示保留 Scope 和宽度，显式业务入口可请求定位，由页面负责确认；× 仅隐藏。

## 协议、权限与异步

检查使用 IForExcelPurchaseOrderApi：api/for-excel/purchase-orders/check。创建复用 IProcurementOrderApi.CreateAsync：api/procurement/orders，不调用从物料需求生成采购的接口。检查及创建需要 Procurement.Order.Create；配置维护需要 System.ExcelFieldMapping.Manage。认证、401 和 403 沿用插件统一 HTTP 管线。

任意编辑撤销整单检查资格；响应接纳核对会话版本、客户身份、整单编辑版本、请求行集合、稳定 ClientLineId 和逐行版本，本行匹配不覆盖其他行。独立 SKU 匹配安全传递未完成数字输入，不访问空数值的 Value，保留原文且仍阻止保存。检查及保存锁定输入。未知保存结果保留冻结请求；显式“重试原保存请求”使用原 CommandId 和原值，不自动重发。明确拒绝后修正并重新检查。

成功后禁止重复保存；“开始新导入”重建输入。账号切换／退出清空草稿和旧请求，新账号重新加载。普通关闭未知结果会提醒丢失原请求，Scope 释放取消任务并解绑，不终止 Excel。
