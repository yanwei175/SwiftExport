# VSTO 样式迁移说明

## 范围

从 SwiftExport.Client.Wpf/Resources 迁移颜色、布局变量、WPF-UI 项目画刷、字体层级，以及 Border、Button、TextBox、ContextMenu、Thumb、ListBox、DatePicker、原生 DataGrid、TabItem、Image 的视觉样式。资源统一由 Themes.xaml 按基础资源、控件样式顺序合并，设计器通过原有入口使用相同字典。

不引用 .NET 10 客户端或 EnterpriseGrid；不迁移 Shell 页签保活、图片下载缓存、Lookup、筛选控件和分页控件的功能实现。不迁移 BaseLineModel、BaseListModel、LineState 或 GridChangeSet。订单导入预览的 API 匹配、校验、勾选与 DTO 组装留在未来 Features/DataImport 的专用模型和服务，不增加保存 API 或 CRUD 状态机。

## 与源客户端的差异

- Variables 中 System.Runtime 的 Double 改用 net48 的 mscorlib。
- Typography 保留命名键，用原生 TextBlock 样式及明确字号／字重代替 .NET 10 Fluent 专属样式键。
- Button／TextBoxes 显式合并 WPF-UI 4.3.0 对应基础控件字典，保证 ui 控件 BasedOn 可解析；Borders 改用 WPF DynamicResource。
- DatePicker 保留紧凑外观，日期按钮留白由按钮实际宽度计算。库内转换器不能从本程序集 XAML 访问，因此使用小型 C# 7.3 布局转换器。
- DataGrid 删除所有 EnterpriseGrid 附加属性、转换器、行状态标记、扩展验证以及 CurrentRow／CurrentCell 同步。保留原生行／单元格／表头、文本／数字／日期／勾选列视觉、原生 Validation.HasError 提示及键盘焦点边框。
- DataGrid 样式不设置 AutoGenerateColumns、CanUserAddRows、CanUserDeleteRows、SelectionMode、SelectionUnit；这些属于页面行为，页面必须自行明确。RowHeader 不自动生成行号，未引入行为助手。
- TabControl 仅保留 SwiftExportTabItemStyle，不迁移依赖 Shell 的内容保活模板。
- Image 改为原生 Image 的 SwiftExportImage 与 SwiftExportImageToolTip；绑定 Source，不提供 SourcePath、解码或缓存功能。
- 原有 SwiftExportFont／背景／前景资源保留；高对比度下由 ThemeService 覆盖 DataGrid 选中背景与配对文字、主要页面文字和提示色，返回 Light 后恢复字典默认颜色。

## 使用示例

下面仅演示页面需要明确的行为，不引入对应业务 ViewModel：

```xml
<DataGrid Style="{StaticResource SwiftExportDataGrid}"
          ItemsSource="{Binding PreviewItems}"
          SelectedItem="{Binding SelectedItem}"
          AutoGenerateColumns="False"
          CanUserAddRows="False" CanUserDeleteRows="False"
          IsReadOnly="True" SelectionMode="Extended" SelectionUnit="FullRow">
    <DataGrid.Columns>
        <DataGridTextColumn Header="订单号" Binding="{Binding OrderNumber}"
            ElementStyle="{StaticResource SwiftExportDataGridTextBlock}"/>
        <DataGridTextColumn Header="匹配结果" Binding="{Binding MatchSummary}"
            ElementStyle="{StaticResource SwiftExportDataGridWarpTextBlock}"/>
    </DataGrid.Columns>
</DataGrid>
```

需要人工选择匹配结果或勾选行时，由页面明确可编辑列与绑定模式；不要通过样式自动发起 API 请求或执行 DTO 组装。

## 验证边界

独立 STA/WPF 验证会读取各移植资源、实例化命名及隐式样式、检查原生 DataGrid 行生成和选择、原生验证转换器，以及 Light／四种 HC 资源切换。另保留已有 Primary 按钮与资源生命周期回归。真实 Excel 内的键盘、鼠标、日期弹出日历、DPI、设计器预览仍需手工验收；编译和资源解析不代表这些场景已经通过。
