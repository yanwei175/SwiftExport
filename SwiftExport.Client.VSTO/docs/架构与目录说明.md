# VSTO 基础架构

## 定位

这是 .NET Framework 4.8、C# 7.3 的 Excel 插件。WPF 和宿主位于一个程序集，通过目录约束依赖。后续主要做只读单据查询、Excel 制单与少量导入；服务器业务门禁仍由 WebApi 执行。禁止直接连接数据库。

当前根工程总纲中“VSTO 已移除”的描述已过期，本目录以实际工程和本说明为准；未改变 .NET 10 客户端规则。

## 目录职责

| 目录 | 职责 |
|---|---|
| Bootstrapper | 显式读取配置、启动和停止、自有资源清理 |
| Ioc | 唯一服务注册入口，页面使用构造函数注入 |
| Hosting/Threading | 捕获 Excel STA，投递 UI／COM 操作 |
| Hosting/Windows | Owner、同键窗口复用、关闭 Scope |
| Hosting/TaskPanes | WinForms＋ElementHost 桥接，按窗口生命周期释放 |
| Authentication | 内存会话、加密 Token、候选登录、登录页面 |
| Api | Refit 创建、请求授权头、错误分类 |
| Mvvm | ViewModelBase 和项目扩展层 ViewModelBaseEx |
| Excel/Context | 从 Ribbon 获取所属 Excel 窗口 |
| Excel/Reading、Writing | 预留 Excel 快照读写职责，尚未实现业务 |
| Resources、UI/Themes、Assets | WPF 主题资源、预留主题扩展与素材 |
| Features/DocumentGeneration、DataImport | 预留业务目录，无空白页面入口 |
| Diagnostics | 有界日志，只记录固定事件与异常类型 |

## 生命周期和线程

Excel Startup 初始化服务、WPF 资源字典和已创建句柄的调度控件；缓存身份验证在后续消息轮次异步运行。WPF 和 Excel 共用 STA，不创建第二个顶层消息循环。资源承载 Application 采用 OnExplicitShutdown，但插件绝不调用 Application.Shutdown 或 Dispatcher.InvokeShutdown。

WindowManager 区分 Show 与 ShowDialog。需要同时操作 Excel 的工具使用 Show，Scope 随 Closed 释放；登录和切换账号使用 ShowDialog，不注册非模态键盘互操作。LoginCoordinator 在返回后的 finally 中释放 Scope、复位 IsOpen，显示失败和取消也经过同一路径；重复入口在 IsOpen 时被阻止。模态消息循环仍允许异步 HTTP 请求，禁止 Result／Wait。TaskPaneManager 保留窗口 COM 身份并定期核对实际窗口集合，避免仅凭可复用 HWND 或可取消 BeforeClose 清理。窗格隐藏不等于释放，窗口消失后释放；停止期间窗格集合交由 VSTO 最终销毁。

网络层不触碰 UI。状态通知可能来自网络线程，由 Bootstrapper 投递到 Excel STA 后更新 Ribbon。未来页面异步结果在 UI 接纳时核对页面存活及请求编号；不能通过 Task.Run 访问 COM。

## MVVM

继承链：Toolkit ObservableObject → ViewModelBase → ViewModelBaseEx → 页面。

ViewModelBase 仅提供标题、Busy、错误、命令刷新和 Dispose。ViewModelBaseEx 是未来增删项目行为的唯一扩展入口，首期不加空扩展点。Toolkit 的源生成器被排除，禁止 ObservableProperty、RelayCommand 特性和 partial property。手写属性使用 SetProperty，命令使用库的 RelayCommand／AsyncRelayCommand。

## 身份与配置

`vsto.config.xml` 随插件输出，ApiBaseUrl 默认 https://localhost:7286。部署时改成受信 HTTPS 站点根地址，不关闭证书验证，不读取或修改 Excel.exe.config。

启动有缓存时调用 /api/auth/me；没有缓存不发认证请求。只有验证成功才建立身份。Ribbon 登录、切换、退出均为显式入口，恢复时不弹窗。

切换使用独立候选令牌和 /me，成功才提交；取消、失败保留原账号。会话版本递增使旧请求无法回填或通过 401 清掉新账号。403 不退出，网络失败不删缓存，不自动重放写请求。

Token 按服务器 SHA256 分目录，在 LocalApplicationData/SwiftExport/Vsto 下 DPAPI CurrentUser 加密；命名互斥锁保护原子替换。多个 Excel 进程的内存身份互不自动同步；退出清理共享磁盘缓存不等于远端撤销 JWT。没有 Refresh Token 协议，过期需重新登录。密码不绑定到模型、不持久化。

Contracts 当前认证方法没有 CancellationToken 参数。关闭用生命周期令牌阻止迟到接纳，传输由超时结束，插件停止释放自有连接。该限制不等于可以让旧请求更新已关闭窗口。

## 新增一个功能

1. 在 Features/具体功能 下按 Views、ViewModels、Models、Services 放文件，传统 csproj 必须登记新增 Compile／Page 项。
2. ViewModel 继承 ViewModelBaseEx，注入 API 和所需宿主接口，不用 Globals 或服务定位器。
3. 在 Ioc 注册页面 Scope；Ribbon onAction 调用宿主入口，再交给 WindowManager。业务功能增多后再提取窄协调器，不把业务塞入 Bootstrapper。
4. 服务端 DTO 留在 Contracts；Excel 模板、列宽、坐标和打印设置留在具体 Feature。
5. 读取 COM 得到纯数组后才能后台计算；写回前重验目标，不重新使用 ActiveWorkbook 猜目标。
6. 按权限键控制按钮体验，服务端授权仍为最终依据。新增业务 API 从 ApiClientRegistration.Create 创建。
7. 补充功能对应测试和 Excel 人工验收，不迁入大型 CRUD 行状态框架。

## 构建

使用 Visual Studio 的 MSBuild：

```powershell
& 'C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe' SwiftExport.Client.VSTO\SwiftExport.Client.VSTO.csproj /restore /t:Build /p:Configuration=Debug /p:Platform=AnyCPU
```

测试项目链接纯托管生产源码，不加载 Office。构建通过不能替代 Excel 的 Ribbon、输入法、Owner、发布清单和关闭验收。

本机已按用户授权创建一年有效期的 `SwiftExport VSTO Development Only` 自签名证书，位于当前用户 My 证书存储区。工程只记录公开指纹，不保存或提交私钥。其他电脑需要在项目“签名”页选择本机开发证书，或构建时传入 `/p:ManifestCertificateThumbprint=证书指纹`。正式发布必须换成正式证书；开发证书不自动获得发布者信任。
