# 销售订单导入页（本地编辑阶段）

## 入口与能力

已验证登录后，从 Ribbon 的“数据导入 → 销售订单导入”打开非模态 WinForms 窗口，内嵌 `ElementHost` 承载原 WPF 页面。传入的首选尺寸为 1280×820，实际初始尺寸由所属显示器的可用区域调整；可手动调整大小并保持 Excel 可操作。每个 Excel 窗口有独立页面；重复点击激活原窗体，不重置编辑内容。页面只通过选区读取接口取得纯数组，不持有工作簿或 Range。

首次打开按需调用共享基础资料缓存，失败后点击“加载基础资料 / 重试”。Excel 启动、登录和账号切换不预加载；切换账号会清空内存草稿，需再次点击加载按钮。退出登录清空并禁用页面，成功重新登录后也须重新加载。

单头和明细读取已使用地址配置，检验通过后可以创建销售草稿；发票日期、发票更新日期未实现。ETD、ETA 和行交期可编辑。未保存内容只在内存中；读取期间禁止重复操作及普通关闭，其他时间关闭有编辑内容的窗体须确认。插件退出不弹阻塞确认，不停止 Excel。

## 编辑与数据来源

当前布局：客户、系统订单号、日期、交期、币种、汇率、客户 PO 和发票号常显；收货资料、贸易与运输资料、备注及 Excel 单头原文合并在一个“其他表头资料”Popup，不使用折叠面板。单个 OtherToggleButton 双向控制 IsOpen，EntryButton 指定该按钮，PlacementTarget 指定 HeaderStackPanel，弹层宽度跟随单头区域。StaysOpen=true 保持驻留，通过再次点击入口、关闭按钮或未被子控件处理的 Esc 关闭；点击普通外部区域不关闭。弹层仍绑定同一页面模型，关闭保留输入，内部字段流式排列，超出 400 高度后局部滚动。顶部常用操作直接显示，刷新配置、设计配置、加载资料／重试、重试原保存请求及开始新导入在“更多”菜单中。

销售包装数值仅作快照，不参与其他业务逻辑。Excel 净重、毛重、体积的跨行合并值已确认为多行合计：读取时保留原值到本地来源快照，但每箱净重／毛重／体积目标字段留空，并提示合并区域地址；型号、数量等其余字段继续读取，不增加包装分摊或保存门禁。普通未合并值仍正常赋值。其他字段的跨行合并检查及末行定位规则保持不变。

明细工具栏的“显示更多字段”开关默认关闭，控制英文颜色、英文配置、每箱数量／净重／毛重／体积及行备注。隐藏不清空值，也不跳过检验或保存；其余列保留横向滚动。重复的原表中性型号和包装列已去重，不删除任何不同字段。单头弹层内部有限高度滚动，打开不改变明细高度；宿主卸载时同时关闭弹层。

- 客户使用 `ReferenceData.Customers`，选择时把默认贸易条款、币种、收货名称／地址／电话复制到单头。收货名称取 CustomerName。更换或清空客户且存在明细时必须确认；取消恢复原选择，确认清空明细并采用新默认值。
- 币种来自独立币种缓存；付款方式、贸易术语、运输方式、非标单位分别来自 `DictCodes`。选项绑定实际字符串值，空选项表示清除。缓存中消失的正在编辑值作为页面自有选项保留并提示，不修改共享 DTO。
- 标准行 SKU 只能通过已有产品查询选择；搜索以当前客户为上下文，第一页 30 条，可继续输入缩小范围。切换产品回填客户型号、描述、颜色、配置、图片和报价，保留数量、交期和备注。无图片文件缓存。
- 查询没有返回标准产品单位，标准行单位只读且留空，不猜测单位或发起额外详情请求。非标行使用稳定 NS 编号，用户填写描述和单位。
- 数量大于零，价格允许空值或非负值，汇率大于零；非法文本保留并提示，不默认为零。USD 和 CNY 分别计算数量乘单价，不按汇率自动换算。金额显示两位小数，内部不提前取整。空值、非法值不贡献汇总，页面提示统计不完整；数量仅是输入统计，不用于跨单位履约判断。
- 删除按钮删除全部选中行；原生键盘删除关闭，统一由页面命令处理。日期、文本和选项允许手工修正。

## 代码组织与生命周期

`Features/Sales/Orders/Models`：单头与行编辑副本，使用手写 ObservableObject 属性和 IDataErrorInfo；不迁入 BaseLineModel、BaseListModel、脏行基线或服务器状态机。

`SalesOrderImportViewModel`：负责加载、编辑、汇总与会话；Options partial 管理候选快照，Search partial 管理具体行查询，Addresses partial 管理地址读取门禁、确认和结果接纳，Submission partial 管理检验与新建草稿。旧 Excel partial 已删除。每行命令绑定该行，接纳结果检查操作身份、会话版本、客户和行存续。产品提交直接使用控件命令参数，避免 DataGrid BindingGroup 延迟回写导致提交对象为空。

View 负责 DataContext、Loaded、多选桥接及将关闭检查转交 ViewModel。`ModelessElementHostWindowManager` 使用 Excel HWND＋页面键复用窗体，创建独立 Scope，并在 WinForms `ElementHost` 中承载页面。客户切换及普通关闭确认注入同一 Scope 的 `ModelessWindowContext`，由管理器在解析页面前暂设 Excel Owner、创建窗体后改为窗体 Owner；释放时清除句柄，ViewModel 不接触 HWND。窗体关闭后释放 Scope，插件退出跳过丢弃确认。搜索取消后不接受迟到结果，缓存和会话事件在 Dispose 中解绑。查询复用现有认证 Handler，403 保留身份，401 由全局会话处理。

API 只注册并调用现有 `ISalesOrderDetailApi.SearchProductsAsync`，路径 `api/sales-orders/detail/products/search`；虽然 HTTP 方法为 POST，语义是查询。本页未调用 Save、Confirm 或其他写接口，未修改 Contracts 和后端。
