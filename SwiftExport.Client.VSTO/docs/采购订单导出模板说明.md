# 采购订单导出模板

采购列表的“生成选中订单成 Excel”导出当前高亮行；“批量生成勾选订单成 Excel”仅导出当前页显式勾选的订单，每张订单生成一个 `.xlsx`。输出目录取点击时的 `OutputPath`，默认桌面，可手工修改；目录不存在时创建。用户已确认首期使用固定模板坐标，不反向使用数据库中的 ExcelReadProfiles。

## 导出职责

- `PurchaseOrderListViewModel` 冻结订单身份、目录和会话，维护按钮门禁及结果提示，不持有 COM。
- `Services/OrderExport/PurchaseOrderExportService` 串行调用现有 `IProcurementOrderApi.GetDetailAsync`，复用认证与错误管线；不新增 API、不获取 Customer PO Config、不重新定价。
- `PurchaseOrderExportDocument` 将完整详情复制为填充快照，按 `LineNumber` 排序并确定合计、备注及签字行。
- `Excel/Writing/OrderExport/PurchaseOrderWorkbookWriter` 在 Excel STA 创建自有工作簿、填值、保存和清理。
- `PurchaseOrderTemplateService` 沿用用户 VBA 的列宽、行高、合并、字体和打印布局，仅负责格式与固定标签；独立创建／重整格式入口仍可供后续调用。

导出不关闭用户工作簿，不结束宿主 Excel，不改窗口缩放、冻结或宿主计算模式；恢复原活动窗口、ScreenUpdating 和 EnableEvents。

## 数据填充

| 值位置 | 详情字段 |
| --- | --- |
| B2／B3／B4／B5 | CustomerCode／CustomerPoNo／BoNo（为空时 OrderNo）／SalesPerson |
| D2／D3／D4／D5 | OrderDate／ExpectedDate／ReplyDate／PurchasePerson |
| F2／F3／F4／F5 | SupplierName／InletHoseType／AeratorType／PalletType |
| H2／H3／H4／H5 | BoxType／LabelType／InstructionManualType／CartonType |
| J2:K5 | LogoType |
| B6:K6 | Remark |

第 9 行起按原行号填充明细：

| 列 | 显示标题 | 详情字段 |
| --- | --- | --- |
| A | 产品图片 | 始终空白，保留宽度与行高 |
| B | 客户型号 | CustomerSku |
| C | 本司型号 | LinkSku |
| D | 工厂型号 | SupplierSku |
| E | 描述 | DescriptionZh |
| F | 表面处理 | FinishZh |
| G | 配置 | FeaturesZh |
| H | 单价 | UnitPrice，CNY 未税快照 |
| I | 数量 | Quantity |
| J | 金额 | UnitAmount，CNY 未税快照 |
| K | 备注 | SubNote |

不读取或下载 MainImage，不插入 Shape，不建立图片缓存；图片留给业务员用 VBA 插入。明细采用 B:K 二维数组批量写入。型号、PO、备注等字符串先设为文本格式，保留前导零，并避免等号开头的内容成为公式。日期写入 Excel 日期值；数量和价格保持数值。当前模板仅接受 CNY，明确为其他币种时拒绝导出。

合计行 A:H 合并，I 为数量 SUM、J 为已知明细金额 SUM。零明细使用 `=0`，避免循环引用。金额全部为空时合计为空；部分金额缺失时只汇总已知金额，并明确提示“金额汇总不完整”。不把空价格填成零，不按汇率重新换算。不同或未知单位时，数量合计标注“数量统计”。

优惠倍率、整单优惠金额和优惠备注另列在合计之后，**仅作记录，不抵扣合计**。缺失快照提示也写入尾部，签字行位于这些备注之后。显式计算自有工作表，即使宿主处于手动计算模式，也保存正确的合计缓存。

## 文件及异步边界

文件名为 `采购单_采购编号_供应商.xlsx`，清理非法字符。同名文件添加 `_1`、`_2` 等序号，永不覆盖已有文件。先在目标目录保存唯一临时工作簿，关闭成功后用无覆盖移动发布；失败清理自有临时文件。

导出期间禁止重复查询／导出，输出路径只读。单张读取或保存失败记录原因并继续，完成后列出成功路径及失败说明。已经生成的文件不因其他订单失败回滚。

退出、换账号或释放页面会取消操作。接纳详情、创建文件及发布前检查会话与取消状态，旧响应不能继续导出或更新新账号页面。取消不会删除之前已成功导出的文件。权限沿用采购查看权限，服务端仍最终授权。

## 调用

由 Excel 适配层取得并持有明确的目标工作表，等待操作完成后再释放自己拥有的引用。ViewModel 不持有 COM 对象。

```csharp
// sheet 为调用方明确选定的新空白工作表，不在服务内推测 ActiveSheet。
await templateService.CreateTemplateAsync(sheet, detailCount, "诗亦霖卫浴订单明细表");
// 后续对相同结构重新调整格式，不改业务单元格值。
await templateService.ApplyFormatAsync(sheet, detailCount);
```

服务内部通过 `IExcelDispatcher` 执行全部 COM 操作。调用方应保证工作簿在等待期间保持打开，并负责处理失败。服务不创建、关闭或保存工作簿，不更改窗口缩放、冻结或选择，不修改 DisplayAlerts。不要在后台线程读取 sheet 的属性。

## 坐标

- 第 1 行：合并 A:K，标题右对齐；标题由调用方传入，不硬编码企业名称。
- 第 2～5 行：A/B 客户及采购信息、C/D 日期及跟单员、E/F 供应商及配件、G/H 包装；I2:I5 商标标签、J2:K5 商标内容。
- 第 6 行：A6 特殊要求，B6:K6 内容；第 7 行间隔。
- 第 8 行：产品图片、客户型号、本司型号、工厂型号、描述、表面处理、配置、单价、数量、金额、备注（A:K）。
- 第 9 行起：明细。合计行为 `9 + detailCount`，签字行为合计行 + 备注行数 + 1。独立空模板的备注行数为零。零条明细不强行插入示例行。
- 合计行合并 A:H，I/J 用于数量和金额；签字在 B/F/I 列。公式由工作簿写入器填充。

行高、A:M 列宽、字体、人民币格式及对齐沿用 VBA。灰色表头用固定浅灰以免受工作簿主题影响；格式仅作用于模板范围，列宽和行高按 Excel 特性作用于整列／整行。图片只预留 A 列，本期不插图、不调整已有 Shape。没有增加 VBA 未设置的自动筛选。

## 打印与保护

沿用 A4 纵向、1 页宽／纵向不限、四边 1mm、页脚页码、重复第 8 行。打印区域为 A1:K 签字行，包含动态尾部。打印精度沿用驱动默认值，不强制 VBA 的 1200 DPI。极小边距的纸张效果仍需实机确认；失败向上传递，不静默报告成功。

实际测试发现当前驱动在恢复批量打印通信时拒绝设置，因此打印设置直接提交，不切换宿主 PrintCommunication。未启用的首页／奇偶页独立页眉不额外修改。服务不使用 CurrentRegion 或查找“合计”推算末行。

创建入口发现目标区域已有值或公式即拒绝；格式入口合并前检查全部合并范围，冲突或非首格已有值／公式时拒绝，避免丢数据。支持对同结构重复应用格式；不负责增删行或迁移已有合计，列表导出每次建立新工作簿。Excel 格式修改没有事务回滚，打印阶段失败可能已完成部分格式；调用方应在自有新工作簿生成并成功后再保存，不对未知结构的用户订单直接调用。
