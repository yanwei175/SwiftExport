# WPF Theme Resource Guide

## 适用场景

适用于 WPF 主题、资源字典、控件样式、颜色、字号、布局间距和主题修复。

## 推荐做法

- 优先复用项目已有 ResourceDictionary、Style、Brush、Thickness 和控件模板。
- 页面局部样式应避免污染全局资源。
- 全局主题修改要评估所有引用该资源的页面。
- 资源命名应表达用途，而不是只表达颜色值。
- 主题修复应保持 UI 行为不变，除非任务明确要求交互变化。

## 禁止事项

- 禁止为了单个页面随意修改全局默认控件样式。
- 禁止在多个页面复制大段重复样式。
- 禁止把业务状态写进主题资源。
- 禁止无说明地改变字号、间距、对齐和控件高度。
- 禁止在不确认资源引用范围时重命名资源键。

## Codex 修改前检查清单

- 当前页面引用了哪些资源字典和第三方控件库。
- 样式是局部问题还是全局主题问题。
- 修改资源键是否影响其他页面。
- 是否需要截图或运行界面验证。

## 常见错误

- 在页面内联样式越写越多，无法复用。
- 修改全局 Button/DataGrid 样式导致其他模块布局变化。
- 使用颜色值命名资源，后续主题切换困难。
- 忽略暗色/浅色主题兼容。
- 没有记录主题修复影响范围。
