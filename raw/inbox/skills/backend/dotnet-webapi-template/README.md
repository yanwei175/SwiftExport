# dotnet-webapi-template

用于从 `templates/dotnet-webapi` 生成、同步或审查 WebAPI + Dapper + SQL Server 后端模板骨架。

## 适用场景

- 新建后端项目骨架。
- 对齐现有项目到 YanWei 默认 WebAPI 模板。
- 在生成 CRUD、Repository、Refit 契约前确认默认分层和上下文链路。
