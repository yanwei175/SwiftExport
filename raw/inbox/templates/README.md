# Templates 索引

项目模板放在本目录。模板负责项目骨架，不负责承载通用 Skill。

| 模板 | 说明 | 状态 |
|---|---|---|
| `dotnet8-wpf-communitytoolkit` | .NET 8 WPF CommunityToolkit MVVM 模板占位 | 待完善 |
| `dotnet-framework-wpf-mvvmlight` | .NET Framework WPF MVVMLight 模板占位 | 待完善 |
| `dotnet-webapi` | .NET Web API 模板占位 | 待完善 |
| `dotnet-small-erp` | .NET WPF 本地 ERP 模板，包含模板专属架构与重构文档 | 已迁移 |

## 维护规则

- 模板内部可以保留模板专属 `AGENTS.md`、`docs`、`src`。
- 模板中的通用能力应提炼到根目录 `skills`、`guides` 或 `examples`。
- 不确定内容先放到模板内部 `_review`。
