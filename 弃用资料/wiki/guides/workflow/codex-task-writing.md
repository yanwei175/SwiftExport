# Codex Task Writing Guide

## 适用场景

用于给 Codex 编写任务说明、迁移要求、重构约束、验收标准和分阶段执行流程。

## 推荐写法

- 明确目标、范围、禁止事项和完成后输出。
- 对高风险任务分阶段：先分析、再计划、确认后执行。
- 写清哪些文件或目录不能删除、不能移动、不能覆盖。
- 写清输出报告、索引、测试或验证要求。
- 对不确定内容要求标记 TODO 或待确认，不要强行归类。

## 检查清单

- 任务目标和成功标准是否明确。
- 是否说明了可改和不可改范围。
- 是否需要先扫描、先报告或等待确认。
- 是否有输出格式和报告路径。
- 是否说明构建、测试或人工验证要求。

## 常见错误

- 只写“整理一下”而不说明分类标准。
- 同时要求执行和等待确认。
- 没有区分 Guide、Skill、Workflow、Template、Example。
- 让 Skill 承载大量稳定规范，导致重复和难维护。
- 没有要求最终报告实际变更。
