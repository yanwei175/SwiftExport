# 弃用资料说明

本目录保存已经退出 SwiftExport 当前 Agent/Skill/Workflow 主链路的历史资料，仅用于必要时追溯，不作为实现依据。

## 当前正式入口

1. 根目录 `AGENTS.md`
2. `.agents/router.toml`
3. 命中的 `.agents/*.toml` 与 `.agents/workflows/*.md`
4. 命中的 `.codex/skills/**/SKILL.md`
5. 真实源码、调用方与测试

## 归档内容

- `wiki/**`：旧 Wiki、旧工作流和旧技能说明。
- `raw/**`：旧原始资料、收件箱、示例技能和模板。
- `_codex_handoff/**`：旧任务交接、冻结版任务书和历史路线图。

## 使用边界

- 默认不读取或引用本目录。
- 历史资料与当前源码、`AGENTS.md`、`.agents/**` 或 `.codex/skills/**` 冲突时，以当前源码和正式治理入口为准。
- 只有用户明确要求追溯历史决策、迁移旧规则或审计旧方案时才读取对应文件。
- 从本目录恢复内容前，必须重新核对当前分层、技术栈和业务状态，不得直接复制旧实现规则。
