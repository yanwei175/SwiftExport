# WPF Custom Controls Guide

## 适用场景

适用于 WPF 自定义控件、复合控件、搜索框、选择器和可复用 UI 组件。

## 推荐做法

- 控件负责交互和显示，不承载业务保存流程。
- DependencyProperty 命名、默认值、绑定模式和回调要清晰。
- 本地搜索、远程搜索、选中值、显示文本等行为应有明确边界。
- 可复用控件应提供模板、示例用法和注意事项。
- 控件内部注释和复杂状态切换应使用中文说明。

## 禁止事项

- 禁止控件直接调用业务服务、Repository 或数据库。
- 禁止把特定业务字段写死在通用控件里。
- 禁止选择结果时意外触发远程搜索循环。
- 禁止让控件依赖某个页面 ViewModel 类型。
- 禁止在没有测试场景的情况下修改复杂控件状态机。

## Codex 修改前检查清单

- 控件是通用控件还是某个页面的局部组件。
- 现有 DependencyProperty、事件、命令和模板是否已确认。
- 本地/远程搜索、失焦、清空、键盘导航等交互是否会受影响。
- 是否已有示例在 `examples/frontend-wpf` 中可参考。

## 常见错误

- 控件里写死业务 DTO 字段。
- 选中项显示和输入文本同步混乱。
- 未监听集合变化，远程搜索结果更新后下拉不刷新。
- 失焦时误清空已选值。
- 控件样式和逻辑耦合过深。
