# 后端风险测试矩阵

| 改动类型 | 最小验证 |
|---|---|
| DTO、枚举、Refit、Controller 路由 | Contracts/API 契约测试 + 后端 build |
| 标准 CRUD | 校验、Version、软删除、route/body identity + build |
| 查询或分页 SQL | 参数化、筛选、稳定排序、空值和分页边界测试 |
| 权限 | 未认证、无权限、有权限、拒绝路径零写入 |
| 复杂草稿保存 | 头行整体校验、Version、CommandId 重放/冲突、回滚 |
| 确认或取消确认 | 状态矩阵、权限、下游资格、并发冲突、审计与回执 |
| Preview/Post | Preview 零写入、Token/版本过期、提交重新校验、重放 |
| 库存过账 | 数量方向、余额守恒、流水唯一性、锁键顺序、失败回滚 |
| 反过账/红冲 | 原事实不变、反向关系、后续依赖阻断、重复反向拒绝或重放 |
| Entity/Schema/索引 | 元数据、生成 SQL、唯一/检查约束、Repository 列一致性 |

## 完成标准

- 报告实际运行的命令、结果和覆盖的风险。
- 未运行适用测试时说明环境或范围原因，不得声称已验证。
- 测试失败时区分实现缺陷、环境缺失、旧有失败和本次无关改动。
- 对数据库锁、死锁、唯一约束等无法由替身证明的行为，明确记录仍需真实数据库验证。
