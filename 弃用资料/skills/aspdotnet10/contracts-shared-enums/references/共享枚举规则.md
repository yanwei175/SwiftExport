# 共享枚举规则

## 使用规则

- API DTO 和前端页面共用的枚举放 Contracts。
- 枚举值应稳定，尤其是已入库、已序列化、已被前端绑定的枚举。
- 新增枚举要考虑显示文本、数据库存储、前端下拉、Refit 序列化。
- 删除或重命名枚举前先搜索全仓库引用。

## 状态枚举原则

- `OrderStatus` 类状态偏向展示和进度汇总。
- 业务流程判断不要只依赖单一状态字段。
- 确认、执行、过账、改单等应拆出明确状态或执行节点。

## 禁止事项

- 禁止在前端复制一份私有枚举。
- 禁止在 Core 新增前端需要的枚举。
- 禁止随意调整已有枚举数值。
- 禁止把 UI 文案类状态混入核心业务枚举，除非它确实是业务状态。
