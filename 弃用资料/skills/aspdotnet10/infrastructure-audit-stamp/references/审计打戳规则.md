# 审计打戳规则

## 当前源码事实

`AuditStampService` 位于 `SwiftExport.Infrastructure/Services/Auth/AuditStampService.cs`。

依赖：

- `ICurrentUser`
- `BaseEntity`

`RepositoryBaseContext` 聚合：

- `IAuditStampService AuditStamp`
- `ICurrentUser CurrentUser`

`DapperRepository<T>` 在：

- `AddAsync` 调用 `StampForInsert`
- `UpdateAsync` 调用 `StampForUpdate`
- `DeleteAsync` 手动写 `UpdatedDate` / `UpdatedBy`

## StampForInsert

新增前：

- `CreatedDate ??= now`
- `CreatedBy ??= currentUser.UserName`
- `UpdatedDate ??= now`
- `UpdatedBy ??= currentUser.UserName`

新增不覆盖已显式赋值的 Created/Updated 字段。

## StampForUpdate

更新前：

- `UpdatedDate = DateTime.Now`
- `UpdatedBy = currentUser.UserName`

更新必须覆盖最新操作人和时间。

## 禁止事项

- 禁止在 Controller 或 Application 中到处手写审计字段。
- 禁止 Infrastructure 依赖 WebApi 的 `CurrentUser` 具体类。
- 禁止把审计打戳和审批、确认、状态流转混为一谈。
- 禁止库存流水等不可变记录通过普通更新方式修改审计历史。
