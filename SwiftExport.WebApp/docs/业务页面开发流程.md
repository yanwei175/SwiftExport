# 业务页面开发入口

正式流程使用 [Web 工作流](../../.agents/workflows/Web前端工作流.md) 与 [Web Skill 入口](../../.codex/skills/react-web/index/SKILL.md)。本页不重写保存/关闭规则，只说明工程接入点。

1. 读取真实用例、端点、DTO、权限与证据。新增接入先走 [真实契约导出/审核投影及 Orval 命令](工程入口与命令.md)，权限引用生成 PermissionKey；不手写第二套 DTO/HTTP/权限清单。真实 Product 写入仍受 [契约门槛](../../docs/Web首批接口契约验收.md#product-recovery) 阻断，骨架模拟验收不解除门槛。
2. 在 feature 实现控制器/页面，明确字段 owner；使用 `WorkspaceTabProps` 的自身描述，不读取活动页全局身份。
   普通 Form 直接使用 Ant Form；列表复用 [公共编辑集合/表格及页面反馈](前端基础设施与使用入口.md)。头 Form+明细由同一 feature 会话统一校验/冻结/接纳，当前字段值不重复保存。按实际字段消费数值/日期转换、候选及 locateFieldIssues；原始缓冲、业务验证、保存回执和恢复材料仍归 feature，不复制验收模拟器作为业务协议。
3. 通过 `useWorkspaceTab` 注册稳定控制器与最新完整摘要，展示树经 `renderDisplay` 进入 Activity。保存调用 `ensureVisible` 等待明确握手；握手中断确认尚未派发，保留输入。
   新单完整成功回执接纳后通过 `updateBusinessIdentity` 更新业务 Uid；宿主保持 tabId，冲突保留两页。feature 保留已确认的实体/版本，不因定位冲突重新发送新增请求。
4. 在应用页面目录登记参数、去重身份、生成权限键和显式 lazy，布局导航引用该入口；读写权随 useSession 的当前 me 接线，不把恢复 Cookie 或客户端 IsAdmin 当作授权。后续有多个真实导航组时再按既定职责提取导航目录，不预建空清单。
5. 通过生成 HTTP 操作、queryKeys 的身份/permissionEpoch 范围和唯一请求执行边界接入。直接展开 queryPolicies 对应策略，透传 signal，根据 isActive/读取权及搜索词启停；初始化草稿和显式重载遵守 [公共设施基线](../../docs/Web客户端架构与脚手架决策.md#web-common-services)，后台快照不覆盖编辑会话。feature 核对真实 A/B/C 或已有行级回执。
6. 显示偏好只通过 useUserPreferences/PreferenceDataGrid 消费，用稳定 preferenceId 和当前列定义；分页变更仍先处理数据替换保护。诊断只传白名单元数据。首个文件/图片页需先接真实权限与生成读取/上传操作，定义 ObjectURL 释放及部分结果，现有恢复 JSON 不替代文件 adapter。
7. 选取实际类型、依赖、编辑与浏览器检查，核对最终整合版本，证据写入对应验收记录。恢复导出按各 feature 的真实材料和权限接入；验收页白名单只证明本地模拟内容。真实账号、业务库和发布另行验收，不由公共设施或文档同步宣称通过。
