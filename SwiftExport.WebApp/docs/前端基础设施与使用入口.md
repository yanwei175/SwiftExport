# 前端基础设施与使用入口

更新：2026-10-09。本页只说明当前源码入口及调用方式；会话、Query、偏好、诊断和编辑总规则引用 [公共设施基线](../../docs/Web客户端架构与脚手架决策.md#web-common-services)，保存/关闭/恢复引用 [多标签契约](../../docs/Web多标签工作区设计.md#workspace-contract)。工程接线与当前整合验收分开记录，基础设施不依赖先建设置或产品页面。

## 当前公共入口

| 能力 | 实际入口 | 页面如何使用 |
| --- | --- | --- |
| 主题、中文、反馈上下文 | [应用 Providers](../app/bootstrap/应用Providers.tsx) | 直接使用 Ant 控件；`App.useApp()` 取得 message、notification、modal，无第二套弹窗/消息服务 |
| 身份与精确权限 | [会话上下文](../app/shared/session/会话上下文.tsx)、[会话状态](../app/shared/session/会话状态.ts)、[权限检查](../app/shared/authorization/权限检查.ts) | useSession 消费恢复/重认证/退出状态与 me；PermissionKey 使用 [生成目录](../app/shared/authorization/generated/权限键.ts)，不自建角色授权 |
| HTTP 与生成客户端 | [请求执行](../app/shared/api/请求执行.ts)、[Orval 配置](../orval.config.mjs) | 调用生成操作并透传 signal；浏览器会话走 Cookie/CSRF，业务走内存 Bearer，feature 解释完整响应和写入结果 |
| 服务器缓存 | [QueryClient](../app/shared/query/查询客户端.ts)、[查询键](../app/shared/query/查询键.ts)、[queryPolicies](../app/shared/query/查询策略.ts) | queryKeys 使用 userId/identityEpoch/permissionEpoch 与操作/输入；直接展开 live/lookup/reference 原生策略，查询启停由活动状态和读取权接线 |
| 远程搜索防抖 | [useDebouncedSearch](../app/shared/query/useDebouncedSearch.ts) | 传搜索词及 isActive && authorized；300ms 后 isReady 才允许启用 Query，使用返回 value 构键，隐藏/撤权/新词取消旧调度 |
| 用户显示偏好 | [UserPreferencesProvider/useUserPreferences](../app/shared/preferences/用户偏好上下文.tsx)、[纯 store](../app/shared/preferences/用户偏好.ts)、[PreferenceDataGrid](../app/shared/ui/偏好表格.tsx) | Provider 内消费侧栏/列布局/分页偏好；用稳定 preferenceId 和当前声明列白名单，不持久化草稿；storageStatus 提示降级 |
| 轻量诊断 | [诊断记录](../app/shared/diagnostics/诊断记录.ts) | recordDiagnostic 只传固定事件和允许元数据；getDiagnosticSnapshot 供本地检查，clearDiagnostics 清身份上下文，不记录业务正文 |
| 页面驻留与保护 | [公共页签契约](../app/shared/workspace/页签契约.ts)、[useWorkspaceTab](../app/shared/workspace/useWorkspaceTab.tsx) | 注册最新保护摘要及唯一保存/放弃入口，展示通过 Activity 边界保留 |
| 页面状态 | [页面状态](../app/shared/ui/页面状态.tsx) | 呈现加载、空数据、错误、无读取权限；请求、重试动作和草稿保护由调用方提供 |
| 编辑集合 | [编辑集合](../app/shared/editing/编辑集合.ts) | 从单一集合派生增改删，新增/删除/恢复/局部回执接纳；Uid/Version 为元数据 |
| 未提交输入 | [未提交输入](../app/shared/editing/未提交输入.ts) | feature 持有短期缓冲并提供字段转换策略，判断无法转换或实际变化的输入保护 |
| 字段错误与数值/日期 | [字段错误](../app/shared/editing/字段错误.ts)、[数值转换](../app/shared/format/数值转换.ts)、[日期转换](../app/shared/format/日期转换.ts) | locateFieldIssues 由 feature 提供 Form/ClientKey/列映射；parseIntegerText/parseDecimalText/decimalTextToJsonNumber、parseBusinessDate/parseInstant 只转换，不改变后端契约 |
| 候选选择 | [LookupSelect](../app/shared/ui/候选选择.tsx) | 复用 Ant Select 的单选/多选；受控 value/searchValue，当前缺项保留显示，远程查询/信号/权限及防抖由 feature 提供，不静默清值 |
| 公共表格 | [SwiftDataGrid](../app/shared/ui/swift-data-grid/index.ts)、[PreferenceDataGrid](../app/shared/ui/偏好表格.tsx) | 受控 ProTable，传 rows、稳定行键、列及行勾选；单元格区域只发填充意图，原生列设置与列宽接已有偏好 |
| 高级表单及展示 | ProForm、EditableProTable、DragSortTable、ProDescriptions、ProList | 按场景直接复用公开组件；数据和唯一保存入口归 feature，不自建同类控件或启用组件 request/独立存储 |
| 恢复入口呈现 | [恢复操作](../app/shared/ui/恢复操作.tsx) | 放在保存状态旁，传入该 feature 的合法导出与人工终止动作；不自行判定或解除未知锁 |

业务字段校验、DTO 映射、保存编排及恢复材料白名单仍属于 feature。公共表格不请求 API，不存第二份业务当前值，不决定提交成功或解除锁。ProForm 复用原 Ant Form 实例，不建立另一份同步状态；控件复用和字段边界见 [表格与表单规则](../../docs/web-frontend-architecture.md#4-swiftdatagrid边界与首期能力)。

## 当前消费与边界

[验收 feature](../app/features/workspace-verification/验证页签入口.tsx) 已消费 ProForm、公共表格、编辑集合、原始输入保护和恢复区域。列表新增、删除、恢复、区域填充均只改变本地草稿；模拟回执逐项核对 ClientKey、操作、Uid/Version 后才接纳。新增行删除不形成后端删除，既有行删除后恢复保留删除前草稿及未完成输入。

表格提供分页序号、单元格单选/矩形区域、独立行勾选、表头列宽调整、原生列设置、文本/自定义编辑及错误关联。单击单元格后可用 Shift 或空白处拖动扩展选区，再向下填充；输入框内不抢 Ctrl+D。具体源/目标、整次校验和固定列宽规则只维护在上述表格规则。分页只发意图，调用方先处理数据替换保护，序号不作为 ClientKey。

结果未知的恢复区域位于编辑区之前。批量关闭遇到隐藏未知页会定位原页，仍不自动导出、放弃或执行人工终止。恢复导出、权限检查和两步确认使用现有 feature 实现，公共恢复组件仅呈现入口。

## 完成范围与后续接入

已有普通 Form、平面列表、字段映射、数值/日期转换和候选受控入口。单据头 Form 与多行明细使用同一个 feature 会话，按权威规则完成统一校验、冻结和回执接纳；公共函数不替单据解释事务结果。验收 feature 的保存仍是本地模拟，公共入口存在不代表真实单据协议已经接入。

文件/图片 adapter 尚未接入：在首个相关业务页前，先审核真实读取/上传契约并生成操作，再由 feature 接权限、成功/部分结果与 ObjectURL 释放。恢复 JSON 导出不属于文件上传服务。树与大数据虚拟化也按真实用例单独验收，不预建空插件框架。

下一业务模块沿用 [页面接入流程](业务页面开发流程.md)，再选择必要端点审核、Orval 生成和权限验收。Product 真实写入仍受 [后端契约门槛](../../docs/Web首批接口契约验收.md#product-recovery) 限制。Linux 实际构建、真实业务库及部署验证未由本轮完成。

当前检查与证据范围见 [骨架验收记录](骨架验收记录.md)。
