# 前端基础设施与使用入口

日期：2026-10-09。本页说明当前 Web 工程可以复用的入口，规则仍以仓库三份正式 Web 设计及既有工作流为准。基础设施不依赖先实现设置或产品页面；本轮没有接入设置页、扩充 API 快照或修改后端。

## 当前公共入口

| 能力 | 实际入口 | 页面如何使用 |
| --- | --- | --- |
| 主题、中文、反馈上下文 | [应用 Providers](../app/bootstrap/应用Providers.tsx) | 直接使用 Ant 控件；`App.useApp()` 取得 message、notification、modal，无第二套弹窗/消息服务 |
| 身份与精确权限 | [会话上下文](../app/shared/session/会话上下文.tsx)、[权限检查](../app/shared/authorization/权限检查.ts) | 消费当前 me；同用户重认证保留页签，换用户隔离草稿与缓存 |
| HTTP 与生成客户端 | [请求执行](../app/shared/api/请求执行.ts)、[Orval 配置](../orval.config.mjs) | 调用生成操作，信号及 Bearer 由唯一边界接入；业务结果由 feature 核对 |
| 服务器缓存 | [QueryClient](../app/shared/query/查询客户端.ts)、[查询键](../app/shared/query/查询键.ts) | 使用身份范围和规范操作键，缓存只保存服务器快照 |
| 页面驻留与保护 | [公共页签契约](../app/shared/workspace/页签契约.ts)、[useWorkspaceTab](../app/shared/workspace/useWorkspaceTab.tsx) | 注册最新保护摘要及唯一保存/放弃入口，展示通过 Activity 边界保留 |
| 页面状态 | [页面状态](../app/shared/ui/页面状态.tsx) | 呈现加载、空数据、错误、无读取权限；请求、重试动作和草稿保护由调用方提供 |
| 编辑集合 | [编辑集合](../app/shared/editing/编辑集合.ts) | 从单一集合派生增改删，新增/删除/恢复/局部回执接纳；Uid/Version 为元数据 |
| 未提交输入 | [未提交输入](../app/shared/editing/未提交输入.ts) | feature 持有短期缓冲并提供字段转换策略，判断无法转换或实际变化的输入保护 |
| 公共表格 | [SwiftDataGrid](../app/shared/ui/swift-data-grid/index.ts) | 传 rows、稳定行键、列和受控选择；接收输入、取消、分页、填充意图 |
| 恢复入口呈现 | [恢复操作](../app/shared/ui/恢复操作.tsx) | 放在保存状态旁，传入该 feature 的合法导出与人工终止动作；不自行判定或解除未知锁 |

业务字段校验、DTO 映射、保存编排及恢复材料白名单仍属于 feature。公共表格不请求 API，不存第二份业务当前值，不决定提交成功或解除锁。普通单对象 Form 直接使用 Ant Form，不再为其建立另一份同步状态。

## 本轮实际消费

[验收 feature](../app/features/workspace-verification/验证页签入口.tsx) 已消费公共表格、编辑集合、原始输入保护和恢复区域。列表新增、删除、恢复、单列填充均只改变本地草稿；模拟回执逐项核对 ClientKey、操作、Uid/Version 后才接纳。新增行删除不形成后端删除，既有行删除后恢复保留删除前草稿及未完成输入。

表格提供分页序号、稳定选择、文本编辑、数值原始输入及错误关联。Ctrl+D 仅在表格内有有效填充意图时处理，源为当前可见顺序的首个选中行，目标过滤不可编辑行；输入框内不抢快捷键。字段转换和填充校验由 feature 处理；分页只发意图，调用方先处理数据替换保护。序号不作为 ClientKey。

结果未知的恢复区域位于编辑区之前。批量关闭遇到隐藏未知页会定位原页，仍不自动导出、放弃或执行人工终止。恢复导出、权限检查和两步确认使用现有 feature 实现，公共恢复组件仅呈现入口。

## 完成范围与后续接入

当前公共能力支持普通 Form 和平面列表的首批页面开发；验收页是本地模拟消费，不是真实业务保存证明。日期/lookup 专用编辑、树和大数据虚拟化等没有伪称完成，也不预建空插件框架，按实际页面用例继续实现和验收。

下一业务模块沿用 [页面接入流程](业务页面开发流程.md)，再选择必要端点审核、Orval 生成和权限验收。Product 真实写入仍受 [后端契约门槛](../../docs/Web首批接口契约验收.md#product-recovery) 限制。Linux 实际构建、真实业务库及部署验证未由本轮完成。

当前检查与证据范围见 [骨架验收记录](骨架验收记录.md)。
