# 目录职责与依赖规则

规则正文见 [架构决策](../../docs/Web客户端架构与脚手架决策.md)。本页只对应当前实际文件：

| 路径 | 当前职责 |
| --- | --- |
| app/root、routes、bootstrap | Framework 文档/路由、启动组合、应用 Providers |
| app/layouts | Web 工作区布局、导航与账户入口；Ant App 提供反馈上下文 |
| app/workspace | 页面目录、稳定描述与地址、关闭/离开协调、Activity 展示握手 |
| app/features/auth | Ant Form 登录及初次登录页面；会话策略由 shared/session 接线 |
| app/features/home | 首页已接入入口说明 |
| app/features/workspace-verification | 明确启用的两个编辑验收页，模拟保存/回执与未知记录保全，不是业务实现 |
| app/shared/api | 唯一 Orval Fetch mutator、HTTP/网络事实；generated 只经工具生成 |
| app/shared/session、authorization、query | 内存会话、精确权限键、唯一服务器缓存与身份查询键 |
| app/shared/workspace | feature 使用的公共参数与关闭控制契约 |
| app/shared/editing | 基线隔离、单一增改删集合、删除恢复/局部接纳及未提交输入保护的纯算法 |
| app/shared/ui | 标准页面状态、恢复入口呈现及受控 SwiftDataGrid；不请求 API 或持有业务草稿 |
| tests | 真实配置违例检查、纯状态、Chrome 生命周期回归 |

逻辑依赖为应用组装 → feature → shared。ESLint 使用实际解析路径拒绝 shared 反向引用、跨 feature 内部引用和 feature 导入工作区实现；测试用真实禁止样例核对规则。业务页只能从 shared 获得注入意图。

Form 字段当前值只在 Form；列表当前值只在编辑集合。原始单元格缓冲在 feature 会话中保留；Workspace 只接收完整保护摘要与回调，不持有草稿。Activity 只包展示，注册、原始输入和保存回执位于外部控制器。

当前只登记已实现页面，不预建产品/订单等空模块；`WPF ShellWindow` 仅作导航与交互需求参考，没有引入 ViewModel 继承或窗口服务。主动退出经 Web 完整守卫，避免复制桌面当前直接清理的行为。

公共能力的当前实现与消费范围见 [前端基础设施与使用入口](前端基础设施与使用入口.md)。
