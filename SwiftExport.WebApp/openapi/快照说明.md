# 首批接口快照

初始 `首批接口.json` 原样复制自仓库 `_tools/Web契约验证/openapi.json`，对应 2026-10-07 的首批 HTTP 契约验收范围。当时 SHA-256 为 `B2EF287A3B5033598F1ABF47872863B542664728DDB141BFB85BE8B3136A5C59`，复制时与源文件逐字节一致；该哈希不代表后续更新后的快照。

当前快照由 [审核清单](已审核端点.json) 从真实 HTTP 宿主导出的完整 Swagger 投影，包含 15 个操作及其 schema 引用闭包。2026-10-09 新接入字典类型读取、类型批量保存和字典项批量保存，复用已有 by-code 读取。三项管理端点的后端 Swagger 未提供 operationId；清单第四项 `web-alias` 明示仅在 Web 投影赋予稳定生成方法名。已有后端 ID 不得覆盖，端点、请求、响应和认证描述不补造；新增未描述的失败状态仍由 feature 根据运行事实保守解释。具体来源与验收见 [字典接入记录](../docs/字典管理接入与验收.md)。

Web 项目独立消费此快照，用锁定的 Orval 8.40.0 和项目 `orval.config.mjs` 生成 `app/shared/api/generated/client.ts`。`npm run generate:check` 重新生成并检查字节差异，不依赖后端源码或工具目录在场。

保留 HTTP 状态联合类型、路径参数编码、裸登录/me DTO 及其他端点的完整响应。生成操作通过唯一 mutator 接入 `shared/api/请求执行.ts`，该层不判断业务写入成功或回滚。

快照包含 Product 保存描述，不解除其真实写入门槛：当前失败分支的稳定生效分类、结果查询/幂等能力及真实 PostgreSQL 验收仍按正式契约报告安排。此处不新增后端能力，也不把模拟 Fetch 测试当真实后端或浏览器证据。
