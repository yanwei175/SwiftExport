## API

~~~text
api/sales-orders/workspace
~~~

已实现：

~~~text
POST /api/sales-orders/workspace/search
GET  /api/sales-orders/workspace/{uid}
POST /api/sales-orders/workspace/products/search
POST /api/sales-orders/workspace/customers/search
POST /api/sales-orders/workspace/save
POST /api/sales-orders/workspace/{uid}/confirm
POST /api/sales-orders/workspace/{uid}/cancel-confirmation
POST /api/sales-orders/workspace/{uid}/close
POST /api/sales-orders/workspace/{uid}/delete-draft
~~~

Controller 只负责 HTTP 边界并转发到
ISalesOrderWorkspaceService / SalesOrderWorkspaceService。保存、确认、取消确认、
关闭和草稿删除均由 Application Service 开启事务。

## 状态模型

- SalesOrderDocumentStatusEnum：Open、Closed。
- ConfirmationStatusEnum：待确认、已确认。
- SalesOrderFulfillmentStatusEnum：根据活动毛需求的发货数量查询计算，不持久化到订单头。
- SalesOrderStatusEnum 已从有效新链路删除。
- 旧数据库列 `OrderStatus / ApprovalStatus / VersionNo / IsLocked` 已删除。

## 保存规则

- 新单号只由 DocumentNoService 生成，格式规则继续由单号服务管理。
- 更新订单不会采用客户端提交的 OrderNo。
- 只允许保存 Open + 待确认 的订单。
- 请求必须显式提交所有保留行，并通过 DeletedLines 提交删除行的 Uid + Version。
- 头、更新行和删除行均校验 Version；任一写入失败会回滚整个事务。
- 服务端按请求中有效行的顺序重排行号 1..N。
- 标准行必须关联有效 Product；可选 CustomerProduct 必须属于当前客户和产品。
- 客户货号、描述、颜色、规格及 CNY/USD 单价作为订单历史快照保存。
- 非标行禁止关联 Product/CustomerProduct，也不能与标准行原地互换。
- 非标 SKU 固定由行 Uid 生成：非标件-{Uid前12位大写N格式}。
- 行 CNY/USD 金额分别按对应单价乘数量重算。
- 头本币金额汇总 CNY；订单币种为 CNY 时原币也汇总 CNY，否则汇总 USD。

## 确认与取消

确认使用唯一来源值：

~~~text
SourceType = "SO"
~~~

每个活动订单行只允许一条活动 IndependentDemand。新建毛需求直接设置：

~~~text
OrderStatus = 已确认
ConfirmationStatus = 已确认
IsDecomposed = false
~~~

确认过程不执行 BOM 拆解。重复确认返回幂等成功，不新增第二条毛需求。
如果历史数据存在重复毛需求或无法对应当前订单行，服务会阻止确认并要求先清理数据。

取消确认前检查：

- 毛需求拆解标记。
- 已填充、已发货等执行数量。
- DependentDemand 净需求。
- PackingListLine.SoLineId 出货关联。
- PurchaseReceiveLine.SoLineId 收货关联。

存在任一阻断项时整笔拒绝。允许取消时软删除本订单的活动毛需求，并将订单恢复为待确认。

## 关闭与删除

- 任意 Open 订单可关闭，关闭原因必填且最多 1000 字符。
- 关闭持久化 CloseReason / ClosedDate / ClosedBy，保留订单与全部历史。
- 草稿删除只允许 Open + 待确认，软删除订单头和全部活动行。
- 已生成活动毛需求的订单不能作为草稿删除。

## Repository

- SalesOrderHeadRepository：工作区分页、详情头、状态更新、关闭和草稿删除。
- SalesOrderLineRepository：详情行、保留客户端 Uid 新增、批量更新、版本软删除和行号预处理。
- ProductRepository：销售产品分页；有 CustomerId 时只返回该客户的活动 CustomerProduct。
- CustomerRepository：销售客户分页和默认贸易/收货字段。
- IndependentDemandRepository：来源锁定查询、确认同步、取消阻断和来源软删除。

关键词沿用 SqlLikePattern：空格匹配任意多个字符，? 匹配单个字符，
其他字符按普通文本处理。
