# 成品需求与交付的当前边界

核对日期：2026-10-06。本文整篇替换旧阶段计划，描述当前调用链及边界，不提供自动重构或开发授权。

SourceDemandReceptionService参加销售/售后父事务，接收带来源版本的SO/CR要求。同版本不同内容拒绝，较旧版本拒绝覆盖；较新内容发生变化须核对下游处置。

退出已调用IMaterialDemandSourceExitService取得NetDemand历史证明，再调用ISourceDeliveryService.VerifySourceExitAsync核对有效箱单草稿、正式交付及对应库存单据历史。无物料历史硬删除来源，有完整安全回退历史作废；证明缺失仍失败关闭。

SourceDeliveryService已提供查询、事务内交付额度复核与来源退出，正式交付聚合来自PG仓储。VerifyClosureAsync仍明确失败，售后正数量结案也仍阻断；退出安全不等于交付完成证明。
