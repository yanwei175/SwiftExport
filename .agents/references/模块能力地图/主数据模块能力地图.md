# 主数据模块能力地图

核对日期：2026-10-06。本文描述当前工作树实现，不沿用旧阶段计划或以历史测试代替当前验收。业务判断以所列服务、实体和实际调用方为准；新增业务规则须另行确认。全部 HTTP 入口见[业务 API 索引](../../../docs/业务API索引.md)，跨域主线见[业务总纲](../业务架构总纲.md)。

## 职责与事实

主数据维护产品、主型号、中性资料、分类/颜色、客户、供应商、双方产品对应及客户采购默认配置。Product 保存真实库存/交易产品身份、单位、供货方式、BOM 绑定和默认值；ProductMaster、ProductNeutral、ProductDetail、ProductPackage 按现有实体分担资料。客户/供应商产品是对应关系，不是独立库存维度。

## 当前能力

| 能力 | Application 入口 | 页面/契约 |
| --- | --- | --- |
| 产品查询、批量维护 | ProductQueryService、ProductMaintenanceService | IProductApi；Products、ProductDetail，编辑模型在客户端 |
| 默认供应商 | ProductDefaultSupplierService | 默认建议值，不替代实际采购输入 |
| 主型号、中性资料 | ProductMasterQueryService、ProductMasterMaintenanceService、ProductNeutralQueryService、ProductNeutralBatchMaintenanceService | 独立 API 与管理页面 |
| 分类、颜色 | ProductCategoryService、ProductColorService | 分类树、维护及引用删除边界 |
| 客户、供应商 | CustomerService、SupplierService | 管理 API/页面；IsActive 与 IsDeleted 分开 |
| 双方产品对应、客户 PO 默认配置 | CustomerProductQuery/MaintenanceService、SupplierProductQuery/MaintenanceService、CustomerPoConfigService | 对应 API、管理页面和采购使用场景 |
| 执行资格/采购候选资料 | ExecutionEligibilityService、ProcurementMasterDataQueryService | 窄查询接口，复用现有身份/启停/单位校验 |

## 当前边界与限制

产品单位允许资料阶段为空；新增/更改明确单位按有效 Unit 字典归一化，历史交易仍使用 UnitSnapshot。当前 BOM 绑定保存有专门共享图校验；不能通过普通产品更新绕开组成边界。默认仓库、制造商字段已在 Product，不应按旧提示词重复新增。

主数据查询、维护和具体执行准入是不同职责；停用后的既有单据是否可继续要读取对应执行服务，不能写成所有流程一律拒绝或一律放行。编码、主数据单位冻结、生命周期能力只按实际公开入口认定；不要把旧“专用更名/恢复治理目标”当已存在命令。保存历史快照，不用名称匹配替代稳定 Uid。
