# 库存模块能力地图

核对日期：2026-10-06。本文描述当前工作树实现，不沿用旧阶段计划或以历史测试代替当前验收。业务判断以所列服务、实体和实际调用方为准；新增业务规则须另行确认。全部 HTTP 入口见[业务 API 索引](../../../docs/业务API索引.md)，跨域主线见[业务总纲](../业务架构总纲.md)。

## 职责与事实

WarehouseSite 是仓库身份；InventoryBalance 是 WarehouseSiteId+ProductId 当前余额；InventoryLedgerEntry 是不可变数量事实，保存来源、CommandId/CommandItemId、序列和历史快照。库存不增加客户或销售订单余额维度，客户交付净额属于 Shipping。

## 当前能力

| 能力 | 后端 | 消费者 |
| --- | --- | --- |
| 仓库列表、详情、选择器、候选 | WarehouseQueryService、WarehouseCandidateQueryService | IWarehouseSiteApi；仓库页与采购/入出库候选 |
| 新建供应商虚拟仓、编辑、启停 | WarehouseManagementService | 明确管理命令，不通过泛型 CRUD 破坏活动仓唯一性 |
| 余额、流水、Trace | InventoryQueryService | IInventoryApi；InventoryBalance、InventoryLedger、Trace 页面 |
| 普通过账、反向、原子纠错 | InventoryPostingService | 入库/出库/自动单据内部调用；不是页面直接余额写入 |
| 跨命令资源准备 | IInventoryPostingPreparation 对应 PG 实现 | 稳定库存键及命令资源声明，参加最外层事务 |

## 关键规则

活动供应商虚拟仓按供应商/类型约束唯一，不能重复创建同一活动身份；活动编码也受唯一约束。候选依使用目的、实际产品/供应商及权限判断，存在仓不等于当前业务可使用。

库存流水只新增；反向记录 ReversalOfLedgerId，纠错使用 ReplacementOfLedgerId/CorrectionGroupId。只有实际校验和调用路径允许的受控命令可形成纠错，不因实体支持就宣称各单据都有纠错页面。统一过账核对单位、幂等指纹、余额和禁止负库存；失败不保留部分行。序列可能因事务回滚留缺口，不能以连续序号作为正确性条件。

主数据单位与历史单位快照分开；不能用现时产品字段覆写旧流水。期初枚举和底层入账支持不等于已有公开期初页面；真实可见入口以导航与 Controller 为准。
