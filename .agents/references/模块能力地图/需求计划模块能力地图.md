# 需求计划模块能力地图

核对日期：2026-10-19。本文描述当前工作树实现，不沿用旧阶段计划或以历史测试代替当前验收。业务判断以所列服务、实体和实际调用方为准；新增业务规则须另行确认。全部 HTTP 入口见[业务 API 索引](../../../docs/业务API索引.md)，跨域主线见[业务总纲](../业务架构总纲.md)。

## 职责与事实

GrossDemand 表达来源实物要求及生命周期；NetDemand 保存一次拆解形成的物料事实、根子关系和 DecompositionRevision；DemandExecutionLink 保存物料到采购行的贡献，三者不是同一状态对象。来源接收仅接受 SO/CR；手工来源有独立维护入口。

## 当前能力与交接

| 能力 | 实现 | 消费者与边界 |
| --- | --- | --- |
| 来源事实列表、分组、详情 | GrossDemandQueryService | IGrossDemandWorkspaceApi；GrossDemandWorkspace 负责事实查询和独立需求维护，普通列表分页，选定来源全量加载 |
| 成品需求下游跟踪 | OrderTracking 查询切片 | 成品需求工作区、物料追踪和采购追踪统一跳转订单跟踪明细；按订单跟踪及各下游维度权限读取，不再提供旧 GrossDemand Trace 接口 |
| 手工来源维护 | ManualGrossDemandService | ManualGrossDemandController，不能改销售/售后拥有的来源事实 |
| 外部来源确认/退出 | SourceDemandReceptionService | 销售与售后外层事务；物料历史证明由 IMaterialDemandSourceExitService，交付退出由 ISourceDeliveryService |
| 建立物料 | MaterialDemandEstablishmentService | Establish 命令；串行化事务核对来源版本、依据指纹及当前共享组成 |
| 物料列表、来源 | MaterialDemandQueryService、MaterialDemandSourceQueryService | INetDemandManagerApi；NetDemandManager；来源导航按来源身份及已应用生命周期完整取数，主列表分页 |
| 物料下游跟踪 | OrderTracking 查询切片 | 物料工作区及采购追踪跳转现有订单跟踪明细；旧 MaterialDemand Trace 接口及页面退役，各下游维度独立授权 |
| 推荐供应商 | MaterialDemandSupplierSuggestionService | 推荐值不代替实际采购供应商；独立更新命令 |
| 安全回退 | MaterialDemandReversalService | 按成品需求整批回退活动物料修订，保留历史；存在执行占用时返回可定位且按权限脱敏的阻断原因，不得删除历史来伪造未执行 |
| 来源交付列表/单项 | Shipping.SourceDeliveryService | ISourceDemandDeliveryApi；Shipping 拥有正式交付聚合，不由来源写回完成数 |

## 2026-10-20 采购数量调整（已提交并合并原目录，未推送）

草稿仍保留物料需求来源关系与占用，只有确认后的采购才计入已采购。需求查询分别提供已采购、草稿占用、未采购、可创建草稿量；旧关联量仍代表总承接，不能改名冒充已采购。草稿引用仍阻断物料修订回退，取消确认不释放占用。占用草稿的身份及单号按采购读取权限提供，必要数量摘要保持原物料查看权限边界。订单跟踪的正式采购摘要和关注筛选按已确认采购口径更新，不跨单位累加。此段为已批准目标，最终实现与验证以本轮交付证据为准。

## 数量与退出规则

GrossDemandDecompositionPlanner 当前只展开直接客供件，根及子件的 NetQty 为来源/组成计算值，没有自动扣减库存或在途的 MRP 净算。非标来源生成无 ProductId 的采购型根物料；生产根包含客供件时明确不支持。

采购创建草稿同事务建立 PO Link；有效贡献为 AllocatedQty-ReleasedQty。取消确认保留来源占用，删行、整单删除草稿或作废才按采购规则释放。来源退出已组合物料历史与 Shipping 证明：活动修订、历史不完整、有效 PackingList 草稿或正式交付均可阻断。没有物料历史的来源硬删除，安全回退历史的来源作废；原 DP-009“交付核验未接入”不再是当前事实。

物料修订的实物适用性以非空、精确相等的需求依据指纹判断，并保留来源身份、生命周期与完整性校验；建立时的技术版本快照用于追溯，不能单独作为指纹未变时的失效依据。正式命令仍以请求中的当前版本防止并发覆盖。

物料查看权限允许读取必要承接摘要；采购单号、实际采购供应商及相应筛选需要采购查看权限。交期提示仅表示未承接风险，不表示采购或收货完成；无可信数量不显示为零。推荐采购供应商不替代实际采购供应商。

仍没有通用的已执行需求减量/商业终止处置用例；不能把纠错安全回退改称这类业务变更。来源和物料页面只执行自身命令，采购创建属于采购领域。
