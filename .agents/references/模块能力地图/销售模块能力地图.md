# 销售模块能力地图

核对日期：2026-10-18。本轮销售事实拆分已在开发工作树实现，尚未合并或部署。本文描述开发工作树实现，不沿用旧阶段计划或以历史测试代替当前验收。业务判断以所列服务、实体和实际调用方为准；新增业务规则须另行确认。全部 HTTP 入口见[业务 API 索引](../../../docs/业务API索引.md)，跨域主线见[业务总纲](../业务架构总纲.md)。

## 职责与事实

销售保存客户订单、价格和明细快照；确认把实物要求交给成品需求，销售查询不直接生成采购、库存或 PackingList。权威实体是 SalesOrderHeader、SalesOrderLine；订单自身 Open/Closed 与待确认/已确认独立保存。管理列表与详情只读取订单事实和商业快照，不再查询或展示履约数量与交期预警。

## 当前能力与调用链

| 能力 | 后端实现 | 契约及消费者 |
| --- | --- | --- |
| 列表、详情 | SalesOrderQueryService | ISalesOrderManagerApi、ISalesOrderDetailApi；SalesOrderManagerViewModel、SalesOrderDetailViewModel |
| 草稿保存、删除 | SalesOrderDraftService | Draft Controller、详情编辑；保存保留服务的版本与状态约束 |
| 确认、取消确认 | SalesOrderConfirmationService、SalesOrderCancellationService | Confirmation Controller；确认使用 ISourceDemandReceptionService，取消须先取得来源退出证明 |
| 关闭 | SalesOrderLifecycleService | 独立生命周期命令、原因和版本；调用 ClosePendingAsync，存在活动物料或交付阻断时拒绝 |
| 独立履约查询（保留后端） | SalesFulfillmentQueryService | ISalesFulfillmentApi；旧 WPF 页面、菜单和销售管理入口已移除，不提供过渡入口，未来订单跟踪待另行开发 |

## 关键边界

确认必须有有效明细和 UnitSnapshot；已确认重放不能绕过来源版本一致性。来源接收、订单状态、业务审计及命令回执参加同一最外层事务。关闭保留历史，不自动撤销采购或库存；当前没有销售恢复、商业修订或行级终止的公开命令，不能把旧规划当现有功能。

页面路由要求 Sales.Order.View；写操作使用草稿、确认和生命周期各自权限，详情不能仅凭可见性判断可操作。实际键和端点映射见 EndpointPermissionFilter、PermissionKeys。

## 销售事实拆分与默认交期

字段、契约、目录和验收范围见[销售管理事实查询拆分方案](../../../docs/销售管理事实查询拆分方案.md)。列表保留发票号；行保留图片、产品、客户型号、中性型号及必要快照。客户代码使用 MultiSelectLookupButton 多选。订单数量仅按整单有效行及单位完整性汇总，不受来源或交付核实影响；有效交期只用于选单，不截断整单合计。

系统参数 Sales.DefaultDeliveryDays 初始60个自然日，新建且未指定交期时在首次保存事务内按订单日期计算并持久化；显式日期优先，既有订单及历史空交期不重算。行空交期继承头交期。原有生命周期保护、权限及命令重放保持。WPF与VSTO销售查询消费者同步迁移。
