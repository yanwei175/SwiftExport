# 数据模型与状态规则

核对日期：2026-10-06。模型以 Core/Entities 和 Contracts/SysEnums 当前定义为准，本文件不提出新增表或通用状态架构。

## 身份、约束与历史

Uid 是技术身份，业务编码及当前唯一索引保障具体局部不变量。关联使用稳定 Uid；编码/名称/单位等交易快照表达发生时事实。IsActive、IsDeleted、单据生命周期和过账分别解释，不将任一标志替代所有准入校验。跨表关系是逻辑外键，由用例校验，生成器不建物理外键；数据库 CHECK、唯一键和不可变规则继续有效。

## 核心实体关系

| 事实 | 当前关联及责任 |
| --- | --- |
| SalesOrderHeader/Line、AfterSalesHeader/Line | 头行及快照由所属领域维护；确认调用来源接收 |
| GrossDemand | SourceType/SourceUid/SourceLineId、SourceVersion、DemandBasisFingerprint及自身LifecycleStatus |
| NetDemand | GrossDemandId、RootNetDemandId、ParentNetDemandId、DecompositionRevision和采用快照 |
| DemandExecutionLink | NetDemandId到TargetHeadId/TargetLineId，PO有效贡献AllocatedQty-ReleasedQty |
| PurchaseOrderLine | 实际数量、单位和价格；UnlinkedQty允许独立未关联部分；确认状态在头 |
| Inbound/OutboundDocumentLine | 来源身份与实际库存数量；自动单据TriggerPackingListId保持归属 |
| PackingListLine | GrossDemandId及交付数量；正式执行依据由PostingExecution/Line保存 |
| InventoryBalance | WarehouseSiteId+ProductId余额投影 |
| InventoryLedgerEntry | 不可变增减、序列、来源和单位快照；ReversalOfLedgerId/ReplacementOfLedgerId/CorrectionGroupId支持受控反向/纠错 |
| SysUser/SysRole/SysUserRole/SysPermission/SysRolePermission | 当前扁平RBAC五实体，RoleCode/PermissionKey为稳定身份 |

PurchaseConfirmationLine/Node仍有历史实体定义，但当前采购确认不创建新节点。实体存在不是活动业务写链证明。没有 NetDemandAllocation 或旧计划命令日志的活动实体，不能从旧 ER 图恢复这些表。

## 实际状态定义

| 对象 | 枚举/字段 | 已定义状态 |
| --- | --- | --- |
| 销售单 | SalesOrderDocumentStatusEnum | Open=0、Closed=9 |
| 确认 | ConfirmationStatusEnum | 待确认=0、已确认=1 |
| 来源 | GrossDemandLifecycleStatusEnum | Active=0、Closed=8、Voided=9 |
| 物料 | NetDemandLifecycleStatusEnum | Active=0、RolledBack=8、Voided=9 |
| 采购 | PurchaseOrderLifecycleStatusEnum | Active=0、Closed=8、Voided=9 |
| 库存单据生命周期 | InventoryDocumentLifecycleStatusEnum | Active=0、Closed=8、Voided=9 |
| 入库/出库/箱单过账 | 对应PostingStatusEnum | Unposted=0、Posted=1、Reversed=8 |
| 箱单生命周期 | PackingListLifecycleStatusEnum | Active=0、Closed=8、Voided=9 |
| 售后通用单据状态 | DocumentStatusEnum | Open=0、Closed=8、Voided=9 |

枚举存在不证明每个转换都有公开命令；例如销售没有恢复命令。履约、采购收货和物料执行进度是查询投影，不据此自动关单或覆盖原始状态。

## 历史与数量边界

流水不能普通修改/删除；错误通过受控反向保留原事实。来源无物料历史可在安全取消确认时硬删除，有安全回退历史则作废。物料回退保留修订。BomVersion是有效性标记，拆解修订是采用历史；当前BOM修改不重算旧执行。

当前本位币切换把全部RateToBase设为1并提示用户重设；并不放宽非空约束。单位链使用原单据/来源/库存UnitSnapshot，不以当前产品单位补写旧事实。
