# SwiftExport ERP 业务架构总纲

核对日期：2026-10-06。本文从当前工作树重写，描述现有业务代码和接线。过往阶段计划、待实施方案与旧偏差编号不作为现行实现说明；本次整理没有改变业务规则。具体方法、数量和状态准入仍以源码为准。

## 系统与权威事实

当前后端为 ASP.NET Core / .NET 10、PostgreSQL、Dapper；主客户端为 .NET 10 WPF + CommunityToolkit.Mvvm，另有 Excel VSTO。Infrastructure DI 已使用 PostgreSqlConnectionFactory、PostgreSqlDapperRepository 和各 PG 专用仓储。源码存在或已编译不代表任意业务组合、数据库部署和客户端操作已验收，实际测试事实保留在各结果记录。

| 模块 | 权威业务事实 | 当前边界 |
| --- | --- | --- |
| 主数据/BOM | Product 等资料、当前共享 BomNo 组成 | 默认值和身份维护，不直接改历史交易或库存 |
| 销售 | SalesOrderHeader/Line | 草稿、确认、取消、受控关闭、只读履约 |
| 售后 | AfterSalesHeader/Line | 服务事实、补发要求、确认/取消、受控生命周期 |
| 成品需求 | GrossDemand | SO/CR/手工实物要求、来源版本及自身生命周期 |
| 物料需求 | NetDemand | 采用时组成、根子关系、拆解修订及供应商建议 |
| 采购 | PurchaseOrderHead/Line、PO DemandExecutionLink | 实际供货承诺、来源贡献、确认/反向、收货资格 |
| 入出库 | InboundDocument/Line、OutboundDocument/Line | 单据库存事实，人工和箱单触发自动单据分开 |
| 库存 | InventoryBalance、InventoryLedgerEntry | 仓库+产品余额，不可变流水和受控反向 |
| Shipping | PackingListHead/Line、PostingExecution/Line | 来源交付额度、正式交付净额、箱单执行证据 |
| 系统 | RBAC 五实体、字典、币种、Excel配置、号段 | 认证授权、基础配置及明确管理命令 |

## 正向与反向主链

销售或售后确认调用 SourceDemandReceptionService，在父事务中形成 GrossDemand。MaterialDemandEstablishmentService 核对来源版本及指纹，读取一致的当前共享 BOM，形成根及直接客供件 NetDemand。采购从物料建立草稿及 PO Link，也允许独立采购不带需求关系。确认校验采购事实；人工采购入库或箱单内自动收货才写库存。

PackingList 草稿关联有效来源；正式过账复核交付额度、实际物料依据、PO Link、采购净可收容量和库存，统一形成执行证据、必要自动单据和正式交付。当前非标及 CR 来源走仅交付路径；不能从“标准产品”字面推断所有售后补发都经过库存。

纠错反向逐域显式执行：箱单整单反向、必要采购入库反向、采购取消确认、草稿删行/作废释放贡献、物料安全回退、来源取消确认。并非所有场景需要全部步骤，必须按实际活动事实判断。取消采购确认仍保留 Link；来源退出已组合物料历史与 Shipping 证明，不直接假设交付链未接入。

## 数量、快照与状态

- Link 有效贡献是 AllocatedQty-ReleasedQty；未关联量 UnlinkedQty 与活动贡献一起约束采购行数量。入库追溯使用真实采购行 Uid。
- 正式交付净额由有效已过账、未反向的 PackingList 行计算；人工 StockIssue 不代表客户交付。
- NetQty 当前是来源/组成计算值，没有自动扣减库存或在途的完整 MRP。
- 来源单位、单据单位、库存流水单位保存各自 UnitSnapshot；当前主数据变更不覆写历史事实。
- BomVersion 为有效标记，当前单套共享组成不提供发布或历史版本选择。DecompositionRevision 是物料采用历史。
- 确认、单据生命周期、过账和查询执行进度分开。真实错发/退货不能被等同于撤销错误过账。

## 当前真实限制

| 限制 | 当前证据 | 不得误称 |
| --- | --- | --- |
| 正数量售后单结案 | AfterSalesLifecycleService 仍返回 AFTERSALES_DELIVERY_QUERY_UNAVAILABLE；VerifyClosureAsync 明确失败 | 已有交付查询不表示结案证明完成 |
| 销售商业修订、恢复及行级终止 | 当前销售 Controller/接口没有相应用例 | 旧目标不代表已开放命令 |
| 生产根含客供件 | GrossDemandDecompositionPlanner 明确拒绝 | 枚举存在不代表生产供料已实现 |
| 通用需求减量/执行处置 | 现有建立/回退/来源安全退出是明确用例 | 安全回退不代表所有商业变更方案 |
| 本位币切换 | 当前重置全部 RateToBase=1，成功 Message 提醒重新设置 | 不自动换算旧汇率或清除币种间独立汇率表 |
