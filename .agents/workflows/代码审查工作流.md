# 代码审查工作流

## 适用

审查、review、验收、风险评估、重构检查。

## 步骤

1. 先读 `AGENTS.md`、`.agents/router.toml`、`.agents/reviewer.toml`。
2. 读取 `.agents/references/测试与验收总纲.md`。
3. 后端改动读 `.codex/skills/aspdotnet10/index/SKILL.md`；前端改动读 `.codex/skills/wpf-dotnet10-design/index/SKILL.md`。
4. 前端改动涉及异步、写命令、Busy、导航/关闭、错误反馈或资源释放时，读 `.codex/skills/wpf-dotnet10-design/runtime-safety/SKILL.md` 及其 `references/运行时安全门禁.md`。
5. 前端改动涉及 ViewModel/API/Feature Service 职责、页面权限、普通表单验证、导航参数、Document Tab identity 或 Dialog/抽屉/子页面返回协议时，读 `.codex/skills/wpf-dotnet10-design/page-architecture/SKILL.md` 及其 `references/页面架构边界决策表.md`。
6. 前端改动涉及测试证据、可访问性、本地化/文化格式、性能、日志/敏感信息、缓存或文件导入导出时，读 `.codex/skills/wpf-dotnet10-design/quality-gates/SKILL.md` 及其 `references/前端质量门禁矩阵.md`；完成审查前读 `references/检查清单与代表性验收.md`。
7. 涉及已有业务模块时读取对应能力地图；采购改动读取 `.agents/references/模块能力地图/采购模块能力地图.md`。
8. 查看 git diff 和相关源码，对比能力地图和偏差账本。
9. 优先找 bug、分层违规、业务回归、测试缺口。
10. 对前端检查 CommunityToolkit 源生成器写法；按操作分类检查查询取消与过期结果、写并发、Busy owner、页面存活、错误分类、反馈/日志 owner、导航生命周期、资源释放和未保存变更。
11. 对前端列出 ViewModel 依赖并检查直接 Refit/Feature Service 选择、API 注册、三层权限、验证 owner、打开参数、Tab identity、重复激活和 Dialog 结果接纳；检查 Service/UI 与业务 ViewModel 的依赖方向。
12. 对后端检查 WebApi/Application/Core/Infrastructure/Contracts 边界。
13. 涉及 DTO 时检查复用决策：复用是否满足语义、字段口径、权限暴露、生命周期一致和真实多消费者条件；新建是否按 API 用例命名并避免聚合桶文件。
14. 检查改动是否扩大能力地图已知偏差；扩大偏差属于阻断问题，必须要求用户确认重构或兼容方案。
15. 对前端检查测试证据与豁免、键盘/Automation/高对比度、文化格式、UI 线程/虚拟化、日志脱敏、缓存隔离/失效及导入导出安全。
16. 对业务流程检查状态、改单、库存流水、过账/反过账边界。

## 输出

1. Findings：按严重程度排序，带文件/行号。
2. Open Questions：只列影响判断的问题。
3. Test Gaps：说明缺少哪些验证。
4. Summary：简短总结。
