# WebApi 目录职责

| 文件夹 | 负责内容 |
|---|---|
| Controllers | 按业务模块接收 HTTP 请求、绑定参数并调用 Application |
| Authentication | 当前用户读取、JWT 签发、凭据版本验证与认证接口 |
| ErrorHandling | 错误码到 HTTP 状态映射、统一失败包装、结果过滤器和全局异常出口 |
| Observability | 请求关联标识、日志上下文及对应用层的追踪适配 |
| RequestProtection | 请求防抖等 HTTP 入口保护；不替代业务幂等 |
| Configuration | 依赖注册、JWT/JSON/Swagger 配置及请求管道组合 |
| Development | 仅开发环境使用的身份注入辅助 |
| Properties | 框架宿主启动配置 |
| Logs | 运行日志输出，不存放业务实现 |

Program.cs 保留启动配置读取、日志初始化、生产安全检查及启动/关闭入口，通过 Configuration 组合服务和管道。

公共类型命名空间与职责目录一致，例如 SwiftExport.WebApi.Authentication、SwiftExport.WebApi.ErrorHandling。原 Services、Middlewares 和 Filters 中的类型已迁移，不保留旧命名空间兼容类型。

错误码由 Application 提供，HTTP 状态由 ErrorHandling 统一映射。认证、模型校验、防抖和异常出口采用相同失败包装；失败 Data 为 null，客户端从非 2xx 正文读取 Error。CorrelationId 位于异常中间件外层，贯穿错误日志和响应。

业务资格、数量、状态和事务编排继续属于 Application；数据库访问继续属于 Infrastructure。Development 中既有开发身份查询方式本次原样迁移，其实现边界另行治理。
