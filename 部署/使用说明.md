# SwiftExport 部署工具

部署和维护入口集中在本目录。业务项目保留在仓库根目录；生成产物写入 `artifacts/部署/`，真实配置与本机记忆写入 `部署/本机配置/`，均不提交版本库。服务器运行目录、更新 URL、图片/附件和 Caddy CA 数据不随仓库整理迁移。

| 组件 | 开发电脑入口 | 服务器或用户端入口 |
| --- | --- | --- |
| WebApi | [打包后端](WebApi/打包后端.ps1)，或 Visual Studio 文件夹发布 | [首次托管与日常更新](WebApi/Caddy首次安装与日常更新.md) |
| ClientWpf | 双击 [一键打包客户端](ClientWpf/一键打包客户端.cmd) | 分发 Setup；更新按 [客户端说明](ClientWpf/客户端部署与更新.md) 发布 |
| WebApp | 在 WebApp 项目执行现有 npm 构建 | [静态发布模板](WebApp/使用说明.md) |
| VSTO | 使用现有 Visual Studio 发布方式 | [VSTO 发布边界](VSTO/使用说明.md) |
| 公共 | [Caddy 工具](公共/Caddy/获取Caddy.ps1)、[证书安装](公共/证书/安装客户端根证书.ps1) | 随部署 ZIP 一起保留公共目录 |
| 管理员急救 | [独立恢复工具](维护工具/AdminPasswordRecovery/使用说明.md) | 使用明确 PostgreSQL 连接和交互密码输入 |

## 常用命令

在仓库根目录运行；脚本也支持从其他工作目录用绝对路径调用：

```powershell
& .\部署\ClientWpf\一键打包客户端.ps1 -NonInteractive -NoOpenFolder
& .\部署\WebApi\打包后端.ps1 -OutputDirectory .\artifacts\部署\WebApi\本次发布 -RuntimeIdentifier win-x64
& .\部署\WebApi\打包部署工具.ps1 -OutputPath .\artifacts\部署\WebApi\SwiftExport-部署工具.zip
dotnet run --project .\部署\维护工具\AdminPasswordRecovery\AdminPasswordRecovery.csproj
```

客户端版本根据已有 `artifacts/部署/ClientWpf/Releases` 递增；不要清空旧包和索引。打包设置位于 `部署/本机配置/ClientWpf/打包设置.json`，日志和说明分别位于产物目录的 Logs、Notes。后端窗口设置位于 `部署/本机配置/WebApi/部署窗口设置.json`；工具 ZIP 解压后也按同样布局保存本机设置。

服务器部署工具 ZIP 只包含白名单脚本、示例、说明及经过校验的 Caddy。完整解压，保留同级 `WebApi` 和 `公共`，从 `WebApi` 启动窗口。开发机与服务器的生产配置分别保管；复制新版工具时保留服务器工具根目录已有的 `本机配置`。

旧入口不保留转发；历史验收文档仍保留当时的路径和日期。Visual Studio 需要识别的 PublishProfiles 继续位于对应业务项目。

本次文件迁移、构建、隔离验证与真实打包结果见 [迁移验证记录](迁移验证记录.md)。

目录迁移不代表已验证服务器上的启动器问题，也不执行服务器更新、服务注册、信任库修改或数据库恢复。后续统一 GUI 将复用本目录的工具能力，本轮没有创建 GUI 项目。
