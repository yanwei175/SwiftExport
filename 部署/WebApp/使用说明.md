# WebApp 静态发布模板

在 `SwiftExport.WebApp` 中使用现有 npm 构建命令，构建输出为 `build/client`。将完整静态文件复制到仓库 `artifacts/部署/WebApp/<本次发布>/` 作为部署暂存和归档，再按服务器平台配套使用下方模板。生产环境提供静态文件，不运行开发预览脚本。

- Windows 模板：[web.config](windows/web.config)，需要 IIS 的 URL Rewrite/ARR。
- Linux 模板：[nginx.conf](linux/nginx.conf)。

这些是适配模板，不是已部署配置；API 目标仍需按实际服务器端口调整，现有 Caddy 后端监听地址为 `http://127.0.0.1:5081`。按既有发布规则验证 API/文件路由、SPA 回退和缓存后再上线。本轮只迁移模板，未接入或改写服务器 Caddy 路由。

工程命令与边界见 [Web 工程入口](../../SwiftExport.WebApp/docs/工程入口与命令.md)。
