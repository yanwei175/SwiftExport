# VSTO 发布入口

当前 Excel 插件项目为 `SwiftExport.Client.VSTO`，目标 .NET Framework 4.8，使用现有 Visual Studio Office/VSTO 发布流程。项目启用了部署清单签名和 VSTO Runtime 引导安装。

在 Visual Studio 打开现有 VSTO 解决方案，使用插件项目的发布功能；发布目录、安装地址、版本及签名证书沿用该发布配置并单独验收。客户端的 Velopack 打包入口只适用于 .NET 10 WPF，不用于 Office 插件。

本目录先统一发布说明入口，本轮没有新增 VSTO 自动打包、修改签名、变更项目文件或编辑业务源码。VSTO 发布配置继续保留在 Visual Studio 要求的项目位置。
