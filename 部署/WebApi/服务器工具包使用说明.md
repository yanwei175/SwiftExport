# 服务器部署工具包

完整解压本 ZIP 到独立工具目录，例如 `D:\ERPDeploy\部署工具`。保留同级 `WebApi`、`公共` 以及公共目录内的 Caddy 程序和许可证，不要只复制 CMD 或窗口脚本，不要把工具放进后端安装目录。

- 已有 Caddy 托管：打开 `WebApi\启动后端部署工具.cmd`，按 [日常更新说明](Caddy首次安装与日常更新.md) 更新程序。
- 首次安装：打开 `WebApi\启动Caddy首次安装.cmd`，先检查配置，再按说明安装。
- 后端发布包和生产配置单独提供；本 ZIP 不携带它们或服务器 CA。

窗口只将目录和运行选项保存到工具根目录的 `本机配置\WebApi\部署窗口设置.json`。替换工具时保留该目录。已有服务器程序安装路径、文件存储和 CaddyData 继续沿用；更新不重新签发 CA。

工具支持 Windows PowerShell 5.1。若双击失败，可在 PowerShell 中直接运行 `WebApi\后端部署窗口.ps1` 查看初始化错误；目录迁移和本地布局验证不等于服务器启动问题已经解决。
