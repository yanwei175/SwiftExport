# 数据库结构变更

## 规则

- 迁移工具：**DbUp（MIT）**。脚本嵌入 Infrastructure，命名 `yyyyMMddHHmm_描述.sql`。（DbUp 尚未接入时标注“待实施”，不假装存在。）
- 脚本**只增不改**；已执行脚本不得修改，修正用新脚本。
- Agent 只新增脚本，不直接连库执行 DDL，除非用户明确授权具体实例与库名。
- Core 实体特性（`[Table]`、`[DbColumn]`、`[DbIndex]`、`[DbCheck]`）与脚本保持一致。

## 类型约定（新增列默认值；已有列以实体为准，不因本表修改）

| 内容 | 数据库 | C# |
|---|---|---|
| 业务日期 | `date` | `DateTime`（仅日期部分） |
| 时间戳 | `timestamptz` | 与同实体现有字段保持一致 |
| 数量、单价、金额 | `numeric`，精度按业务文档 | `decimal` |

- 舍入方式、精度、币种与快照字段由业务文档决定，本技能不规定。
- 软删除表的唯一索引带软删除过滤条件（部分索引）。
- 外键列与常用查询列建索引。
- 表间依赖、字段引用、唯一约束的任何变更：先询问用户，给出原因与方案。

## 禁止

- 修改已发布脚本；删除列而不评估客户端与历史数据。
- 为配合代码方便而改实体既有字段语义。
