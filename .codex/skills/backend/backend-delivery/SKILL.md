# 交付验证

## 完成定义

1. 解决方案构建通过，无新增警告（可空、未使用引用）。
2. 相关测试通过：
   - 状态方法：单元测试（无数据库）。
   - 正式命令：成功、重复 `CommandId` 重放、同 `CommandId` 不同内容 422、`Version` 冲突 409、业务规则不满足 422。
   - 改变下游事实的命令：下游数据与反向操作正确（具体断言来自业务文档）。
   - 权限：未授权 403。
3. Contracts 仍为 netstandard2.0 可编译；DTO 无 `record`/`init`/`required`/`DateOnly`。
4. 改表时有新增迁移脚本，未修改旧脚本。
5. 残留检查：本次范围内无新增 Support/Helper/Manager/Pipeline、无 Newtonsoft、无操作名字面量、无 Service 内 try/catch 转错误、无仓储内开事务。
6. 重构任务：被替换的旧代码已删除或列入明确删除计划。

## 数据库测试

PostgreSQL 集成测试只在用户授权的测试库运行；不得连接生产库。无授权时说明未运行项。

## 报告

分开列出：已完成、已验证（附命令/测试名）、未验证及原因、发现但未处理的问题。不把“编译通过”表述为“业务验收通过”。
