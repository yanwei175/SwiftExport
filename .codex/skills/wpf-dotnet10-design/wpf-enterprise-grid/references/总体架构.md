# SwiftExport WPF Enterprise Grid 当前架构

基线日期：2026-10-16。本文替代旧阶段路线图，描述独立项目退出后的客户端职责；源码存在不等于所有业务组合已验收。

## 1. 决策与依赖

- 宿主始终是 System.Windows.Controls.DataGrid，保留原生列、编辑事务、键盘和虚拟化。
- 退出 Numeric/Lookup 自定义列、GridSelection 状态镜像、SelectionSnapshot、点击后备同步以及没有读取者的 CanNavigate。
- EnterpriseGrid 独立项目及专项测试项目退出；所有有效适配及测试归客户端。Microsoft.Xaml.Behaviors.Wpf 沿用客户端现有依赖。
- 通用适配不引用业务 DTO、服务或商业 Grid；业务语义归页面命令，宿主 UI Service 继续处理弹窗。
- 不保留版本兼容空壳、总入口或协调器；列身份直接使用原生对象，所有旧 GridColumn 元数据退出。

## 2. 原生状态与数据流

| 需求 | 入口 | 边界 |
|---|---|---|
| 整行选中项 | DataGrid.SelectedItem | 直接 TwoWay 绑定，多选时不等于活动行 |
| 活动格所在行 | DataGrid.CurrentItem | 原生 CurrentCell.Item，显式 TwoWay |
| 活动格/列 | DataGrid.CurrentCell / CurrentColumn | View 层直接消费，不建立字符串镜像 |
| 行选区 | DataGrid.SelectedItems -> 命令参数 | 按执行时读取，异步前复制所需数据 |
| 格子选区 | DataGrid.SelectedCells -> 命令参数 | 原生实时集合，不持续镜像 |
| 活动视觉 | CurrentCell -> MultiBinding/Converter | 不缓存容器，不存储继承的选择副本 |

固定 FullRow 页面按选中项语义使用 SelectedItem；需要跨行/格模式取得活动行的页面使用 CurrentItem。二者不得同时 TwoWay 绑定同一个 VM 属性。

原生 CurrentItem 不承诺在集合 Reset 后自动清空；删除、重载和关闭用例负责维护有效活动项。BaseListModel.Clear/Remove 维护其 SelectedItem，页面独立 SelectedLine 由页面用例维护。程序化滚动在 Loaded 后显式 ScrollIntoView，不恢复全局选择协调器。

DataGridSelectionBehavior 没有业务调用，已删除实现和专属测试；选区按命令读取原生集合，不维护持续同步快照。

Cell 模式下 SelectedItems 为空；CellOrRowHeader 下只包含完整行选择。需要格子选区涉及的行时，业务显式从 SelectedCells.Item 去重，不在空选区时补入活动行。

## 3. 当前模块

| 归属 | 职责 |
|---|---|
| 客户端 GridRowHeader / GridValidation | 各自独立管理启停、卸载重载和事件释放 |
| 客户端填充 | DataGridFillDownBehavior -> FillDownRequest -> 页面业务命令；无提交历史 |
| 客户端 GridValidation | 模型软错误 Errors / ErrorCount，CellState / RowState 软提示 |
| 客户端 GridRowHeader | 视图行头行号与可选独立行号列 |
| 客户端 Resources/Converters | 三个原生选择/活动状态转换器 |
| 客户端 Resources/Behaviors | 填充桥接和 GridRowPresentation 的画刷、文本槽 |
| 客户端 Resources/DataGrid.xaml | 原生虚拟化配置和命名样式 |

Operations、Filtering、Layout、Exporting、GridVirtualization 及其专属测试已退出。没有业务调用的 CanUndo、HasErrors、FirstError、FocusFirstError 也退出；不再提供 Grid Undo；编辑器 Undo 和页面放弃修改语义独立。业务行重排仍归客户端 RowDragReorder，不属于框架。

## 4. 必要列元数据

- GridColumn.Key 已删除；错误持有原生列对象，View 事件通过具名列引用识别。
- GridValidation.FieldPath：只为有真实字段错误的模板列映射模型字段，当前业务仅销售 UnitSnapshot；普通列使用 Binding.Path。
- 填充元数据已迁出：客户端 Field 显式开放业务字段；许可和完整写入由页面命令负责。

不引入稳定字符串列标识，不自动猜测模板业务字段。GridCellReference 和 PropertyPathAccessor 随 Operations 删除。

## 5. 输入和列编辑

原生 DataGrid/编辑器拥有鼠标选择、双击、F2、Enter、Tab、Shift+Tab、Esc。无选择 Behavior。客户端填充行为只在 Loaded 时注册 Ctrl+D，Unloaded/Detach 移除自身命令。框架不订阅编辑结束或维护 Undo。编辑器 Ctrl+Z 沿用原生，页面放弃修改仍恢复既有基线，不替代成逐步 Undo。

数字使用 DataGridTextColumn。客户 PO 默认折扣率改为原生列及 Feature 内 ValidationRule，保留空值、非负和六位小数输入限制，行模型保存校验不变。Lookup/枚举/复选框使用 DataGridTemplateColumn 和宿主编辑器；候选查询、业务值回填继续由宿主负责，不恢复便利列体系。

Grid 不再提供文件导出；业务字段、权限、文件和格式处理由客户端现有文件服务负责。Grid 级粘贴与 Delete 清空已退出，关联字段由已有业务清空命令维护。复制完全交给原生 DataGrid，模板数据列提供 ClipboardContentBinding；没有 TSV 解析/序列化或复制后重写剪贴板的兼容层。多行内容沿用原生各格式语义，外部应用粘贴效果按实际目标验证，不再保留 Grid 往返契约。

## 6. 验证与交付

- Grid：原生编辑入口、活动项绑定、虚拟化、原生命令、验证与生命周期；保留原生集合视图兼容性测试。
- 客户端 Resources/Behaviors：填充选区、命令生命周期及行标记继承；原生选择兼容测试保留。
- 客户端：实际页面资源、活动项绑定、行/格切换、数字输入失败保留/修正/取消和标签生命周期。
- 样式：活动行/格、选择、验证优先级和回收后重算，不以截图替代行为断言。
- 旧镜像、强制点击选行和自定义列类型测试随契约退出；有效原生兼容及业务校验断言迁移保留。
- 共享 Application 导致测试宿主冲突时分进程复测，记录方法与结果，不修改业务实现迁就测试隔离。
- 构建、证据复用和失败重测遵循测试总纲，不按每个 Skill 重复执行同一集合。

使用及独立项目退出迁移见 [使用与迁移指南](../../../../../docs/wpf-datagrid/使用与迁移指南.md)。

客户端填充的 ViewModel 白名单、业务关系更新与迁移示例见使用与迁移指南第 2.2 节。不新增 DataGridExtensions 依赖。

软验证仅挂接颜色、字典数据、销售订单明细、入库行、出库行；采购候选直接展示模型 ValidationDisplayMessage，不再挂接没有显示消费者的聚合。默认折扣率 ValidationRule、原生转换错误、页面保存校验及 Ctrl+D 业务实现保留。

软验证只观察模型错误：仅 IDataErrorInfo 观察 PropertyChanged，INotifyDataErrorInfo 适配分支随无效采购挂载退出；合并 Dispatcher 刷新并在卸载/关闭取消。Errors 不承诺顺序，不包含原生转换/ValidationRule 错误，不作为保存门禁。MarkerGlyph 无读取方已删除。
