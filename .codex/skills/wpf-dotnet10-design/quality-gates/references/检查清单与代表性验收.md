# WPF 质量检查清单与代表性验收

本表用于模块/完整UI或专项非功能验收，按本次实际影响选择条目，不是普通小改的全量完成清单。日常证据选择与复用以测试总纲、前端质量矩阵为准；无关主题不要求填表或启动窗口。

## 当前可复用基础（2026-08-31 抽样）

- 有效 Grid 专项测试已迁入 `SwiftExport.Client.Wpf.Tests`；该项目为 `net10.0-windows`、MSTest、`UseWPF=true`，已有 `StaTest`/Dispatcher 测试基础设施。
- 客户端已有 ViewModel/模型、API runner、缓存、导航和自定义控件测试；Grid 已覆盖选择、编辑、验证、筛选、虚拟化生命周期与 CSV/XLSX 导出。
- `SwiftExport.slnx` 包含两个 WPF 测试项目；`SwiftExport-Frontend.slnx` 当前只包含 Client、Contracts 和 Grid 产品项目，因此前端综合构建不等于运行 WPF 测试。
- Grid 已提供 `GridExportRequest`、CSV/XLSX provider、取消/进度、文化选项和公式注入防护；业务页面已有独立导出 Service。
- 客户端存在会话级基础资料缓存、磁盘图片缓存和 DPAPI Token 存储，可作为 owner、隔离、TTL/失效和敏感信息审查的真实样本。

## 当前代表性偏差

- `AutomationProperties` 主要集中在少量共享控件与 Grid，尚无全页面可访问名称、焦点顺序和屏幕阅读器反馈的系统证据。
- 可见业务文案和 `StringFormat` 大量直接位于 XAML/ViewModel/Service，尚未形成统一资源所有权与本地化机制。
- 客户端日志当前清空默认 provider 后只启用 Debug provider，日志持久化、生产级别与集中脱敏策略未建立；本阶段只建立门禁，不实施基础设施。
- 会话级基础资料缓存有会话结束清理和显式刷新，但未统一表达 TTL、用户/租户 key 与写后失效；图片缓存有配额/过期测试，不能据此推导所有缓存安全。
- 导出已有公式注入与格式测试，但业务导出对权限、敏感字段、当前视图/全部数据语义、临时文件和错误报告的覆盖不统一；导入能力未形成统一管线。
- 多个页面已启用 Grid 虚拟化并使用分页/异步模式，但缺少统一的代表性性能基线和测量记录。

以上偏差采用触碰即治理；未被当前任务触碰时记录风险，不批量重构。

## 实施与审查

- [ ] 测试断言行为和不变量，包含失败、取消、空值、重入或边界值，不只匹配实现文本。
- [ ] 全键盘可达，焦点恢复稳定，快捷键不抢占控件/DataGrid 原生语义；无文字控件有可访问名称。
- [ ] 状态、错误和禁用不只靠颜色；高对比度/系统强调色下仍可识别。
- [ ] 新可见文案和格式没有散落；文化、时区、币种、数量、百分比、单位和空值边界明确。
- [ ] 无 UI 线程同步 I/O；大集合、搜索、批量通知和虚拟化策略有代表性测量或合理上界。
- [ ] 日志级别与 owner 正确，用户反馈不含堆栈，日志/错误/文件不泄露敏感信息。
- [ ] 缓存 owner、key 隔离、TTL/失效、刷新与写后行为明确；没有把页面状态或缓存冒充离线支持。
- [ ] 导入导出限定类型/大小/编码/路径，防公式注入，支持取消/进度/清理，明确数据范围、权限和敏感字段。

## 代表性验收场景

- 键盘：不用鼠标完成查询、进入 Grid、编辑、提交/取消、打开/关闭 Popup/Dialog/抽屉并返回触发点；检查 Tab、Shift+Tab、Enter、Space、Esc、F2 与业务快捷键。
- 可访问性：使用高对比度与系统强调色检查焦点、选择、错误、禁用和行状态；核对无文字按钮与动态反馈的可理解名称/文本。
- 文化与格式：至少用当前目标文化和一个不同小数/日期分隔符文化覆盖日期、金额、数量、百分比、单位、空值及解析失败；跨时区场景核对业务日期不漂移。
- 性能：列表/树/Grid 使用与生产接近的数据量；连续输入搜索、快速翻页/切换、滚动回收、批量更新，记录首次响应、持续交互、内存或 UI 卡顿中与任务相关的指标。具体阈值由功能基线或需求确定，不凭空设统一毫秒数。
- 日志与缓存：模拟网络失败、401/403/409、正常取消、会话/租户切换、刷新失败和写成功后读；确认一次反馈、正确级别、脱敏、旧会话结果不污染新会话。
- 文件：覆盖空文件、错误扩展名/编码、超限、特殊字符、公式前缀、取消、写入失败、当前视图/全部数据/选中行和敏感列排除；实际用目标应用打开导出文件。
