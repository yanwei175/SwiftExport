# Web 主壳与业务模块开发

## 输入与范围

读取已授权用例、实际 Web 文件/调用方、直接相关能力地图和后端读取契约；主壳任务按 [工作流](../../../../.agents/workflows/Web前端工作流.md) 只读对照 WPF Shell 及导航。写入限本次 Web 文件与相关测试，不能复制或修改 WPF 代码来满足 Web 任务。

规则正文见 [架构 §6/7](../../../../docs/Web客户端架构与脚手架决策.md#web-field-owner)、[公共契约](../../../../docs/Web多标签工作区设计.md#workspace-contract) 和 [权限设计](../../../../docs/web-permission-design.md)。选择对应部分，不默认全仓审计。

## 实施要点与复用入口

1. 按用户动作列出页面职责、权限、输入/返回及真实 API；搜索现有导航目录、页面目录、Form、lookup、Grid 和反馈组件。主壳只组装；业务保存及 DTO 映射归 feature。
2. 页面目录在应用层登记 pageKind、参数类型、访问条件和显式 lazy import；feature 经 shared 注入公共意图，跨模块读取使用生成操作/规范 Query Key，打开页面不导入另一个页面的组件。
3. 按 WEB-EDIT-01/02 确定 Form 或集合的字段 owner；普通 Form 不再用 useState 同步同字段。列字段转换、必填/跨字段验证及服务器 field 到实际控件路径的映射；无法定位的错误也必须显示。
4. 区分页面访问、实际操作、候选读取权限；菜单、URL、已驻留标签均核权。缺候选权限按 [典型账号门槛](../../../../docs/Web首批接口契约验收.md) 禁用相应编辑/提示，保留已有值，不扩大系统管理权限。
5. 中文布局/消息/职责注释；键盘、焦点和错误定位归当前标签。依赖和公共抽象只为真实用例新增，不机械创建未来模块空目录。
6. 公共设施复用 [已确认基线](../../../../docs/Web客户端架构与脚手架决策.md#web-common-services)：Ant App 反馈、用户偏好、诊断、字段错误、数值/日期、受控 Grid 编辑和候选。候选搜索不作为业务当前值，后台读取不覆盖 Form/Grid；日期手输需先具备 raw 输入保护，首期只允许选择。

## 禁止事项

不得在页面散落 fetch/认证头、放草稿进 Query、引用其他 feature 私有 hook、自己维护标签列表、以 View 权限代替全部写权，或用角色中文名授权。日期/金额转换先确认字段契约，不统一补 Z 或让 JS 浮点成为服务器金额权威。

## 验收与交付

- 检查 import 方向和页面注册，重复打开/权限拒绝/空与错误状态可解释。
- 普通 Form 改回原值恢复业务 clean；未提交缓冲仍按 workspace 摘要保护。
- 按任务验证候选权限、实际字段错误定位、键盘/焦点及保存失败输入保留；结合 [delivery](../react-web-delivery/SKILL.md) 选择构建/浏览器证据。
- 输出复用文件与尚未实现入口；不能把 WPF 可用推断成 React 主壳已通过。
