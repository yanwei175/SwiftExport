# DvFileStorage

独立的 .NET 10 文件存储类库，程序集名为 DvFileStorage.dll。

当前仅建立项目骨架，尚未实现文件操作接口或本地存储。没有第三方包或其他项目依赖，可单独复制和构建。

下一步执行依据：[本地文件存储首期实施计划与提示词](本地文件存储首期实施计划与提示词.md)。本轮包含宿主 JSON 根目录接线，不包含产品图片业务。

后续职责限定为文件流读写、删除、存在检查、文件信息以及存储根目录内的路径约束。业务命名、数据库记录、HTTP 接口、认证授权和对外地址由使用方负责；类库不自行读取宿主配置文件。

接口和本地实现随实际代码加入 Abstractions、Local、Configuration、Models 目录，不预先建立空壳类型。

构建：`dotnet build DvFileStorage.csproj -c Release`。
