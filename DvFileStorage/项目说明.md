# DvFileStorage

独立的 .NET 10 文件存储类库，程序集名为 DvFileStorage.dll。

当前已实现本地文件的流式写入、读取、存在检查、文件信息和幂等删除，以及根目录路径边界、显式覆盖、同卷完整发布和失败临时清理。没有第三方包或其他项目依赖，可单独复制和构建。

完整配置、调用示例、流所有权、取消和已知限制见：[使用说明](使用说明.md)。实施范围与验证记录见：[本地文件存储首期实施计划与提示词](本地文件存储首期实施计划与提示词.md)。

后续职责限定为文件流读写、删除、存在检查、文件信息以及存储根目录内的路径约束。业务命名、数据库记录、HTTP 接口、认证授权和对外地址由使用方负责；类库不自行读取宿主配置文件。

公开接口位于 `Abstractions`，本地实现位于 `Local`，配置和文件信息分别位于 `Configuration`、`Models`。业务命名、数据库记录、HTTP 接口、认证授权和对外地址仍由宿主负责。

构建：`dotnet build DvFileStorage.csproj -c Release`。

定向测试：`dotnet test ..\DvFileStorage.Tests\DvFileStorage.Tests.csproj -c Release`。
