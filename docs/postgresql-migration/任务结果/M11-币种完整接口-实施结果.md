更新锁使用基类 GetLockHint：非空输入的锁查询须外层已开启事务；仓储不新建、提交或回滚事务。空规范化集合沿用源提前返回，未加事务门槛。FOR UPDATE 只保护已有匹配行，不声称覆盖缺失行、并发插入或范围保护。五表 CTE 无共享协议、表锁、advisory lock 或临时表；数据库对去重/UNION 禁止直接 FOR UPDATE，所以锁下沉源表。真实等待和跨连接行为尚未运行。

NOLOCK 读取翻译为 PG 正常快照读取，不承诺脏读兼容。代码等值/数据库去重/代码排序使用现有 rtrim(...,' ') COLLATE public.erp_dictionary_ci 表达式：两侧仅删除 ASCII 尾空格，返回文本不改写、前导空格保留；输入规范化仅发生在源已经规范化的三个入口。NULL 排序显式保留 SQL Server 升序代码 NULL 首位、本位币降序 NULL 末位。

关键字沿用源 % + Keyword.Trim() + % 和裸 LIKE，ESCAPE '' 保留反斜杠字面量；不调用 SqlLikePattern.Build，因为该 helper 会转义 %/_ 并改变空格及 ? 的含义。当前没有可调用的共享裸 LIKE 字符组适配 helper，MAIN RBAC 适配为其私有实现，未复制或新建全局比较框架。**SQL Server 方括号字符组 [abc]/[^x]/[a-z] 与 PG 裸 LIKE 仍有差异，未标兼容通过；需要 MAIN 后续决定复用/统一适配。** %/_、反斜杠、CI、ASCII 空格、Unicode/宽度/kana 和排序均未实库验证，B10 仍开放。
