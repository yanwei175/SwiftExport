Search才加Active、有客户、正Remaining及原AND filters、六Keyword列。`candidates AS MATERIALIZED`固定一次完整过滤候选，SQL COUNT::integer 与page共同消费，最终totals LEFT JOIN page+HasSource保留空页/超末页总数。私有29字段传输包（27投影+count/flag）全部nullable投影用于空页；C#只组装，不重复净额、计数、资格或排序，真实Empty身份不会被吞，必需值NULL及缺结果行暴露技术错误。

Get仅Gross身份及共同准入，Closed/Voided、缺客户、零/负剩余可读，缺失/软删/标准产品失效为null；不新增服务参数校验。Search原int减一再long乘保留，非正Take负LIMIT/负OFFSET保持技术拒绝，COUNT int溢出不改业务错误。
