## 实现与冻结语义

### Manager 单工作集协议

`SearchManagerAsync` 只发出一个参数化 SQL：`workspace AS MATERIALIZED` 一次投影完整工作集；`filtered` 应用唯一 QuickView 条件；count 和 page 均读这一过滤集合。最终单行返回 TotalCount 与局部 JSON 页面，页面零行时仍返回正确总数和 `[]`。分页在 SQL 中完成，C# 仅反序列化当前页面；SourceUid 模式不加 LIMIT/OFFSET、固定 PageIndex=1、PageSize 至少1且等于总量，无200/10000行截断。

工作集有49个显式字段别名，CTE二次读取也使用固定列清单，无 SELECT *。原工作台未查询的 SuggestedSupplierSku／SuggestedUnitPrice／SuggestedTaxPrice 明确投影 null，保持原 DTO 默认值，不引入候选查询的 SupplierProduct 连接或字段推断。

复用现有八个实体的 public snake_case 表名和参数机制，dto/json字段保留 CLR 大小写。查询借用 Session.Connection，Transaction 可空／已有透传，取消原样传递；不创建连接、事务、临时表、锁、数据库函数或多语句批次。空请求守卫先于取消与执行。

### 原工作台业务差异

- 直接仓储 PageSize<=0 使用20，普通分页上限200；服务另一套入参归一化不在本轮修改。SourceUid 不分页，仍为采购预览整来源加载提供事实。
- 默认 NetDemand 与 Gross 均有效未删除；指定历史物料生命周期时不强求 Gross 有效，但仍排除删除来源。历史实际采购过滤允许历史关联和头，不额外添加目标行检查。
- 单位仅物料 UnitSnapshot 的 ASCII 首尾空格修剪，未知不回退当前产品／来源单位。客供图只当前物料图；其他物料图优先修剪后的来源图再当前物料图。LinkSku 保留当前产品到来源快照的 COALESCE 回退。
- 推荐采购供应商不新增 IsActive 筛选，建议送达方按同父、Gross、Root、修订、有效未删目标派生；无目标／无推荐／推荐已删除的三个提示保留。推荐提示不自动改变采购量可信度或冒充实际采购。
- 关联量先汇总活动正剩余 Link，保留 LEFT JOIN 失效采购目标的数量事实，再独立判断目标、客户和单位可信度。历史、来源客户／版本／指纹、未知单位、非正物料量、无效采购目标和超量按原优先级处理；AssociatedPurchaseQty／RemainingQty 未知不转0，DueHint保持空。
- DueHint 在 C# 一次取得 China Standard Time 日期并显式绑定墙上时间参数；有效、可信、未全承接且有交期的行才判断逾期或七天内临近。起始日期保留时间，结束日期取次日排他，不用 PG CURRENT_DATE 或重复取业务时钟。
- 数组原样 Distinct，空数组不筛选；UUID 数组绑定 ANY，文本数组按冻结 ICU／尾 ASCII 空格比较；PO编号保留原请求 Trim 后精确比较。实际供应商／单号筛选不顺手增加源查询没有的行资格。
- 字面模式复用 `SqlLikePattern.Build`：空白跳过，原输入不额外Trim；ASCII空格变%，问号变_，波浪号/百分号/下划线保留源转义规则，只将 `~[` 调整为 PG 字面 `[`。三个搜索入口均参数化，未接 M10 原始 LIKE 字符组解析器。

`SearchMaterialSourceGroupsAsync` 继续 **只按 SourceUid 分组**，SourceType／SourceNo 用 MAX，DemandCount整数，历史来源规则同上；未改成来源候选的类型＋Uid分组。

文本比较遵循冻结 ICU／ASCII 范围，未证明 Unicode 全等价或解决 B10；UUID排序仍是已登记跨库差异，不声称与 SQL Server 字节级逐行同序。聚合单号和实际供应商沿原去重键，没有新增未规定的聚合内部排序契约。
