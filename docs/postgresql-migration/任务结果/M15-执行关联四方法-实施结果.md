## 准备与边界

IMaterialDemandTransactionPreparation直接委托同RepositoryBaseContext的PGGross四集合实现，不复制发现循环/预算/租约。共享C_cmd（有才取）→C_item整组→全部S→全部U的实现保持原样。读取Item过滤Empty，写入Item包含Empty并参与C_item准备。
