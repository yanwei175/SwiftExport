## 原行为与翻译

|项目|保留内容|
|---|---|
|入口|null 请求先 ArgumentNullException；不在其前增加取消短路，不修改请求对象。|
|普通分页|PageIndex 至少1，PageSize 强制1至200（零/负值结果1，非默认50）；原 int Offset 运算。|
|指定来源|SourceUid.HasValue 即进入来源模式（含 Guid.Empty）；PageIndex=1、不加 LIMIT/OFFSET；其余筛选仍生效；返回 PageSize=Math.Max(1,total)。|
|阶段|先 QueryAsync 列表完整缓冲，再独立 ExecuteScalarAsync<int> 计数；不合并 reader、不增加快照/锁/事务。两命令分别使用会话当时 Transaction 和同一取消令牌，异常直接传播。|
|基础资格|只筛选 GrossDemand.IsDeleted=FALSE，不补来源、客户、产品活动资格，不修复历史数据。|
|Keyword|非空白时 .Trim() 后包 %，匹配原 SourceNo/SkuSnapshot/CustomerSkuSnapshot/DescriptionSnapshot；保留 %/_ 通配符和反斜杠文本，用原 CI 规则的公共 ICU collation。方括号字符组差异见下文。|
|CustomerKeyword|非空白时沿用 SqlLikePattern.Build 原文输入，不 Trim；空格转%、?转_、~/%/_/[ 转义；客户 EXISTS 仅过滤未软删，LIKE ESCAPE '~'，不要求 IsUsable。|
|四文本集合|原 .Distinct() 顺序与值保留，不 Trim、不删除空/null条目、不改大小写；null/空集合不加条件。明确 text[] 绑定并用 unnest 子查询模拟 IN；SQL CI 及 ASCII 尾空格等值处理不改展示值。|
|生命周期集合|Distinct 后原整数值（含未知枚举）；非空时明确 integer[] ANY，避免 Dapper 展开；每个命令独立参数实例。|
|日期|From 原精确值包含时间，>=；To 取.Date，<加1日；共享 AddTimestamp 保留无时区墙上时间。|
|其他筛选|IsNonStandard 和 SourceUid 仅 HasValue 时精确匹配；TraceView 精确六个字符串分支，未知/null/All不增加条件，不 Trim/忽略大小写。|
|排序|RequiredDate NULL 最后，再升序；CreatedDate NULL 最前，再升序；最后 Uid 按源 SQL Server SqlGuid 字节优先级，不采用 PG 默认 UUID 顺序。|
|投影|与列表 DTO 30 个属性逐名核对一致；显式 CLR 别名；NULL、原快照/单位和审计日期不补值、不修剪。COUNT(1)::integer 保持 int 返回。|

三个存在性表达式用于展示和快捷筛选，共用同一源资格，不展开 Link：

- ActiveMaterial：NetDemand 对应来源、未软删、生命周期0；不额外限制版本/指纹。
- ActivePurchase：原活动 Net、Link 活动且 PO、AllocatedQty>ReleasedQty、头行身份匹配、头行未软删且头生命周期非9；来源 Version/指纹和来源版本分支一致；来源客户存在且采购头客户相同；采购行单位只需 ASCII Trim 后非空。不加入 Trace 的来源单位匹配、采购确认状态、Guard 或额外来源身份合法性。
- PostedDelivery：未软删装箱行对应来源，未软删装箱头且 PostingStatus=1；不补客户、单位、正数量或历史完整性条件。

私有 WorkspaceParameters 只组合现有 PostgreSqlParameters 与本查询的明确 integer[] 状态；每命令新建 NpgsqlParameter，不修改共享类、原 SourceLifecycleParameters 或追踪辅助链。
