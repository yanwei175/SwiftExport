原 #InboundSources 临时结果转成单条 SELECT 的 candidates AS MATERIALIZED。同次候选物化供 COUNT(*)::int 与 page AS MATERIALIZED，page在数据库按原顺序 LIMIT/OFFSET；一条LEFT JOIN计数行保证零候选和越界空页仍得到总数。Dapper以 DocumentType splitOn，把SQL NULL的空页候选映成null，只返回原候选DTO，私有SourceCount不泄漏API，不把占位行加入Items，不C#排序或取页。该映射及空页行为仅编译/源码核对，**未实际运行**。

页参数保留 (long)(request.PageIndex-1)*request.PageSize，未 clamp 或设默认。CASE Take<=0 返回负LIMIT，使PG不能将原非法FETCH零变合法空页；负offset同样保持技术失败，不把非法请求改为业务默认。服务已有合法页验证不改。
