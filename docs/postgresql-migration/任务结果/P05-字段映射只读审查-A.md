## 判定方法与保留要求

- EntityMetadataCache 从基类到派生类收集可读写、非索引、未标 NotMapped 的公共属性；SQL 名称使用 Table/Column 标记。PostgreSqlEntityMetadata 复用同一属性集，以 CLR 类型/属性名独立转蛇形名称。特别确认 ProductDetail→SQL ProductDetails→PG product_detail，ProductSKU→product_sku、IMPath→im_path、USDPrice→usd_price、MOQ→moq、IMType→im_type，未采用粗略逐字母插入下划线方式。
- SQL nvarchar 的 max_length 是字节数，除以 2 与 PG 字符上限比较；候选 DATALENGTH/2 超限计数为 0，包含尾部空格的长度没有因 LEN 忽略而漏报。此为保守 UTF-16 单位检查；主控预检按 EnumerateRunes 的字符数检查也为 0。未核验 NUL 与不成对代理项。
- 所有 decimal 列使用同一 precision/scale；TRY_CONVERT 到目标等效 decimal 类型后 NULL 或数值改变的计数均为 0，包括 DefaultDiscountRate(9,6)、DefaultExchangeRate(18,6) 和其余 (18,4) 字段。不以浮点中转价格、折扣或汇率。
- 本批没有 CLR enum 属性；ExcelReadProfile.EndMode 是 int，实际 CHECK 域为 0、1、2，候选超域数 0。未重新编号或转成字符串。
- 每个 Guid 字段的空 GUID 计数均为 0；主控预检额外检查主键空值/重复为 0。关联完整性、跨表目标闭包与唯一业务键冲突不由这些结果证明。
- Version<1 全部为 0；两个目标库对应 CHECK 都存在。保留源 Uid、Version、IsDeleted、CreatedDate、CreatedBy、UpdatedDate、UpdatedBy，含允许的 NULL；补迁不能调用会重新生成 Uid/审计时间或将 Version 重置为 1 的普通新增入口。审计用户名仅核验列类型、长度、NULL，未输出明文或证明用户关系可解析。
- 额外实际 CHECK 值核验：Bom 分子/分母正数、自引用排除；CustomerPoConfig 折扣非负；ProductNeutral 汇率为 NULL 或正数；ExcelReadProfile.EndMode 域。以上计数均为 0；没有把单表 CHECK 等同 BOM 图无环或配置功能正确。
