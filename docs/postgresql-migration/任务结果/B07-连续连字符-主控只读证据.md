## 相同源数据库中的LIKE与BETWEEN

源N'z'、N'中'均匹配N'%[a--c]%'和N'%[a---]%'，却不在普通N'a'到N'-'的BETWEEN范围；N'-'不匹配前者、匹配后者。PG普通ICU的a到-同样不包含z。**因此两个已知失败不能仅归咎于ICU与源排序差异：源LIKE字符组/连续连字符解释本身也不等于普通BETWEEN。** 这属于实际观察；没有据此推定全部范围算法。

源只读查询：

```sql
SELECT samples.character,
 CASE WHEN samples.character LIKE N'%[a--c]%' THEN 1 ELSE 0 END AS like_a_hyphen_c,
 CASE WHEN samples.character LIKE N'%[a---]%' THEN 1 ELSE 0 END AS like_a_hyphens,
 CASE WHEN samples.character BETWEEN N'a' AND N'-' THEN 1 ELSE 0 END AS range_a_hyphen
FROM (VALUES(N'a'),(N'b'),(N'c'),(N'd'),(N'z'),(N'-'),(N'0'),(N' '),(N'_'),(N'~'),(N'中')) samples(character);
```
