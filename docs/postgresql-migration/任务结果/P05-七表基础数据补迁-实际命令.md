# P05实际PowerShell命令

以下是实际运行脚本，无凭据值；读取授权配置只在内存中，进程环境finally恢复。按执行顺序，所有实际写入仅各一次，均exit0。不得直接重复运行写入或覆盖历史结果文件。

## 隔离只读预检

```powershell
$taskNames = @('SWIFTEXPORT_P05_SOURCE_CONNECTION','SWIFTEXPORT_P05_TARGET_CONNECTION')
$taskOld = @{}
foreach ($taskName in $taskNames) { $taskOld[$taskName] = [Environment]::GetEnvironmentVariable($taskName,'Process') }
try {
    $taskSourceConfig = ((git show HEAD:SwiftExport.WebApi/appsettings.json) -join [Environment]::NewLine) | ConvertFrom-Json
    $taskTargetConfig = Get-Content SwiftExport.WebApi/appsettings.json -Raw | ConvertFrom-Json
    $env:SWIFTEXPORT_P05_SOURCE_CONNECTION = $taskSourceConfig.ConnectionStrings.Default
    $env:SWIFTEXPORT_P05_TARGET_CONNECTION = $taskTargetConfig.ConnectionStrings.Default -replace '(?i)(Database\s*=\s*)[^;]+', '${1}dv_next_pg_failure_tests_20261004'
    dotnet run --project _tools/基础数据补迁/基础数据补迁.csproj --no-build -- --preview | Tee-Object -FilePath docs/postgresql-migration/任务结果/P05-基础数据补迁-隔离库预检.json
    $taskExit = $LASTEXITCODE
} finally {
    foreach ($taskName in $taskNames) { [Environment]::SetEnvironmentVariable($taskName,$taskOld[$taskName],'Process') }
    $taskSourceConfig = $null
    $taskTargetConfig = $null
}
exit $taskExit
```
