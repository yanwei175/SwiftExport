## 实现协议

新增 partial 补齐 `IOutboundQueryRepository.SearchItemsAsync`，完整实现现有五方法接口，构造器与会话复用原 partial。一次 Dapper 命令、一个结果集：`candidates AS MATERIALIZED` 固定原十字段资格关系；`COUNT(*)::integer` 和分页读取同一候选；最终 `totals LEFT JOIN page` 用显式 `HasItem` 保留零候选及超末页总数。C# 只组装 DTO，不重复资格判断、计数或排序。无结果行、真实行必需身份/余额 NULL 均暴露技术错误，真实 Guid.Empty 不冒充占位。

资格保留实际请求仓库、正且未删余额、当前未删启用产品及实际未删启用仓库；默认仓仅 LEFT JOIN 未删记录，停用名称仍可见。单位资格仅 `btrim(unit,' ')` 去 ASCII 两端空格，返回原文，tab/NBSP 不额外排除。SKU、关联 SKU、中文说明三列沿既有 Like 的 .NET whitespace/Trim 和 `~,%,_,[` 转义次序，不扩字段。

五参数局部显式绑定 uuid、uuid[]、text、bigint、integer。null 排除列表按已冻结的源 Dapper 空集合结果转为空 uuid[]；非空保持顺序、重复与 Empty，不增加限制。页内及最终输出均按局部 `rtrim(Sku,' ') COLLATE public.erp_dictionary_ci ASC NULLS FIRST` 和既有 ProductId SqlGuid 字节键排序。原 int 减一后 long 乘法保留；非正 Take 用负 LIMIT 触发技术错误，不引入业务 Validation，计数仍保留 int 溢出边界。

单语句 PG MVCC 候选观察是本轮冻结协议，未声称与 SQL Server READ COMMITTED 的所有瞬时观察完全相同。B10/B19 全域 Unicode 比较差异仍未解决。
