# 任务结果记录说明与模板

[主迁移清单](../主迁移清单.md)由主控独占维护；本目录每个任务单独一份，例如 M09-登录账号-结果.md。执行窗口只写获分配的记录，不改其他窗口报告。主控检查实际 diff 和证据后才能更新主清单；任务开始前先填授权文件范围和基线。

窗口运行状态按[窗口协调](../窗口协调.md)维护：开始前在自己的状态页登记轮次并标“运行中”，结束前先写本结果记录，再写结束时间、结果路径和停写状态。窗口运行完毕不等于迁移验收通过。状态页使用协调入口登记的唯一绝对路径，主控直接读取，不维护镜像副本。

## 模板

- 任务编号/名称：
- 窗口标题/真实 ID/负责人：
- 基线 commit、分支、绝对工作目录/worktree：
- 用户及主控授权范围、实际可写文件：
- 开始时已有未提交修改（不得覆盖）：
- 前置任务编号、是否已冻结、共享文件归属：
- 状态：待处理 / 开发中 / 代码完成待验证 / 验证通过 / 已接入运行 / 阻塞。
- 现状及实际调用链：
- 实际新增/修改文件：
- 是否修改业务代码/服务/契约；必要性与已批准的语义边界：
- 尚余工作、未验证内容：
- 跨边界需求/问题编号/是否阻塞/已报告主控：

## 验证证据

| 日期/代码版本 | 实际完整命令或只读查询 | 类型（静态/模拟/真实 PG/宿主） | 目标实例/库（不含凭据） | 通过/失败/跳过/未运行及数量 | 日志位置或原始输出摘要 | 与已知失败基线比较 |
|---|---|---|---|---|---|---|

数据库测试另填：备份核验结果及对应记录、测试前摘要、获准初始化与精确清理范围、单一执行者/时段、测试后摘要与序列状态、事务/锁释放、残留、异常清理结果。未做恢复演练必须写明；不把“有备份名”写成恢复验证通过。

失败先分类本次回归/既有失败/环境；保留有效断言。编译通过不等于测试通过，模拟测试不等于实库通过，实库仓储通过不等于宿主接线。历史结果只作引用，不累加成当前通过数量。
