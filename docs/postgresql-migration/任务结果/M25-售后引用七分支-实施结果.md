## 实现核对

公开声明方法只有四参数 ReferenceAsync。借用 RepositoryBaseContext 的当前 Session.Connection/Transaction，单个 QuerySingleOrDefaultAsync；无取消接口、自建事务、FOR UPDATE、隐藏连接、重试、NULL/Empty 身份短路或补查。缺失 null；重复匹配保持单行异常；驱动错误原样传播。显式局部参数包绑定 uid/CustomerId 为 NpgsqlDbType.Uuid，NULL 仍有 uuid 类型，不修改公共 PostgreSqlParameters。

表/列只从固定泛型实体和 PostgreSqlEntityMetadata/PostgreSqlNames 获取；kind 不进入标识符，不 Trim/改大小写。非法 kind 保持原 ArgumentException、参数 kind 和带句号原消息“不支持的售后候选类型。”。产品以外严格投影 Uid/Code/Name，产品严格 9 列，不更改 DTO 或全局 Dapper 空值设置。

| kind | 保留的过滤、投影和边界 |
| --- | --- |
| customers | IsDeleted=FALSE；仅 requireActive 时 IsActive=TRUE；Code/Name 来自客户编码/名称。 |
| suppliers | 同上；原供应商编码/名称。 |
| owners | 同上；Name=COALESCE(NickName,UserName)，空昵称不回退。 |
| colors | IsDeleted=FALSE，忽略 requireActive；英文 NULL 才回退中文。 |
| quality-categories | IsDeleted=FALSE，requireActive 才 IsEnabled；DictCode 使用 rtrim ASCII 尾空格与 erp_dictionary_ci 对固定常量等值；不加 IsSystem/Type 资格。Code 优先英文、Name 优先中文。 |
| sales-order-lines | 头行内连并均未删；头 CustomerId=@CustomerId；忽略 requireActive/头状态/确认，不 join 产品；CONCAT 及原 Sku 名称保持。 |
| products | 产品未删，requireActive 才产品活动；描述/特征/颜色原 COALESCE，空串保持；颜色 LEFT JOIN 不过滤软删/活动。 |

产品 CustomerProduct 始终 IsDeleted=FALSE 且 IsActive=TRUE，按产品和可空客户匹配；LEFT JOIN LATERAL/ORDER BY SqlGuid/LIMIT 1 等价原 OUTER APPLY TOP(1)，缺关系保留产品。SqlGuid 使用冻结网络字节顺序 `[10,11,12,13,14,15,8,9,7,6,5,4,3,2,1,0]` 重排 uuid_send；不用原生 uuid 排序/MIN，也不查询客户资格。产品投影完整 `Uid,Code,Name,CustomerSku,LinkSku,Unit,ColorId,ColorName,Specification`。
