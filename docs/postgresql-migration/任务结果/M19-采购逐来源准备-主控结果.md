sourceLease通过await using延续到原事务finally Dispose/Session清空后释放；prepare取消继续传播。准备返回空未开事务，保留原来源Failed/UNEXPECTED_ERROR/“创建采购草稿失败。”，后续来源仍独立处理，无全批重试。没有改公共接口、PG锁实现、API、DTO、原默认隔离、逐来源部分成功、Link重放校验、供应商预览/token/警告、目标验证、取号、采购/Link写入或提交缓冲发布位置。
