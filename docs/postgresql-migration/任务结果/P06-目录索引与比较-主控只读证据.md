源实际查询：

```sql
SELECT DB_NAME() AS database_name;
SELECT t.name table_name,c.name column_name,c.collation_name,
       i.name index_name,i.is_unique,i.filter_definition
FROM sys.tables t JOIN sys.columns c ON c.object_id=t.object_id
LEFT JOIN sys.index_columns ic ON ic.object_id=c.object_id AND ic.column_id=c.column_id
LEFT JOIN sys.indexes i ON i.object_id=ic.object_id AND i.index_id=ic.index_id
WHERE t.name IN ('SysUser','SysRoles','SysPermissionDefinitions')
  AND c.name IN ('UserName','RoleCode','PermissionKey')
ORDER BY t.name,c.name,i.name;
```

三列均`Chinese_PRC_CI_AS`；角色码、权限键普通唯一覆盖全部状态，用户名唯一过滤`IsDeleted=0`。

PG实际索引查询：

```sql
SELECT t.relname AS table_name,i.relname AS index_name,
       ix.indisunique AS unique_index,pg_get_indexdef(i.oid) AS definition
FROM pg_index ix JOIN pg_class t ON t.oid=ix.indrelid
JOIN pg_class i ON i.oid=ix.indexrelid
JOIN pg_namespace ns ON ns.oid=t.relnamespace
WHERE ns.nspname='public'
  AND t.relname IN ('sys_user','sys_role','sys_permission','sys_user_role','sys_role_permission')
ORDER BY t.relname,i.relname;
```
