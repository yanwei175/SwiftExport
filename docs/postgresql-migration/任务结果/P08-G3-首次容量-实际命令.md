必要编译7次（仅本轮夹具变化引起，均0错误/7旧警告；无普通/全量测试）：

```powershell
dotnet build SwiftExport.Application.Tests/SwiftExport.Application.Tests.csproj --no-restore -v minimal
dotnet build SwiftExport.Application.Tests/SwiftExport.Application.Tests.csproj --no-restore -v quiet
```
