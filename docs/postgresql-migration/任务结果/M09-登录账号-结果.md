## 八方法实现与冻结决定

| 方法 | 本轮实现及保留边界 |
|---|---|
| GetActiveUserByNameAsync | 使用公共 PG 元数据的完整显式列别名；双方 rtrim ASCII 尾空格及既有 ICU；只读活动未删账号，保留单结果校验。 |
| GetActiveUserByIdAsync | UUID 读取完整凭据，活动未删筛选。 |
| IsAdminAsync | 三表 SELECT EXISTS；活动未删用户/角色及未删关联，RoleCode=SYSTEM_ADMIN。 |
| IsUserNameInUseAsync | 同一用户名比较；未删除域包括停用账号。 |
| CreateUserByAdminAsync | 先打戳、判重名，再独立授权 INSERT；定向 ON CONFLICT ((rtrim(user_name, ' ')) COLLATE public.erp_dictionary_ci) WHERE is_deleted=FALSE DO NOTHING RETURNING uid。零行再次查名，区分晚到重名或 ActorNotAdmin；其他唯一错误向上抛出。保留输入 Uid、Version、CredentialVersion，强制新记录活动未删。 |
| UpdateOwnPasswordAsync | 双版本及有效账号条件 UPDATE；数据库两版本各加一，影响一行成功；不向输入实体回填版本。 |
| ResetNonAdminPasswordAsync | 依次检查操作者、目标有效性、目标管理员；最终独立 UPDATE 重验操作者权限、目标非管理员、活动/未删及双版本。保留 ActorNotAdmin/TargetNotFound/TargetIsAdmin 的预判顺序，最后零行返回 ConcurrencyConflict。 |
| IsCredentialVersionValidAsync | EXISTS 匹配有效账号与凭据版本；服务仍拒绝非正版本。 |
