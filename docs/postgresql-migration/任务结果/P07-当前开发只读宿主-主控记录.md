当前原Development配置Auth:UseDevUser=true、DevUserName=dev。主控随后按真实两库查询：

```sql

SELECT Uid,IsActive,IsDeleted,CredentialVersion FROM dbo.SysUser WHERE UserName='dev';
-- PG dv_next，使用当前真实开发查询相等规则，只有SELECT
SELECT uid,is_active,is_deleted,credential_version
FROM public.sys_user
WHERE rtrim(user_name,' ') COLLATE public.erp_dictionary_ci=rtrim('dev',' ') COLLATE public.erp_dictionary_ci;
```
