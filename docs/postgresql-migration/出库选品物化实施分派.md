采用审查中的单语句 `candidates AS MATERIALIZED` → COUNT 聚合 → 有序 page → totals LEFT JOIN page。生产表候选定义一次，count 与页读同一物化关系，空候选和超末页保留总数。PG 单语句 MVCC 为本基础设施翻译的观察边界；不承诺 SQL Server 锁式 RC 每个微时刻相同，不增加隔离、更新锁、库存预占或业务重试。禁止两次候选生产读取、全量候选传到 C# 计数/分页、临时 DDL、通用物化框架。

保留源全部十字段与资格：正余额、实际仓未删启用、当前产品未删启用；默认仓 LEFT JOIN 仅未删、停用名称仍可见。单位仅 ASCII 空格 btrim 资格，输出原 Unit，tab/NBSP 不扩大过滤。关键词沿既有 Like 帮助方法及三个原列，不加新字段、ILIKE 或硬编码比较样本。
