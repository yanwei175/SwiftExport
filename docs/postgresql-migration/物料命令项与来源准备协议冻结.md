## 资源、连接和生命周期

复用当前DbSession及其唯一SourceDemandLease，不新增连接/事务/全局业务锁。已有机器命令C_cmd有才先取；全局CommandItem身份→全部SourceUID→全部GrossUID；每族按实际signed 64位key升序、去重，跨族重复摘要只额外串行，逆序释放。C_item键为UTF8 `SwiftExport:SourceDemand:CommandItem:{guid:N}` 的SHA256前8字节big endian；S/U键保持旧协议。不会按SourceType、来源或ExecutionRequest分区命令项。

Empty命令项也是真实写入身份，不能在准备/Insert入口过滤；原GetByCommandItem读取过滤Empty保持原语义。取消或反向完全释放贡献仍保留此全局身份。数据库无条件唯一约束仍是最终防线，不吞唯一错误/换UID重执行业务。

同一物理连接、打开周期、PID及占位必须有效；原parent/ambient事务、嵌套或并行准备拒绝。已有C_cmd必须完成真实获取、current且非AttemptPending才能准备需求。反向持来源后追加C_cmd拒绝，避免相反前缀。父事务完全结束且清空session引用后才归还租约；未知获取结果/周期变化/未结束事务/解锁失败复用现有隔离连接策略，不把不明持锁连接送回池。

U覆盖Gross下全部Net修订/历史/家族及其Link贡献/空范围，S覆盖同源新Gross成员。动态Net根子UID、采购头行及LinkUID仍在原action产生，不新增无真实需求的Revision/Root/Net全局锁。

## 技术发现与准备入口

新Core IMaterialDemandTransactionPreparation的四集合分别是sourceUids/grossDemandIds/netDemandIds/commandItemIds。当前PGGross以新partial实现，后续PGMaterial/Link复用同context委托；SQL服务业务入口暂不换库或增加长期双库框架。

事务外先读已知命令项的全部历史Link身份→union输入Net→全部Net的Gross归属→union输入Gross→Gross的Source→同源全部Gross成员。没有启停、软删、生命周期、目标类型或贡献数量业务资格裁决；输入和私有投影不是新领域表/DTO。空集合免发现SQL，缺失Gross仍声明已知U，缺失Net不造Gross。

取得整组C_item/S/U后重读Item/Net/Gross绑定及来源当前成员；出现/消失/改绑/新增未覆盖成员，释放整组并重新发现，不持U后补S或Item。发现、等待及有限重准备共享30秒取消预算；调用取消原样传播、预算耗尽null、首次业务事务与回执读取尚未开始。不重试action、不提前真实取号/供应商/版本/重放校验。

父事务各仓储方法只消费已有current完整覆盖；无父事务原方法局部准备不增加批次事务或把两独立MAX/Insert调用变成原子。Add逐行枚举/原部分提交，Link原全批校验与Dapper逐条写入边界保持。
