# 单位快照的当前链路

核对日期：2026-10-06。当前产品Unit保存字典英文代码，资料阶段可为空；ProductUnitPolicy对明确的新单位按有效Unit字典归一化，既有相同停用单位的保留规则以该策略实现为准。

SalesOrderLine.UnitSnapshot是销售采用事实，确认要求有效明细均有单位，SourceDemandReceptionService直接转为GrossDemand.UnitSnapshot，不以当前产品资料覆写。物料建立继承来源/组成单位，采购确认核对真实产品单位与采购快照；非标输入需明确合法单位。售后正数量补件同样要求单位。

入出库及InventoryLedgerEntry保存发生时单位快照，过账核验数量/单位一致，不自动执行单位换算。不因本次整理回填、改写或修复历史缺单位数据；历史是否补齐须查实际数据证据。
