> 2026-09-22：当前版本为“一单一个投诉，行只保存补件”。设计权威见[售后模块设计方案](售后模块设计方案.md)。本次修改业务代码、共享契约、WPF及售后测试，不自动执行业务库操作。

## 接口和契约

根路由仍为 /api/quality-control/after-sales；GET列表/详情/候选、POST新建及状态命令、PUT保存不变。API返回ServiceResult，读取Error.Code / Error.Field，不能只根据HTTP状态判断成功。

AfterSalesHeaderDto / AfterSalesEditHeaderDto增加投诉、责任方、问题产品、成本和要求交期等字段，AfterSalesLineDto / AfterSalesEditLineDto移除对应字段；完整归属见设计方案。QualityCategoryId可空透传，不提供分类功能。旧客户端不兼容，必须停止旧版本写入后配套发布。

保存协议仍提交完整Header和显式AddedLines / UpdatedLines / DeletedLines。空新占位被过滤，已有行只经显式删除集合删除。零明细合法。

~~~json
{
  "commandId": "10000000-0000-0000-0000-000000000001",
  "uid": "10000000-0000-0000-0000-000000000002",
  "version": 1,
  "header": {
    "customerId": "20000000-0000-0000-0000-000000000001",
    "acceptedDate": "2026-09-22",
    "customerComplaintNo": "CLIENT-001",
    "issueDescription": "成品松动，补发螺丝",
    "responsibleSupplierId": "30000000-0000-0000-0000-000000000001",
    "serviceAmountCny": 0,
    "requiredDate": "2026-10-01"
  },
  "addedLines": [{
    "uid": "10000000-0000-0000-0000-000000000003",
    "isNonStandard": true,
    "descriptionSnapshot": "螺丝",
    "quantity": 2,
    "unitSnapshot": "Pcs"
  }],
  "updatedLines": [],
  "deletedLines": []
}
~~~

示例Guid必须替换。纯投诉可将addedLines改为空，不要求责任方和成本已定。保存不发布需求；显式确认才交接正数量补件，交期来自Header.RequiredDate。

保存成功返回头最新版本，必须重新GET取得头行基线。网络结果不明时复用CommandId和完全相同内容；内容变更需新命令。并发冲突保留本地输入，不能静默覆盖。

## 页面与错误

Manager不再聚合旧行投诉或费用；投诉号及问题型号查头，补件型号用EXISTS。金额为空显示待定、0显示免费、正数显示整单人民币金额。

Detail新建零明细，可删除最后一行。上方编辑单个投诉，下方仅编辑补件。Header.字段名定位头输入，Lines[Uid].字段名定位稳定行。可补充权限CanEditSupplement适用头投诉号、投诉描述、原因、处理、退回日期、整单备注及行备注；CanEditFacts适用锁定事实和行结构。

正数量结案当前返回AFTERSALES_DELIVERY_QUERY_UNAVAILABLE；这是明确保留的边界，不接入PackingList或出库。来源安全撤回失败必须保留确认状态。
