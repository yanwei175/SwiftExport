# 售后用例说明

核对日期：2026-10-07。当前一单保存投诉/服务主事实，明细表达补件要求；具体字段以AfterSalesHeader/Line和DTO为准。

管理页与详情页已注册并消费IAfterSalesApi。草稿保存/删除、确认/取消和结案/重开/作废由独立服务处理，公共命令执行器维护事务及完整回执。确认正数量补发行必须有单位，将实物要求交给CR来源；取消需先取得来源安全退出证明，不在售后页面复制采购或库存反向。

售后品质分类由独立分类树维护，父级和末级均可选择。新选/改选要求分类存在且启用；历史未改选草稿与确认允许停用分类，分类仍可空。通用字典维护页不再显示该类型，旧字典数据保留；增量迁移按原 Uid 保留单据引用。本次实现及验证范围见[分类树主控验收](售后品质分类树主控验收.md)，运行库部署与人工交互验收另列状态。

正数量单据目前仍不允许结案：AfterSalesLifecycleService明确返回AFTERSALES_DELIVERY_QUERY_UNAVAILABLE。已具备PackingList来源和交付查询不表示结案证明接通；重开仅用于已Closed单据，不能用重开绕过结案条件。当前箱单CR来源走仅交付路径，不据标准ProductId推断自动库存。

字段、页面、调用方向及权限见[售后地图](../.agents/references/模块能力地图/售后模块能力地图.md)，API入口见[索引](业务API索引.md)。本说明不重新发布旧后端/前端实施任务，未运行客户端或售后写入。
