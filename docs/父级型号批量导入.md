# 父级型号批量导入

入口：父级产品页面“更多功能 → 批量导入”。页面沿用 `Products.Master.View`，提交 API 复用 `Products.Master.Edit`，应用服务额外实时检查活动管理员；没有新增权限键。

本轮替换旧导入导出实现，删除服务器预览、差异模型、整批原子提交、筛选资料导出和对应专用契约。公共 Excel/CSV 解析及服务器模板导出设施保持独立。本页提供下载空白导入模板、加载并校验文件、开始队列保存、停止、下载未成功数据。

## 文件规则

仅支持 XLSX，模板由客户端代码生成，不从服务器模板目录下载、不依赖 VSTO。第一行前十一列必须包含下列完整字段，可在十一列内调换顺序；必填“主型号”显示红色。

| 字段 | 规则 |
|---|---|
| 主型号 | 必填，最多 300 字符，按编码新增或更新 |
| 中文描述、英文描述 | 可空，各最多 2000 字符 |
| 中文配置、英文配置 | 可空，各最多 500 字符 |
| 每箱装率 | 可空，有值必须为正整数 |
| 每箱净重(KG)、每箱毛重(KG) | 可空，非负，最多 4 位小数，符合 numeric(18,4) 容量 |
| 每箱体积(CBM) | 可空，非负，最多 6 位小数，符合 numeric(18,6) 容量 |
| 产品系列英文名称 | 可空，最多 500 字符；按 `ProductSeries` 字典有效明细的 `DataNameEn` 匹配 Uid，去除首尾空格并忽略大小写；不匹配中文名 |
| 默认供应商编码 | 可空，最多 300 字符；服务器重验当前编码 |

空白去除首尾空格后归一为 null。更新时清空对应可空字段，包括 `ProductSeriesId`；空供应商沿用实体的 `Guid.Empty` 未设置约定。产品分类不再参与导入或错误数据导出：更新保留原分类，新型号保持未分类。默认装率已调整为 `int?`，实际子产品包装装率仍必填。`ProductType`、属性模板及标签选择不在导入字段内；非导入资料保留，父级数据不下发子产品。

请重新下载新模板。原“分类路径”列已替换为“产品系列英文名称”；旧分类模板会明确拒绝读取，避免把分类内容误当系列名称。系列不存在、停用、删除或英文名称匹配不唯一时，服务器返回该行原因，不创建新系列。

读取完整文件后统一检查表头、必填、长度、格式、范围及忽略大小写的重复编码。只要任意行本地错误，就不发送任何保存请求。错误文件下载包含整个输入文件和末尾“错误原因”列，用户修改后重新加载。重导入只读前十一列，忽略旧原因列。文本作为字面值写出，不转换为 Excel 公式；公式读取使用已保存缓存，缺少缓存时要求修正。

不设一千行限制，也不设旧的一万行导出限制。继续保留公共文件保护：输入最大 20 MiB、XLSX 声明解压最大 100 MiB、读取快照最大 250000 单元格（含表头）。超限明确失败，不截断；前十一列计入快照，原因列不计入。

## 队列和保存

客户端在内存维护队列，每批固定 100 行、最后一批可不足，每次最多一个 HTTPS 请求，复用既有认证 HTTP 客户端。DataGrid 只读、每页 100 行，翻页不重读文件；状态显示待提交、提交中、成功、失败、结果未知。进度按完整批次回执推进。

唯一接口：`POST /api/ProductMasterImport/import`，请求为 `List<ProductMasterImportRowDto>`，响应为 `ServiceResult<BatchSaveResponseBase>`，`SaveItemResult.RowIndex` 对应原文件一基行号。每请求接受 1 至 100 行，原行号必须有效、不重复。

服务端每行独立事务，重验字段。分类只按已有 Uid 保护原引用，不读取或解析分类树；旧、新系列按 Uid 排序锁定，然后锁供应商、主型号，重验匹配名称、启用状态、字典类型及主型号引用是否变化。复用主型号编码查询及活动编码唯一索引，创建冲突或更新失败返回该行原因；业务失败只回滚该行，继续处理其他行。属性模板和标签选择保留。导入不调用常规主从同步批量保存，不创建后台任务、数据库导入表或通用导入框架。

网络故障、认证失败、服务器切换、账号变化、取消或不完整回执都会停止发送后续批次；无法确认的当前批次标记“结果未知”，已收到的成功回执保持成功，未发送的行保持待提交。技术中断时服务器可能已提交本批的部分行，所以不能自动重试或承诺整批回滚。用户应先核对未知结果，再下载未成功数据处理。

保存启动后，只下载失败、结果未知及未发送行，成功行排除。队列不落盘，关闭页面前提供未下载数据提示；成功后手动刷新父级列表，避免覆盖已有列表草稿。

## 代码与发布

新导入核心实现为十个文件：WPF 视图及 code-behind、ViewModel、行模型、工作簿服务；Contracts 行 DTO 与 Refit API；Application 接口与实现；Controller。取消旧专用匹配、导出仓储方法，复用现有仓储。

装率可空贯通 Core、Contracts、普通维护校验、WPF 模型/Lookup、文本绑定及 PostgreSQL 基线。发布前须由管理员在目标库执行 [父级默认装率可空迁移](../SwiftExport.Infrastructure/Database/PostgreSQL父级默认装率可空.sql)，再发布后端和客户端。脚本仅交付，本轮不自动写库或部署。
