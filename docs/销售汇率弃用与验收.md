# 销售汇率弃用与验收

核对日期：2026-10-10。依据当前工作树源码及本次隔离测试；不表示运行数据库、Excel 实机或真实服务器已验收。

## 当前业务规则

销售订单汇率已退出业务输入和校验。ForExcel 检查、销售草稿保存及客户端不再要求填写汇率，不以缺失、零或负数阻断销售操作，也不补默认值 1。日期、客户、币种、定金比例、数量、价格、产品匹配、版本、权限与状态等原有规则继续有效。

币种及 USD／CNY 原始单价、行金额和商业快照继续保留。各币种金额按自身单价与数量计算，不按汇率推算另一币种报价，不新增价格管理功能。采购、产品、财务及币种主数据的汇率不在本次范围内。

## 兼容边界

| 对象 | 当前处理 |
| --- | --- |
| ForExcel `SalesOrderImportHeaderInput.ExchangeRate` | 保留可空属性以接纳旧数值请求，但不校验、不产生 `ExchangeRateInvalid`；旧错误码常量只为兼容保留 |
| 普通草稿 `SalesOrderEditHeaderDto.ExchangeRate` | 改为 `decimal?`；保存忽略传入值，新建实体留空，更新保留原记录值 |
| 查询与历史实体 | `ExchangeRate` 原样返回，包括 null、零、负数和正常历史值；列表及详情不再以零替代 null |
| WPF 销售详情 | 移除汇率输入和本地门禁；加载保留历史快照，新建不补默认值 |
| VSTO 销售导入 | 移除汇率输入与可导入标记；兼容文本属性不解析、不影响检查资格；检查及保存请求不填汇率 |
| 销售旧 `Header.ExchangeRate` 地址配置 | 不显示编辑项；保存其他配置时保留旧字段原始内容，读取前过滤，不参与客户端地址校验或赋值 |
| 仅含旧汇率的读取部分 | 不访问 Excel、不替换当前输入，提示该部分无活动字段 |
| 其他业务组、未知字段 | 保持原有检查、读取和受控赋值规则 |

配置兼容副本保留原始字段键、地址、工作表与方向，不与可编辑行共享引用，也不影响活动字段的统一参考表名；切换或重载配置会清理上一配置的副本。服务器对地址配置自身格式、权限、版本和事务的校验仍有效。本次兼容不授予自动清理配置或数据库的权限。

JSON 中旧数值请求继续可被共享契约接纳，缺省和 null 现在也可表示废弃字段；随附客户端须使用更新后的 Contracts 重新构建。没有验证任意旧客户端二进制的本地校验或反序列化行为。
