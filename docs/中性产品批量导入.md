# 中性产品批量导入

入口：中性产品管理页“更多功能 → 批量导入”。固定导入页签重复打开时激活已有页面，不替换队列。页面和文件操作沿用 `Products.Neutral.View`；上传沿用 `Products.Neutral.Edit`，服务端再次检查当前活动管理员，没有新增权限键。

## 模板与匹配

下载的空白 XLSX 由客户端代码生成，不使用服务器模板目录或 VSTO。第一行前八列识别字段，允许在八列内换序，必须完整且不重复。前三个必填表头为红色，编码列为文本格式。

| 字段 | 规则 |
|---|---|
| 主型号 | 必填，最多 300 字符，按现有 `MasterSku` 匹配父级 |
| 中性产品编码 | 必填，最多 300 字符，按全部未删除记录中的 `ProductCode` 唯一识别 |
| 颜色唯一编码 | 必填，最多 300 字符，按现有 `ColorCodeUnique` 匹配颜色 |
| 默认人民币采购价、默认美元销售价 | 可空、非负，符合 numeric(18,4) 容量和四位小数精度 |
| 默认汇率 | 可空，有值大于零，符合 numeric(18,6) 容量和六位小数精度 |
| 利润率 | 可空，零至小于一，最多四位小数；0.2 表示 20% |
| 图片地址 | 可空，最多 1000 字符；只保存文本，不探测或上传图片 |

主型号和颜色必须存在且未删除，不自动创建。编码不存在时新增；编码存在且父级相同时更新，保留原编码文本；编码属于其他父级时返回该行错误，本模板不调整归属。颜色只作为可更新属性，不参与匹配或重复判断。

空白 Trim 后转 null，更新时清空可空导入字段。价格、汇率及利润率直接保存，不进行价格计算。更新保留 `IsMainImage`、原始身份及创建审计；新增不自动设主图。主图补齐和带 UUID 的更新模板后续单独建设。

## 校验、队列与错误文件

后台读取整张工作表，在内存统一校验表头、必填、长度、数值及去除首尾空格后忽略大小写的重复 ProductCode。任一行本地失败阻止所有上传；此时可下载完整文件，末尾追加错误原因。

校验通过后，固定每批 100 行、最后一批可不足，同一页最多一个在途请求。DataGrid 只读、每页显示 100 行，状态为待提交、提交中、成功、失败和结果未知。进度按完整回执推进，翻页不重读文件。

唯一新增接口为 `POST /api/ProductNeutralManager/import`：输入 `List<ProductNeutralImportRowDto>`，输出 `ServiceResult<BatchSaveResponseBase>`，`SaveItemResult.RowIndex` 对应原文件行号。请求一至一百行，行号有效且不重复。服务端逐行事务，按颜色、父级、中性行顺序加锁，重验引用和归属，用当前版本保存；确定业务失败只回滚当前行并继续，技术中断停止整个请求。

取消、401/403、网络故障、账号或服务器变化、不完整回执均停止后续队列。当前批次可能已部分提交，不能自动重试或宣称整批回滚。保存启动后只下载失败、未知及未发送行，成功行排除；未知行先核对实际保存结果。旧错误原因列不参与重导入。

模板和错误数据均以字面文本写出，不将文本转换为公式；输入公式只使用已保存缓存，缺少缓存要求修正。输出沿用同目录临时文件原子发布，默认拒绝未经确认的覆盖。关闭或替换文件前提示尚未下载的数据，保存后由用户手动刷新中性产品列表。

不设 1000 行或 10000 行业务限制，保留公共文件保护：输入 20 MiB、XLSX 声明解压总量 100 MiB、读取快照 250000 单元格（包含八列表头）。超限失败，不截断。不支持 XLS、CSV 或宏文件。
