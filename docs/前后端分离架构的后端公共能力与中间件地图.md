# 当前后端公共能力与请求边界

核对日期：2026-10-06。当前业务能力由Application用例实现，HTTP边界和基础设施各有职责，不按旧计划额外建设通用业务框架。

| 能力 | 当前入口 | 边界 |
| --- | --- | --- |
| 宿主与请求管道 | WebApi/Program.cs、Configuration | 注册服务与HTTP流程，不编排单据业务 |
| 身份与具体权限 | WebApi/Authentication、Application/Services/Auth | 实时有效授权，未知键拒绝 |
| 错误包装及HTTP状态 | WebApi/ErrorHandling、Contracts/DTOs/Errors | 明确代码映射，不根据中文消息猜状态 |
| 请求关联和日志 | WebApi/Observability、CommandPipeline | 关联ID和结构化完成事件，业务审计独立 |
| HTTP防抖 | WebApi/RequestProtection | 频率限制不替代数据库幂等 |
| 请求验证、事务和回执 | Application/Commands | 模块授权委托、请求Validator、最外层事务与完整结果 |
| PostgreSQL会话及仓储 | Infrastructure/Data、Repositories | 共享IDbSession、稳定映射、异常分类，不定义HTTP状态 |
| 文件与业务图片 | DvFileStorage、WebApi/Files | 文件能力与业务引用/HTTP暴露分开 |
| 客户端API失败解析 | WPF/Services/Api | 读取ServiceResult错误、保留待确认命令，不决定业务准入 |

具体路径以[WebApi](../SwiftExport.WebApi)、[Commands](../SwiftExport.Application/Commands)、[PG接线](../SwiftExport.Infrastructure/DependencyInjection.cs)为准；权限/页面见[当前系统说明](系统设置与权限.md)，完整错误分类见[HTTP契约](统一错误与HTTP响应契约.md)。本次未重排中间件或运行宿主。
