# 父级型号批量导入导出

本模块属于 .NET 10 WPF 客户端。入口为「父级型号 → 更多功能 → 批量导入导出」，每次打开独立批次页签。读取和生成 XLSX 都在客户端内完成，无需安装 Excel、VSTO 或服务器文件目录配置。

## 使用流程

1. 在父级型号页完成一次成功查询，确定希望导出的筛选范围。
2. 从更多功能打开页面，下载空白导入模板。第一行是识别表头，第二行起填写；红色「主型号」必填。
3. 选择 XLSX 文件，选择并读取工作表。默认优先「父级型号」表，否则选首表；首表是说明页时可改选真正的数据表。
4. 校验与匹配，查看新增、更新、无变化或错误，以及拟保存差异。修正表格输入或移除错误行后重新校验。
5. 管理员确认后提交。修改任意输入或移除行都会使整批预览失效；提交前必须重新校验。
6. 导入成功后，来源管理页提示刷新。不会覆盖来源页尚未保存的父级或中性产品编辑。
7. 导出筛选数据时，读取打开页签时已应用筛选的全部已保存资料。后续修改来源页筛选不改变此页签的导出范围。

「当前选择」表示可选文件和工作表；「本批已读来源」表示当前表格实际来源。选择其它工作表不会隐式读取，读取失败会保留原输入和批次来源。

## 首期十一字段

| 模板识别表头 | 字段 | 规则 |
| --- | --- | --- |
| 主型号 | MasterSku | 必填，最多 300 字符；按现有数据库编码规则匹配 |
| 中文描述 | DefaultDescriptionZh | 最多 2000 字符 |
| 英文描述 | DefaultDescriptionEn | 最多 2000 字符 |
| 中文配置 | DefaultFeaturesZh | 最多 500 字符 |
| 英文配置 | DefaultFeaturesEn | 最多 500 字符 |
| 每箱装率 | DefaultPcsPerPackage | 正整数；新增空白默认 1 |
| 每箱净重(KG) | DefaultNetWeight | 非负，最多 4 位小数，符合 numeric(18,4) 容量 |
| 每箱毛重(KG) | DefaultGrossWeight | 非负，最多 4 位小数，符合 numeric(18,4) 容量 |
| 每箱体积(CBM) | DefaultCbm | 非负，最多 6 位小数，符合 numeric(18,6) 容量 |
| 分类路径 | CategoryPath | 完整祖先路径，例如「工具 / 夹具」；不自动建立分类 |
| 默认供应商编码 | DefaultSupplierCode | 按已有供应商编码匹配，不使用供应商名称，不自动建立供应商 |

ProductType、ProductTag 不进入模板、预览输入或导出文件；已有值保留。ProductSeries 本期不增加，后续单独接入。也不删除旧实体字段、修改常规维护页面或建设数据库迁移。

列可重排；缺失的可选列作为空白输入；重复识别字段或缺少主型号表头直接拒绝。未知列有忽略提示。空行跳过，错误仍按原文件行号定位。

更新时空白表示保留已有值，不提供清空、重命名、恢复删除记录或删除操作。新增时其它空白可选字段为空。数值文本使用固定小数点，不接受模糊千分位；实际数值单元格按原数值转换，不受界面文化影响。

公式仅读取文件中已有缓存；缺失缓存或错误缓存形成可修正的字段错误，不计算公式。平表识别字段及数据不接受合并单元格。输出的业务文本作为纯文本写入，等号等前缀不会成为公式。

## 权限和接口

不新增权限键。

- 页面入口、模板生成、读取、预览及导出使用 Products.Master.View。
- 本地表格编辑沿用父级创建或编辑能力；普通查看用户仍可预览和导出。
- 提交端点登记 Products.Master.Edit；服务再次读取活动账号投影，只有有效管理员可提交。普通用户即使拥有全部 CRUD 权限也不能提交。
- 不以 JWT 角色展示或客户端按钮禁用代替服务端检查。

| HTTP | 地址 | 返回 |
| --- | --- | --- |
| POST | /api/ProductMasterImportExport/preview | 全批逐行校验和当前/拟保存值，不写库 |
| POST | /api/ProductMasterImportExport/import | 管理员提交、逐行身份/版本回执 |
| POST | /api/ProductMasterImportExport/export | 全部匹配的已保存父级数据 |

Refit 沿用 Controller 基地址注册和现有 AuthTokenHandler。服务端只接收结构化行数据，不接收、储存或解析工作簿。预览和提交 JSON 正文限制 20 MiB；请求错误沿用 ServiceResult 与现有 HTTP 分类。

导入最多 1000 个非空输入行；导出最多 10000 行。超过上限明确失败，不截断、不静默分批。输入文件继续受公共服务的 20 MiB 原文件、100 MiB 声明展开内容、列/单元格容量及 XLSX/宏检查约束。

## 保存与失败边界

提交在同一请求会话和事务中重读分类、供应商及主型号匹配，核对预览中的 UID、Version、分类和供应商身份。锁顺序为分类、供应商、主型号。引用歧义、失效层级、编码重复、数值错误或依据变化均阻止整批保存。

专用服务只调用父级仓储的新增和更新。它不调用常规 BatchSaveAsync、ProductMasterSynchronizationService，也不下发中性产品或物料；已有类型、标签及未纳入十一字段的资料从原实体保留。

任何写入失败都会回滚前序写入，最后检查取消再提交，并清理事务槽位。预览不提供写入授权，提交始终重新校验；编码并发占用仍由现有数据库唯一约束兜底。无变化行不写库、不递增版本。

取消操作会保留输入并使预览失效。提交已到服务器时，取消或网络超时不证明服务器没有保存，须先查询已保存资料，再决定后续操作；客户端不自动重试。成功批次锁定，不能再次提交。

切换账号、退出会话、权限替换会取消旧操作并拒绝迟到结果；导出还核对 API 地址，并在最终文件发布点再次核对身份。输出采用同目录独占临时文件，默认拒绝覆盖；覆盖许可来自系统保存对话框。取消或失败不损坏既有输出。

## 源码归属

- Contracts/DTOs/Products/ProductMasters/ImportExport：输入、预览依据、回执与窄导出资料。
- Application/Services/Products/ProductMasters/Import：权限、引用解析、稀疏合并及整批事务。
- Infrastructure/Repositories/Products/ProductMasters：与分页共用筛选的有界导出和参数化编码匹配。
- WebApi/Controllers/Products/ProductMasters/ProductMasterImportExportController.cs：HTTP 边界。
- Client.Wpf/Features/Products/ProductMasterImportExport：工作簿平表定义、页签状态、原生编辑桥接及文件对话框。

模板由 ProductMasterWorkbookService 根据固定列定义即时生成，用户决定保存位置；没有预制模板目录，也不使用服务器 Report 模板目录。它与复杂销售、采购、箱单的服务器模板导出服务各自承担不同业务职责。页面列名、模板识别和文件导出共用此 Feature 的字段文案定义。
