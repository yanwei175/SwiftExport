# 系统设置与权限

核对日期：2026-10-06。当前代码已实现扁平RBAC与WPF设置窗口，不再沿用“实施中、旧直接授权待退出”的旧阶段计划。

## 权威事实与调用链

SysUser、SysRole、SysUserRole、SysPermission、SysRolePermission保存账号及活动关系。PermissionCatalog/PermissionKeys是代码目录；PermissionEvaluationService从真实有效用户/角色关系生成去重权限投影，未知权限键即使管理员也拒绝。系统管理员身份以稳定RoleCode识别；普通角色只得到目录允许分配的键。JWT身份、CredentialVersion和账号状态按AuthSessionService/UserAccountService的当前校验执行。

RbacManagementService负责用户、角色、分配及目录同步；影响管理员集合的操作保留最后管理员保护。管理端不任意新增权限定义，不使用角色显示名或旧模块关系授予权限。WebApi EndpointPermissionFilter映射具体Controller动作，Application写命令重验自身权限；WPF菜单/按钮只提供可见性与交互限制，后端始终权威。

## 现有设置能力

| 能力 | 当前服务 | 客户端/契约 |
| --- | --- | --- |
| 登录、本人身份、密码 | AuthSessionService、UserAccountService | IAuthApi、IRbacUsersApi，登录与密码页面 |
| 用户/角色/权限目录及分配 | RbacManagementService、PermissionEvaluationService | RBAC API；SystemSettings管理页面 |
| 字典类型/项 | SysDictTypeService、SysDictDataService | 系统设置字典页；本地导航不从字典动态创建页面 |
| 币种与独立汇率 | SysDicCurrencyService、SysDicCurrencyExchangeService | 相应API和币种/汇率页，沿用版本及引用校验 |
| Excel地址配置 | ExcelReadProfileService | IExcelReadProfileApi及VSTO消费；主版本管理完整快照 |
| 单据编号 | DocumentNoService | IDocumentNoApi；业务号段与技术Uid分开 |
| 客户端版本 | ClientVersionController | 现有版本查询，不代替业务权限 |
