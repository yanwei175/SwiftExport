# 当前复杂单据命令链路

核对日期：2026-10-06。以采购确认或箱单过账为例，客户端提交CommandId、版本及本用例预览依据，经Controller进入Application。HTTP权限过滤与业务命令权限校验不相互替代。

CommandPipeline先授权和验证；BusinessCommandExecutor准备必要资源、开启最外层事务、查相同请求成功回执或执行首次业务。所属服务锁定并重验真实单据、来源和库存事实，参加服务共享IDbSession；状态、业务审计、流水和回执统一提交。Preview不预留，旧令牌/版本不能保证正式写入资格。

成功可重放原完整结果；同CommandId不同内容拒绝；忙碌保留原请求重试；结果不明先核实，不能新建ID自动再写。已过账反向用受控反向事实，不删历史。
