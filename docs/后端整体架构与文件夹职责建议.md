# 后端当前架构与目录职责

核对日期：2026-10-06。本文整篇替换旧分批审查/迁移累计内容，记录当前代码结构。历史迁移实证继续保留在postgresql-migration，不能把本文当新一轮重构计划。

| 目录 | 当前责任 | 主要调用方向 |
| --- | --- | --- |
| WebApi/Controllers | 路由、模型接收、转发服务结果 | Application接口 |
| WebApi/Authentication、ErrorHandling、Observability、RequestProtection | 身份/权限、HTTP失败包装、关联日志、防抖 | 公共协议与Application权限评估 |
| Application/Services | 分域查询/草稿/确认/生命周期/过账/反向 | Core仓储接口及窄领域接口 |
| Application/Commands | CommandPipeline、BusinessCommandExecutor、命令验证/日志 | 最外层事务、完整成功回执 |
| Core/Entities、DatabaseSchema | 持久化实体、约束元数据、历史与逻辑关联 | 不依赖实现层 |
| Core/Interfaces | 会话、仓储、审计、领域基础协议 | 由Infrastructure实现 |
| Infrastructure/Data、Repositories | PostgreSQL连接、会话、通用/专用Dapper仓储 | Core与Contracts，不引用Application |
| Contracts/DTOs、Apis、SysEnums、Wrappers | 共享契约、Refit、枚举、错误和权限键 | 前后端共用，UI状态不进入DTO |

## 当前接线

[Infrastructure DI](../SwiftExport.Infrastructure/DependencyInjection.cs)已经注册PG连接、异常分类和专用仓储，IDbSession与DbSession共享scoped实例。[Application DI](../SwiftExport.Application/DependencyInjection.cs)连接当前用例与公共命令设施。2026-10-07整理后，实体直接声明PG表列名、类型、CHECK及部分索引谓词，仓储和结构生成共用EntityMetadataCache；专用SQL直接写固定PG名称，泛型CRUD保留元数据生成。不存在SQL Server名称投影或类型/表达式翻译层。

成品需求调用物料退出与Shipping核验；采购确认只检验采购事实；箱单调用入出库内部端口，统一库存服务写余额流水。实际服务切片已存在，不按旧计划重新拆分仓储或改目录。

## 确认事实与验证边界

当前源码仍含少量早期过渡注释/分支，不能据注释“SQL Server原行为”推断仍有SQL Server运行接线。数据库已部署、调用已成功、并发已通过必须由对应实际证据证明。本轮不运行构建、测试或数据库检查；既有结果和失败不重标绿色。

当前仍有正数量售后结案阻断、未提供的销售商业修订/恢复等能力，详见[业务总纲](../.agents/references/业务架构总纲.md)。只整理文档，不处理这些业务问题。
