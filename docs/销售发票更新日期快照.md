# 销售发票更新日期快照

`SalesOrderHeader.InvoiceUpdateDate` 是可空发票更新日期快照，对应 PostgreSQL `public.sales_order_header.invoice_update_date`（`timestamp(6) without time zone`）。发票日期继续使用 `OrderDate`；不借用审计字段 `UpdatedDate`，不参加金额、交期或需求计算。

销售草稿保存继续复用 `SaveSalesOrderRequest.Header` 的 `SalesOrderEditHeaderDto`。Application 接纳该快照，详情查询原样返回。VSTO 模型开放 `Header.InvoiceUpdateDate` 地址配置及手工日期编辑；.NET 10 编辑模型通过现有 Mapster 读回并回传，避免后续保存丢失。普通草稿的版本、权限、状态及幂等协议保持原有规则。

## 已有库部署

1. 确认目标业务库、备份与部署窗口后，人工执行 [增量脚本](../SwiftExport.Infrastructure/Database/PostgreSQL销售发票更新日期快照.sql)。仅新增可空列和列注释，不回填历史值、不改审计时间。
2. 部署更新后的后端；专用详情查询和通用头仓储都依赖新列，不能先更新程序集再补列。
3. 更新 VSTO 和 .NET 10 客户端，避免旧编辑客户端不带该字段而把现有快照清空。
4. 在销售地址读取配置中设置 `Header.InvoiceUpdateDate` 的值地址，保存配置；没有更新日期的模板留空即可。

[生成结构基线](../SwiftExport.Infrastructure/Database/Generated/SwiftExport.PostgreSql.Schema.preview.sql) 只用于空库结构评审，不能拿来升级已有业务库。本次没有执行业务库迁移；离线测试和 STA 模板验证不能替代真实 Excel 图片加载及服务器读写验收。
