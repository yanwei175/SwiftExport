# 采购单示例模板

本示例把当前 VSTO 代码控制的采购单版式转成受控 XLSX 模板，供 .NET 10 客户端的 ClosedXML.Report 服务使用。示例数据用于开发验收，不代表真实公司、客户、供应商或已保存的采购单；没有接入正式采购页面，也没有部署到正式服务器。

## 文件与契约

| 项目 | 位置或值 |
| --- | --- |
| 仓库模板源文件 | `模板/Excel导出/purchase-order-vsto-demo/v1/模板.xlsx` |
| 仓库源清单 | `模板/Excel导出/模板目录.json` |
| 模板 ID | `purchase-order-vsto-demo` |
| 单据类型 | `PO` |
| 数据契约键／版本 | `purchase-order.vsto-demo`／`1` |
| 模板文件版本 | `1` |

源清单是开发发布描述，可省略 `fileLength`、`sha256`，由既有发布工具校验源文件并计算；服务器实际清单必须包含完整长度和摘要。同 ID、同文件版本不能替换为不同内容，模板内容变化时提高 `templateVersion`；变量结构变化时另提高 `dataContractVersion`。

三份公共能力夹具仍在 `SwiftExport.Client.Wpf.Tests/Services/Files/Templates/Fixtures/`：`头与明细模板.xlsx`、`嵌套分组模板.xlsx`、`公式打印模板.xlsx`。它们验证插值、列表、分组、公式和打印，不作为正式采购单模板或采购业务 DTO。

## 旧代码与版式映射

事实来源为当前 VSTO 源码，未读取弃用资料：[固定布局](../../SwiftExport.Client.VSTO/Excel/Writing/OrderExport/PurchaseOrderTemplateLayout.cs#L9)、[样式与打印](../../SwiftExport.Client.VSTO/Excel/Writing/OrderExport/PurchaseOrderTemplateService.cs#L59)、[字段快照](../../SwiftExport.Client.VSTO/Services/OrderExport/PurchaseOrderExportDocument.cs#L28)、[填值与备注](../../SwiftExport.Client.VSTO/Excel/Writing/OrderExport/PurchaseOrderWorkbookWriter.cs#L76)。

| 旧位置 | 内容与模板变量 |
| --- | --- |
| A1:K1 | 合并、右对齐标题 `Title` |
| B2／B3／B4／B5 | `Order.CustomerCode`／`CustomerPoNo`／`BoNo` 为空时取 `OrderNo`／`SalesPerson` |
| D2／D3／D4／D5 | `Order.OrderDate`／`ExpectedDate`／`ReplyDate`／`PurchasePerson` |
| F2／F3／F4／F5 | `Order.SupplierName`／`InletHoseType`／`AeratorType`／`PalletType` |
| H2／H3／H4／H5 | `Order.BoxType`／`LabelType`／`InstructionManualType`／`CartonType` |
| I2:I5／J2:K5 | 合并商标标签／`Order.LogoType` 文本 |
| A6／B6:K6 | 特殊要求标签／合并的 `Order.Remark` |
| 第7／8行 | 间隔／固定明细标题 |
| 第9行起 | `Lines` 重复明细；A 列图片留空 |

`Order` 共 19 个属性，对应 18 个输出位置，额外 `OrderNo` 用于采购编号回退。B4 表达式为 `{{String.IsNullOrWhiteSpace(Order.BoNo) ? Order.OrderNo : Order.BoNo}}`。三个日期允许为空；调用方应提供日期值，不能把格式化日期文本混作日期计算值。

明细 B:K 的十个字段依次为：

```text
CustomerSku, LinkSku, SupplierSku, DescriptionZh, FinishZh,
FeaturesZh, UnitPrice, Quantity, UnitAmount, SubNote
```

旧导出按 `LineNumber` 排序，没有动态分组、按产品合并或图片下载。示例调用方须预先形成所需顺序的稳定 `Lines` 数组。金额取 `UnitAmount` 快照，不在模板重新计算单价乘数量；空单价、空金额保留为空。示例沿用 CNY 未税格式，优惠只记录，不抵扣合计，不使用税价或进行汇率换算。

`Summary` 提供 `LineCount`、`QuantityLabel`、`NotesText`：行数必须与 `Lines` 一致；合计标签和说明由调用方准备。零明细的 I/J 合计公式为 `0`；有明细时使用 `SUM(I9:INDEX(I:I,ROW()-1))` 及对应 J 列公式，以移动后合计行的上一行为终点，避免 Report 二次调整引用导致自引用。金额全部为空时金额合计仍为空。混合或未知单位可标注“合计（数量统计）”，缺失金额、优惠倍率、整单优惠金额和优惠备注进入说明。

旧代码的合计行为 `9+明细数`，其后每条说明占一行，再显示 B/F/I 的“制单：／审核：／批准：”。本示例将多条说明改为一个 A:K 合并、可换行的 `Summary.NotesText` 说明块，固定高 135，保留三条旧说明各 45 的空间，避免为第二个 Report 重复区域额外引入服务列而造成缩进。说明为空仍保留该块；超过三条或特别长的内容须检查换行是否截断。这是示例与旧动态备注行的明确差异，合计、说明和签字位置应随 `Lines` 展开验收。

## 样式、打印与公式边界

版式设计尽量保持原坐标：A:K 列宽依次为 `19.08、16.15、16.15、16.15、18.31、16.69、30.15、11.54、9、17.23、19.08`；标题行 45，单头行 26.1，特殊要求 40，间隔 5.1，表头 40.2，明细 120，合计与签字 30。基础微软雅黑 12，标题 18 粗体、配置明细 8、商标 26 粗体；表头浅灰 `#F2F2F2`，单头与明细黑色细边框。数量格式 `0.####`，日期 `yyyy/m/d`，单价与金额沿用人民币格式；型号和备注保持文本。

打印设计为 A4 纵向、宽一页高不限、水平居中，重复第 8 行，打印范围至签字行。四边 1mm、页眉边距 0、页脚边距 1mm，中心页脚“第 &P 页，共 &N 页”；不打印网格、行列标题或注释。文件结构检查及自动化渲染测试不代替 Excel 打印预览和实际纸张验收。

Report 展开列表会移动下方内容，但模板原始行高可能留在旧行。示例在合计标签、说明、制单标签后分别声明 `<<Height 30>>`、`<<Height 135>>`、`<<Height 30>>`，由 Report 在展开后设置尾部行高并移除标签。参数直接写数值，不能写 `size=135`；沿用 [Report 官方行高标签](https://closedxml.io/ClosedXML.Report/docs/en/More-options) 的格式，无需公共服务恢复旧行高，也不会覆盖其它模板合法的行高或自动适应指令。

旧 VSTO 写入器最后调用 `sheet.Calculate()` 保存合计缓存；当前 .NET 10 服务按已确认选择只保留公式，由用户打开 Excel 后计算，不承诺生成文件已含计算结果。不迁移 COM 调度、宿主活动窗口、屏幕更新、事件开关、打印驱动或 VBA 插图行为。

## 发布位置与客户端使用

仓库目录是模板源位置。服务器实际根目录仅由 `FileStorage:ExportTemplates:RootPath` 指定，并由 `Enabled` 显式开启；没有默认路径，当前仓库未启用服务器分发。生产根目录尚未选择，实际部署位置未知。部署说明中的 `D:\ServerTemplates` 只是示例，不能直接当作生产目录。

复用 [_tools/ExportTemplates/发布Excel模板.ps1](../../_tools/ExportTemplates/发布Excel模板.ps1)，从仓库根执行开发机验证或打包：

```powershell
pwsh -File .\_tools\ExportTemplates\发布Excel模板.ps1 -Mode Validate `
  -ManifestPath .\模板\Excel导出\模板目录.json -SourceRoot .\模板\Excel导出

pwsh -File .\_tools\ExportTemplates\发布Excel模板.ps1 -Mode Package `
  -ManifestPath .\模板\Excel导出\模板目录.json -SourceRoot .\模板\Excel导出 `
  -OutputRoot .\.artifacts\purchase-order-demo\模板包
```

这些命令不修改服务器配置。正式发布须由管理员选定实际根目录、确认读写账号后显式使用 `Publish`，详见[服务器模板部署说明](../../_tools/ExportTemplates/服务器模板部署说明.md)。服务器保存 `模板目录.json` 和 `purchase-order-vsto-demo/v1/模板.xlsx`，不能只复制清单。

客户端通过 `IServerExcelTemplateService` 按上述 `PO` 数据契约在线查询、选择精确模板版本，并提供 `Title / Order / Lines / Summary` 给已有生成器。本地缓存位于 `%LOCALAPPDATA%\SwiftExport\Cache\ExcelTemplates\v1`，是按服务器、账号及文件身份隔离的缓存，不是模板源或服务器目录；存在缓存也不能绕过在线确认或活动账号检查。

本示例没有正式页面入口，也没有新增导出权限键。模板列表与下载 API 使用活动账号读取策略；未来采购 Feature 接入时需沿用实际采购读取能力 `Procurement.Order.Read` 并明确数据范围。是否另设 Export 权限，应在正式导出操作的权限需求确认后决定，公共模板服务不会替页面授权。
